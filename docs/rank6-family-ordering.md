# Rank-6 Family Ordering

## Primitive-Family Definition

- Status: Proven. The `Reven6+` audit uses a genuinely new parity-even fully symmetric trace-free rank-6 primitive family
  `Z_{ijklmn}`.
- Status: Proven. This primitive family is local in the worldline EFT sense and is treated as a new admitted external-family block rather than as a derived descendant of an already audited family.
- Status: Proven. Trace descendants reducible to lower-rank audited families are excluded from the primitive-family definition itself.

## What Is Excluded

- Status: Proven. Trace-descended rank-6 structures reducible to rank-4, rank-2, or scalar audited families are not counted as new primitive-family admissions.
- Status: Proven. Derivative-generated rank-6 blocks are also excluded from the primitive-family definition itself.
- Status: Proven. In particular, blocks such as `GradU`, second-gradient descendants of lower-rank STF families, higher-gradient vector descendants, and scalar descendants dressed only by derivatives are not double-counted as primitive `Reven6+` admissions.

## Representative Choice

- Status: Proven. The audited representative is the fully symmetric trace-free rank-6 family rather than a generic rank-6 tensor.
- Status: Proven. This is the minimally irreducible parity-even rank-6 tensor class under the current MVP assumptions.
- Status: Proven. Using the STF representative cleanly separates a genuinely new primitive rank-6 family from trace descendants that belong to already audited lower-rank classes.
