# Rank-4 Family Ordering

## Question

- Status: Proven. The current family-envelope gate is whether `Reven4+` is a genuinely new local parity-even rank-4 primitive family in the MVP free-fall sector.
- Status: Proven. The question is not whether rank-4 structures exist at all; derivative-generated and trace-descended rank-4 blocks already exist inside lower-rank audited families.
- Status: Proven. The question is whether there remains a genuinely new primitive rank-4 family after those derived descendants are removed from the primitive-family census.

## What Counts As A Genuine Primitive Rank-4 Family

- Status: Proven. A genuine primitive rank-4 family is a local parity-even tensor family `Q_{ijkl}` admitted as its own worldline-EFT primitive, not as a trace descendant or derivative descendant of an already audited family.
- Status: Proven. The audit excludes trace descendants reducible to already audited lower-rank families, including scalar descendants and rank-2 STF descendants.
- Status: Proven. The audit excludes derivative-generated rank-4 blocks already attached to audited families, including `\nabla T`, `\nabla\nabla E`, `\nabla\nabla V`, scalar-Hessian descendants, and any lower-rank tensor dressed only by derivatives.

## Representative Choice

- Status: Proven. This audit uses option (c): a fully symmetric trace-free rank-4 representative.
- Status: Proven. That choice is explicit rather than tacit.
- Status: Proven. It is justified because:
  1. Any trace component of a parity-even rank-4 tensor reduces to a parity-even rank-2 or scalar descendant and therefore belongs to already audited lower-rank gates rather than defining a genuinely new even-rank family.
  2. Antisymmetric or mixed-symmetry pieces do not define the minimal new nonspinning parity-even MVP gate; under the current assumptions they either reduce to lower-rank descendants or move into sectors already excluded by `A2`.
  3. The fully symmetric trace-free representative is therefore the minimal irreducible parity-even rank-4 class left after quotienting out already audited lower-rank descendants and explicitly excluded sectors.

## Physical Role

- Status: Proven. The audit tests whether unsuppressed admission of this genuine STF rank-4 family creates a new low-order witness inside `\Delta \le 4`.
- Status: Proven. If it does, the theorem layer obstructed is promotion of the enlarged audited-set result `{R2, R0a, R0b, R1, Rodd+}` to an MVP-envelope theorem.
- Status: Proven. If it does not, the audit must still say why: reduction, exclusion, or absorption into already audited families.
