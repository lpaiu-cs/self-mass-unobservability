- Status: Proven. The current question is no longer whether the audited family classes have witnesses.
- Status: Proven. It is whether the already derived class-limited thresholds compose into a jointly sufficient protection of minimal-sector uniqueness for the enlarged audited family set `{R2, R0a, R0b, R1}` at `\Delta \le 4`.

## Distinctions

- Status: Proven. Per-class necessary thresholds tell us what each audited family class needs in isolation.
- Status: Proven. Joint sufficiency asks whether those already derived thresholds, imposed simultaneously, remove every new survivor involving the enlarged audited family set at `\Delta \le 4`.
- Status: Proven. A cross-family obstruction would be the smallest surviving operator that remains after all current audited thresholds are imposed together.
