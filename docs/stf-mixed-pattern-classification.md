# STF Mixed-Pattern Classification

## Purpose

- Status: Proven. This note separates the weaker self-witness threshold theorem from the stronger mixed-pattern story.
- Status: Proven. The threshold theorem is now closed for genuine parity-even STF primitive families with `L \ge 3`.
- Status: Proven. The mixed-pattern story remains split and must not be smuggled back into the threshold theorem.

## Closed Threshold Layer

- Status: Proven. [`stf-self-witness-theorem.md`](stf-self-witness-theorem.md) proves that every genuine parity-even STF primitive family `Y_L` with `L \ge 3` has no linear scalar witness, no mixed quadratic witness `E Y_L`, and therefore the universal necessary threshold `w_Y \ge 3` at `\Delta \le 4`.

## Current Audited Mixed-Pattern Split

- Status: Proven. Rank `2` is the special mixed-aware STF case because `EX` already exists at the mixed quadratic layer.
- Status: Proven. Rank `4` is an explicit mixed exception inside the audited higher-rank STF sector because the cubic layer contains `EEQ` as well as `EQQ`.
- Status: Proven. The audited ranks `3`, `5`, and `6` support the simpler first-mixed pattern `EYY`.
- Status: Proven. Therefore mixed-pattern universality across all higher STF ranks is false as previously attempted, or at minimum not available as a single uniform formula.

- Status: Conjectural. The present audited data do not yet prove that rank `4` is the only even-rank mixed exception in the full STF branch.
