# Vector-Family Ordering

## Genuine Primitive Rank-1 Family

- Status: Proven. In this repo, a genuine parity-even rank-1 primitive family `V_i` means a new local external vector species admitted as an independent primitive block in the free-fall worldline EFT.
- Status: Proven. Its descendant blocks `D_\tau V_i`, `\nabla_j V_i`, and `D_\tau^2 V_i` belong to the same primitive family `R1`; they are not separate family admissions.
- Status: Proven. A derivative-generated vector block already attached to an audited family does not count as a new primitive vector family.

## What Does Not Count As `R1`

- Status: Proven. `\nabla_i S`-type blocks belong to the derivative-only scalar family `R0b`, not to `R1`.
- Status: Proven. Divergence-type blocks such as `\nabla_j X_i{}^j` belong to the parent rank-2 family, not to `R1`.
- Status: Proven. The acceleration test block `a_i` is an EOM probe already present in the baseline reduction rules, not a new primitive family.

## Exact Physical Question

- Status: Proven. The current question is whether the MVP assumptions already force every parity-even local rank-1 vector block to be derivative-generated from an audited scalar or rank-2 family.
- Status: Proven. If not, then `R1` is a genuine primitive-family extension of the current MVP free-fall sector.
- Status: Proven. No such absorption rule is currently written in the assumptions ledger, so `R1` must be audited as a real family gate rather than dismissed by bookkeeping.

## Ordering Options

- Status: Proven. Option 1: no vector suppression. Then the first self witness appears already at quadratic order through `V2`.
- Status: Conjectural. Option 2: explicit vector-family ordering. One may assign `w_V > 1`, which delays both self and mixed vector witnesses.
- Status: Conjectural. Option 3: explicit absorption rule. One may assume every parity-even local vector is derivative-generated from already admitted families, but that would be a new explicit assumption rather than a hidden consequence of the current MVP setup.

## Current Verdict

- Status: Proven. No vector-family ordering or absorption rule is currently active in this repository.
- Status: Proven. Therefore `R1` is treated as a genuine next primitive-family audit, not as a derived subcase of `R0b` or `R2`.
