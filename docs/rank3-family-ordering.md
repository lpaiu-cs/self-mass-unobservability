# Rank-3 Family Ordering

## Question

- Status: Proven. The current family-envelope gate is whether `Rodd+` is a genuinely new local parity-even rank-3 primitive family in the MVP free-fall sector.
- Status: Proven. The question is not whether rank-3 structures exist at all; derivative-generated rank-3 blocks already exist inside audited families.
- Status: Proven. The question is whether there remains a genuinely new primitive rank-3 family after those derived descendants are removed from the primitive-family census.

## What Counts As A Genuine Primitive Rank-3 Family

- Status: Proven. A genuine primitive rank-3 family is a local parity-even tensor family `T_{ijk}` admitted as its own worldline-EFT primitive, not as a derivative descendant of an already audited family.
- Status: Proven. The audit excludes derivative-generated rank-3 blocks already attached to audited families, including `\nabla E`, `\nabla B`, `\nabla V`, and scalar-derivative descendants such as `\nabla_i \nabla_j \nabla_k S` or any lower-rank tensor dressed only by derivatives.
- Status: Proven. The audit also excludes trace descendants that reduce to already audited lower-rank families rather than defining a genuinely new primitive-family admission.

## Representative Choice

- Status: Note. This audit uses option (c): a fully symmetric trace-free rank-3 representative.
- Status: Proven. That choice is explicit rather than tacit.
- Status: Proven. It is justified because:
  1. Any trace component of a parity-even rank-3 tensor reduces to a parity-even vector descendant and therefore belongs to the already audited `R1` gate rather than defining a genuinely new odd-rank family.
  2. Antisymmetric or mixed-symmetry pieces do not define the minimal new parity-even, nonspinning MVP gate; under the current assumptions they either reduce to lower-rank descendants or move into parity-odd or spin-like sectors already excluded by `A2`.
  3. The fully symmetric trace-free representative is therefore the minimal irreducible parity-even rank-3 class left after quotienting out already audited lower-rank descendants and explicitly excluded sectors.
