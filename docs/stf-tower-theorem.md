# STF Tower Theorem

## Target

- Status: Conjectural. The attempted target is a single class-limited theorem for every genuinely new parity-even fully symmetric trace-free primitive family `Y_L` with rank `L \ge 3` in the MVP free-fall sector at `\Delta \le 4`.
- Status: Conjectural. The intended statement is:
  the first self witness is `Y2`,
  the first mixed witness is `EYY`,
  and the corresponding minimal-sector uniqueness threshold is self-only sharp with `w_Y \ge 3`.
- Status: Proven. This is only an STF-tower target; it does not speak about mixed-symmetry, antisymmetric, trace-descended, or derivative-generated higher-rank families.

## Verdict

- Status: Proven. The universal STF-tower target does not close as stated for all audited `L \ge 3`.
- Status: Proven. The first explicit failure occurs at rank `L = 4`.
- Status: Proven. The exact failing reason is that the genuine rank-4 STF class admits an additional mixed cubic witness `EEQ` at the same first mixed order as the manually recorded `EQQ`.
- Status: Proven. Therefore the statement "for every genuine parity-even STF rank-`L` family with `L \ge 3`, the first mixed witness is `EYY`" is false as a single class theorem.

## What Still Survives

- Status: Proven. The self-witness part survives across the audited STF ranks `L = 3, 4, 5`: the first self witness is always the quadratic norm `Y2`.
- Status: Proven. The rank-3 and rank-5 audits support an odd-rank STF pattern in which the first mixed witness is `EYY`.
- Status: Proven. The rank-4 audit is an explicit even-rank exception inside the presently audited STF sector.
- Status: Proven. The threshold statement `w_Y \ge 3` still survives for the audited ranks `L = 3, 4, 5`, but not through a single uniform mixed-witness formula.

## Consequence

- Status: Proven. The next theorem-layer step is not a move to `Reven6+`.
- Status: Proven. The next theorem-layer step is to split the higher-rank STF branch into at least an odd-rank pattern and a rank-4 even-rank exception, or to prove a stronger even-rank classification theorem that explicitly includes `EEQ`-type mixed witnesses.
