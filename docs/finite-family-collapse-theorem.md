# Fixed-order finite-family theorem

Status: Proven. At fixed cutoff D, a locally finite spectrum of positive-weight primitive species, derivatives of positive weight, and a finite tensor-contraction rule produce a finite candidate catalog. Quotienting by stated linear identities cannot increase its dimension. This is the fixed-order finite-family statement.

Status: Proven. For the manuscript's explicit electric block set and A9 potential premise, the weight-four quotient has five operator representatives. The proof is in Section 2 and Appendix A of [the unified manuscript](../paper/manuscript.md); it does not apply unchanged to a generic relativistic electric-Weyl gradient.

Status: Proven. A separate regularity statement, [Lemma 55](../lemmas/55-monopole-jet-collapse.md), gives a finite weighted response expansion with a controlled remainder from C^(D+1) regularity. Analyticity is sufficient and not necessary. This is not exact all-orders reconstruction.

Status: Proven. Neither catalog finiteness nor a finite response jet implies that every associated measurement template lies in an orbital nuisance span. Such absorption requires the actual rank/information condition. There is no general static unobservability theorem here.

Status: Proven. Optional admitted primitive families can add operators while retaining finiteness, so no uniquely physical minimal sector follows from these assumptions alone. Explicit internal states, nonlocality, and differentiability failures affect different layers.
