- Status: Proven. This note is class-limited to the parity-even, nonspinning, local MVP free-fall sector at fixed order `\Delta \le 4`.
- Status: Proven. It works only inside the current theorem domain defined by `A1`-`A8` in [`assumptions-ledger.md`](assumptions-ledger.md).

## Layer Separation

- Status: Proven. Finite primitive-family envelope closure is the statement that no genuinely new parity-even local primitive-family type survives beyond the audited scalar/vector/STF classes.
- Status: Proven. Fixed-order operator finiteness is the statement that, once a finite admitted primitive-family catalog is fixed, the candidate local scalar operator space at `\Delta \le 4` is finite before reduction.

- Status: Proven. Monopole jet collapse is the statement that, once a finite scalar normal-form basis `Y^I` exists and analyticity is imposed, the monopole response `m_A(Y)` has a finite fixed-order Taylor jet.
- Status: Proven. Wilson bookkeeping is the separate statement that higher-multipole operator data remain a finite residual coefficient set distinct from the monopole sensitivities.

## Positive Theorem Target

- Status: Proven. Conditional on the current theorem-domain assumptions `A1`-`A8`, once the irreducible primitive-family envelope closes on the audited scalar/vector/STF classes, every explicit finite admitted primitive-family catalog at `\Delta \le 4` yields a finite candidate local free-fall scalar operator space.

- Status: Proven. Conditional on locality `A3` and analyticity `A5`, the monopole term can then be written as a finite Taylor jet in finitely many scalar normal-form coordinates `Y^I`.
- Status: Proven. Conditional on the same theorem-domain assumptions, the residual higher-multipole operator sector carries finitely many Wilson coefficients that are not merged with the monopole sensitivities.
- Status: Proven. Therefore the positive finite-family collapse theorem closes inside the current theorem domain.
