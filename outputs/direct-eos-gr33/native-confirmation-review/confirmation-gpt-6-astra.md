## 3. B1 정정 확인 결과

### 규약과 입력

**Proven — 확인한 코드 사본과 동결 입력에 한정.**

저장소의 `outputs/remaining-levers15/native-source/`에서 다음 연결을 직접 확인했다.

- `Parameters.cpp`: 안쪽은 `inversetrigo(kappap/ei, etap/ei)`, 바깥쪽은 `inversetrigo(kappaB/eo, etaB/eo)`.
- `Utilities.cpp`: 함수 인자는 코사인, 사인 순서이며 사분면 처리도 이에 맞는다.
- 매개변수 번호 2·4·8·10은 각각 해당 η·κ와 연결된다.
- 기준시각 이동에서 `treference`와 두 `tasc`를 함께 이동한다.

따라서 정정된
\[
\eta=e\sin\varpi,\qquad \kappa=e\cos\varpi,\qquad
\varpi=\operatorname{atan2}(\eta,\kappa)
\]
가 이 코드와 일치한다.

**Imported from prior work.** Ransom 표 1도 안쪽·바깥쪽 모두 \(e\sin\omega>0\), \(e\cos\omega<0\)이며 근점 각은 각각 \(97.6182^\circ\), \(95.619493^\circ\)다. 정정된 사분면과 일치한다. 두 분석의 매개변수값 자체가 같다는 의미는 아니다. [Ransom et al. 2014, 표 1](https://arxiv.org/pdf/1401.0535)

지정된 WSL 릴리스 경로는 접근이 거부되었다. 따라서 **그 경로의 현재 파일과 저장소 코드 사본의 동일성까지 독립 확인한 것은 아니다.**

## 6. 확인하지 못한 것

- **지정 WSL 릴리스 파일의 직접 확인:** 접근 거부로 저장소 코드 사본을 사용했다. 양자의 동일성은 확인하지 못했다.
- **수정된 최소 통계량의 원 배열 기반 독립 재계산:** 투영 코드는 읽었지만 저장된 여섯 통계량을 원 타이밍 배열에서 다시 생성하지 않았다.
- **검증기·상징 계산 전체 실행:** 이용 가능한 Python 실행 경로가 작동하지 않았다. 대신 PowerShell/.NET으로 NPZ·JSON·CSV 산술과 선택한 해시를 확인했다.
- **Monte Carlo·스레드별 재현성 실험:** 재실행하지 않았다. 등록 결과 보존과 코드 의존성을 확인했다.
- **PDF 전 페이지 시각 검사:** 텍스트와 생성 TeX를 확인했지만 글리프·겹침·표 폭까지 시각적으로 보증하지 않는다.
- **전면 재심 범위의 사항:** 백색왜성 결합 계산, 전체 likelihood·pulse 재적합, 문헌상 최초성은 다시 심사하지 않았다.

파일 생성·수정·커밋 및 2분을 넘는 계산은 수행하지 않았다.
