# 단계173 — 통과한 수정 해의 결합 진화 계속

분류: Counterexample candidate. 단계172에서 통과한 실제6/12단계 상태를 그대로 재사용한다. 같은 수정 원천과 시간 규칙으로 광자·열·수소의 지정 전체 기간3.434431ms를 이어가고, 매 원 출력 절점마다 두 경로의 여섯 성분을 비교한다. 하나라도 원2% 기준 또는 보존·단계·출구 기준을 실패하면 즉시 중단한다. 최종 전하 결론은 아직 미판정이다.

분류: Counterexample candidate. 기본64/128 분할에 입력으로 정한 국소 이분을 적용한 전체 실제 단계 수는117/227이고, 이 중6/12는 이미 완료했다. 새로 필요한326단계를 한 번의 경로 쌍으로 진행한다. 이 단계 수를 물리적 최소량으로 부르지 않는다. 새 배경·EOS·공간 격자·원천·차수·추가 이분을 도입하지 않는다.

운영 예산:1 CPU thread, 주소 공간3GiB, 실제 실행 본문4800초(80분) 상한이다. 직전 실제 단계당 비용과 모형 재구성·입출력을 반영한 외삽은 약39분,1.75배 여유를 둔 계획치는 약68분이다. 후반 Krylov·조립·입출력 비용은 미측정 가정이며, 매 구간의 실측으로 남은 비용이 상한에 들어가는지 다시 검사한다. 두 모델은 메모리 상한을 지키도록 순차 실행한다.

분류: Counterexample candidate. 각각의 실제 하위 단계 시각·가중치로 각도 출구와 누적 유량을 재검사하고, 처음 수락한 상태·전달·출구 이력의 바이트 수준 배열 일치를 확인한다. 균일한 SDIRK 시각이나 가중치를 이 경로에 적용하지 않는다. 각 절점의 체크포인트와 실패를 남기며 자동 재시작하거나 격자를 다시 늘리지 않는다.

분류: Conjectural. 이 단계가 통과하면 **같은** 광자 충돌 전달을 자유 물질 진화에 넣고, 상호 결합 잔차와 GR·에너지·출구 이력을 연결해 최종 전하를 다시 판독해야 한다. 광자·열·수소만의 전체 기간 완료로 연구 목표를 완료하지 않는다. 전체 EOS·미분·공간·경계·비선형·정적·관측의 미해결 범위도 유지한다.
