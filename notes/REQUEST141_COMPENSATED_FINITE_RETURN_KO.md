분류: Counterexample candidate. **단계140의 유량 차분 병목을 수정해 실제 진폭의 자유 물질 64/128 경로를 완주하고, 그 압력·응력과 광자를 같은 GR 전하 계산에 적용했다.** native 충돌 교정의 끝점 기여는 +1.380775606782e-34다. 기존 native 압력 교정까지 합친 원천을 직접 적용한 끝점은 +1.021134292423e-27이며, 이 지정 계산에서는 양의 전하가 유지된다. 최종 물리 전하나 전체 결합 고정점 완료를 의미하지 않는다.

## 병목에서 실제 진화로

분류: Proven. 고정된 면 유량 B에 대해 F를 F-B, 셀 원천 G를 G-div(B)로 바꾸면 -div(F)+G는 그대로다. 심부의 고정 배경 압력 유량을 큰 운동량 유량에 더하기 전에 제외하고, 그 발산도 동시에 제외했다. 공유 면에서는 같은 값을 양쪽 셀에 사용한다. 이 항등식은 EOS·시간 적분의 오차 정리가 아니다.

분류: Counterexample candidate. 같은 물리 연산의 대표 0/8/16 시점 대조 오차는 최대 3.61e-14였다. 첫 구현에서는 공유 면을 두 단위 변환 순서로 각각 빼서 작은 잔여에서 3.80e-5 불일치가 발생했다. 원 큰 면 유량의 1e-12 일치를 확인하고 보상된 면 유량 하나를 양쪽에 그대로 전달해 수정했다. 이 실패와 실행 래퍼의 기본 인수 누락은 보존했다. 완료된 owner 대조나 물리 배경을 다시 계산하지 않았다.

분류: Counterexample candidate. 단계140의 같은 64경로 두 단계에서 유량 차분 지표는 0.002425358383에서 9.789029044e-6으로 감소했다. 더 짧은 128경로 pilot의 지표는 1.957081601e-5였다. 원 0.002 기준과 실제 진폭을 유지했다. 원 1e-6 선형 적용 범위 실패를 소급해 통과로 바꾸지 않았으며, 유한 진폭 비선형 물질 차분 방정식을 사용했다.

분류: Counterexample candidate. 두 생산 경로는 336/668 SSP 하위 단계를 거쳐 원 3.434431ms 구간을 완주했다. 새 광자 경로·EOS 보존 역산·배경 항성 경로는 만들지 않았다. 미세 경로 끝점의 최대 상대 상태 변화는 1.42154e-5로, 이번 경로를 이전의 미소 상태 기준 통과로 부르지 않는다. 실제 donor와 native 보간 EOS의 primitive 복원을 사용한 물질 반환이다.
