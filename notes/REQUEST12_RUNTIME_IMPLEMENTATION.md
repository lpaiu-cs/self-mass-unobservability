# Runtime implementation clarification

The archived engine reproduces the frozen baseline bit for bit. Its constructor takes about 139 seconds. The isolated recompiled exponential-capable engine also reproduces that baseline bit for bit, with a shorter constructor. Zero exponential amplitude selects the original unmodified RHS. Derivative production therefore uses this isolated build, with four independent processes and run directories; no scientific step sizes or gates change. The original slow Jacobian process was terminated before a derivative artifact was written. Its preflight and log are retained. Source and binary hashes distinguish the builds; baseline equality alone is not a derivative-accuracy claim. Initial-state production reuses one fit object because Integrate_Allways rereads the drive environment; a final zero-drive recovery is required.
