# Phase67 — 공통 EOS 준위의 실제 원자 흡수와 역방출

분류: Counterexample candidate. **공통 원자 상태가 실제 단면적에 들어가지 않던 구현 병목을 지정 유한 원자 모형에서 해소했다.** 같은 EOS의 He I·금속 16단계/566준위에 실제 oscillator strength가 있는 선 3,674개와 native 광이온화 단면적을 연결했다. 화학 평형 계수에서 독립적으로 만든 역반응 계수도 저장 점유수와 맞는다. 이는 선 세기를 자유 계수로 정규화하던 단계에서 실제 원자 진폭을 갖춘 공급기로의 진전이다. 전체 불투명도·소멸 연속 성분·새 결합 진화의 완료는 아니다.

분류: Imported from prior work. 단계66의 공통 유한 EOS·광학 준위, 원자 파일과 단계64 SYNSPEC 소스를 재사용했다. 실제 상태는 T=18827.94717983866 K, rho=1.91629314435e−9 g/cm³이며 EOS 호출 한 번으로 기존 저장 상태의 모든 원래 inventory snapshot 배열이 비트 일치함을 확인했다. 기체 EOS 바이너리와 기존 항성 이력은 변경하지 않았다.

## 실제 계수를 만드는 경로

분류: Imported from prior work. 원자 모형은 개별 준위와 superlevel을 포함하며, 공식 설명은 전이 세기·광이온화 단면적의 Opacity Project 계보 및 준위 에너지의 NIST 갱신을 명시한다. 원자 입력의 OSC는 bound-bound에서 oscillator strength다. 여기서는 새 목록을 합성하지 않고 이미 고정한 자료와 native RDATA/SIGK 경로를 사용했다. [공식 원자 자료 설명](https://tlusty.oca.eu/tlusty/Tlusty2002/data-atom.html), [TLUSTY 입력 설명, §10.3](https://tlusty.oca.eu/tlusty/Tlusty2002/pdf/tlguide200.pdf).

분류: Counterexample candidate. 기존 RDATA는 원자 모형의 선 전이 세기를 읽은 뒤 버리고 별도 선 목록으로 진행했다. 별도 실행 파일에서 이 파싱 결과를 내보내도록 연결했다. 원 입력 11,314기록 중 비활성/지원 밖 모드 7,245개, 공통 유지 준위 밖 395개를 제외한 3,674개를 채택했다. 이를 전체 천체 선 목록으로 부르지 않는다. 566개 준위 모두에 명시된 광이온화 채널이 정확히 하나씩 있고 다음 이온의 바닥 준위로 연결됨을 확인했다. 미지정 채널을 수소형 공식으로 만들어 넣지 않았다.

분류: Counterexample candidate. 같은 에너지 차이에서 선 주파수 nu를 정하고, 전이 단면적의 주파수 적분 S=pi e² f/(m_e c)를 사용했다. 단계66의 공동 생존 계수 p_ij=min(w_i,w_j)에 대해 다음을 각각 계산했다.

```text
A_line = n_i S p_ij/w_i
R_line = n_j S (g_i/g_j) p_ij/w_j
J_line = R_line (2 h nu³/c²)
chi_line = A_line - R_line
```

분류: Conjectural. 이 값은 선 중심에서의 관계와 주파수 적분 진폭이다. 유한 선폭에 대한 방출 프로파일·압력 넓어짐·재분배를 이 식만으로 인증하지 않는다. 이전 60,140선 Voigt 배경을 새 상태의 3,674선으로 곧바로 대체하지 않았다. 공동 생존 모형과 PL/MHD 광학 해석도 여전히 명시 가정이다.

분류: Counterexample candidate. 광이온화는 native SIGK를 그대로 호출하되 이 공급기에서는 공기 파장 보정을 제거하고 진공 주파수를 사용했다. EOS 문턱 I_new와 원자 자료 문턱 I_old의 차이에 대해 **방출 전자의 에너지 epsilon을 고정**하여 `E_old=I_old+epsilon`, `E_new=I_new+epsilon`으로 옮겼다. 단면적 값을 주파수 비율로 임의 확대하거나 점유수에 맞춰 조정하지 않았다. 원자 파일의 피팅 함수·공명·고에너지 외삽 자체는 수입 모형으로 남는다.

## EOS 화학 평형에서 역반응을 구성

분류: Counterexample candidate. 기존 EOS의 ionize가 이미 보존하던 station_ce, station_dv, station_binding, station_zero를 직접 읽었다. 중성 기준 지수 a_0=−station_zero, q>0에서 a_q=ce_q+dv_q−B_q c2/T로 놓으면 부모 단계 비는 exp(a_(q+1)−a_q)다. 이 계수를 저장 점유수 비에서 역으로 맞추지 않았다.

분류: Counterexample candidate. 준위 i의 해당 이온 내 분율을 f_i, 부모 바닥 분율을 f_parent,0라 하면 `K_i=exp(a_q−a_(q+1))*f_i/f_parent,0`를 저장한다. 부모 바닥 분율은 같은 EOS의 여기 합에서 읽는다. 부모 이온 전체를 바닥 상태로 간주하지 않는다. u=h nu/(kT)에서 다음을 별도로 계산한다.

```text
A_nu = n_i sigma_i(nu)
R_nu = n_parent,0 K_i sigma_i(nu) exp(-u)
J_nu = R_nu 2 h nu³/c²
chi_nu = A_nu - R_nu
```

분류: Proven. 선언 평형 조건 `n_i=n_parent,0 K_i`이면 `J_nu=chi_nu B_nu`가 항등적으로 성립한다. 실제 단면적 sigma_i가 양방향에 그대로 남는다. 기호 검산을 통과했다.

분류: Counterexample candidate. 흡수 점유수만 10% 늘린 양성 대조에서는 J가 그대로이고 chi가 달라져, 코드가 마지막에 J=chi B를 강제하는 구현이 아님을 확인했다.

분류: Conjectural. **이 역반응은 고정 bath의 열역학적 상세평형 폐쇄다.** 비이상 다체 재결합의 산란 행렬이나 독립 Milne 단면적을 유도한 결과는 아니다. 전자 활동도와 구성 자유에너지 보정은 EOS 계수에 들어가며, 다른 상태에서는 이를 다시 계산해야 한다. 이 고정 계수를 비평형 원자 kinetics에 그대로 적용하는 일반화는 미인증이다. 상세평형의 통과만으로 단면적의 물리 정확도나 전체 수송을 인증하지 않는다.
