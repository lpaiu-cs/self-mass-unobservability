# Phase42 — 물질 운동·반경 변화에서 전하 읽기로 연결

## 결과와 연구 판단

분류: Counterexample candidate. **온도에 한정했던 전하 읽기를 바리온 재분배·반경 변화·속도·열유속 응력으로 확장하고, 저장된 실제 결합 진화의 아홉 끝점에 연결했다.** 새 시간 적분은 하지 않았다. 구동−무구동 및 구동−물질 결합 제거 대조의 준정적 전하 읽기가 사전 시간 대조 기준을 모두 통과했다. 상태에서 전하로 가는 연결 병목에 대한 loophole progress다. 빠른 펄스의 복사 전하나 실제 궤도 응답까지 해결한 것은 아니다.

분류: Counterexample candidate. 가장 촘촘한 경로의 구동−무구동 전하 변화는 약 `−1.17210e-8`이다. 고정 재고의 온도 미분만 적용하면 `+3.57985e-10`으로 **부호가 반대이고 크기는 약 33분의 1**이다. 바리온 재분배의 선형 기여는 `−1.22875e-8`이며, 온도와 이를 합한 뒤 남는 조성·비선형·교차 기여는 전체의 약 1.78%다. 따라서 단계 41의 열 민감도 상계만으로 전체 응답을 닫을 수 없다는 판단을 수치적으로 뒷받침했다.

분류: Conjectural. 이 결과를 기존 쌍성의 `1e-9` 목표 달성으로 세지 않는다. 계산한 구동은 0 배경의 강한 수치 펄스이며 쌍성의 약한 비영 배경 구동과 다르다. 또한 매 순간 물질을 준정적으로 외부장에 투영한 전하 읽기이지, 실제 전파·복사를 포함한 동일 펄스의 무한대 전하는 아니다. 다음 핵심은 **비영 배경에서 정규화한 유체 응답과 시간 의존 외부장을 같은 방정식으로 연결하는 것**이다. 긴 궤도 적분 대신 주파수 영역에서 풀 수 있는지 먼저 판단하되, 정상 배경과 경계 조건을 가정으로 숨기지 않는다.

## 추가한 보존 미분

분류: Proven. 셀 바리온 `B=a rho W V`에서 `eta=delta ln B`이면

\[
\delta\ln\rho=\eta-\delta\ln V-\delta\ln W
-a^2\left(\frac{\delta m}{r}-\frac{m\,\delta r}{r^2}\right).
\]

분류: Proven. 정지 배경에서 `delta ln W=0`이고, 열유속을 포함한 응력은

\[
E=\frac{\epsilon+Pv^2+2Qv}{1-v^2},\quad
R=\frac{\epsilon v^2+P+2Qv}{1-v^2},\quad
-E+R+2P=-\epsilon+3P.
\]

따라서 속도 미분은 `delta E=delta epsilon+2Q delta v`, `delta R=delta P+2Q delta v`다. 움직이는 상태에서 정지 상태용 `−E+3P`를 trace로 쓰면 틀린다. 열유속 변화만의 1차 응력은 이 정지 배경에서 0이지만 유한 속도 상태의 `Qv`는 전체 native 읽기에 포함했다. 이 항등식·계량 미분·바리온 관계는 기호 검산했다.

분류: Counterexample candidate. `m'=4 pi G r^2 E`의 이산 질량 제약과 위 바리온 관계를 함께 미분해 각 셀의 밀도·압력·trace를 갱신한다. lapse에는 방사 응력 `R`, scalar source에는 불변 trace를 사용한다. 반경 변화는 면의 위치를 바꾸되 셀 내 부피 비율을 유지하며, 바뀐 부피·질량·계량·외부 매칭과 질량 분모를 모두 포함한다. 외부는 단계 41의 `phi_infinity→0` 극한을 재사용하며 `C=alpha/phi_infinity`를 읽는다. 유한 배경 나머지항의 상계는 이번에도 없다.

분류: Counterexample candidate. 선도 미분은

`delta C = g_B · eta + g_T · theta + g_r · xi + g_v · delta v`

로 구현했다. `xi_i=delta r_face,i/r_face,i`, `theta=delta ln T_J`다. 조성은 이 미분 대조에서 고정하지만 저장 진화의 native 끝점 투영에는 실제 이류된 26종 조성을 사용한다. 고정 격자의 바리온 재분배와 이동하는 물질 좌표의 반경 변화는 같은 운동을 표현하는 서로 다른 좌표일 수 있으므로, 동일 이동에 두 기여를 중복 합산하지 않는다.

| 미분 좌표 | 수치 `l1` 노름 |
|---|---:|
| 셀 바리온 | `3.80063e-4` |
| 온도 | `1.14356e-5` |
| 면 반경 | `3.15038e-4` |
| 속도, 실제 초기 열유속 | `3.93246e-20` |

분류: Counterexample candidate. 위 표는 수치 미분값이며 새 기계적 방향의 구간 인증 상계는 아니다. 온도 성분은 단계 41과 일치했다. 전체 반경 변화는 움직인 벽의 민감도이며 압력 0 자유 표면이 진화했다는 뜻이 아니다.

## Native 대조와 검출 한계

분류: Counterexample candidate. 내부 면 이동, 전체 팽창, 총 바리온을 보존하는 재분배를 각각 `±0.001`, `±0.0003`으로 바꾸고 실제 EOS와 질량 제약을 다시 풀었다. 세 독립 방향 모두 사전 기준 `절대 오차 < 2e-12 + 0.005 |미분|`을 통과했다. 예상 미분과 최대 절대 차이는 각각 `2.20e-11`, `2.28e-10`, `4.06e-15`다. 선택한 방향과 스텝의 대조이며 전체 물리 EOS 오차 인증은 아니다.

분류: Counterexample candidate. 속도 방향은 실제 초기 열유속이 너무 작아 예상 미분 `2.45e-20`이 절대 검출 바닥보다 작고 native 중앙 차분은 0이었다. 결과 파일의 허용치 통과를 속도 항의 수치 검출로 해석하지 않는다. 별도 **추가 EOS 호출 없는** 운동학적 양성 대조에서 `Q=0.01(epsilon+P)`를 선언하면 정확한 trace를 사용한 미분은 `0.03168986157`, 잘못된 `−E+3P`를 사용하면 `−2.72479e-6`이다. 두 중앙 차분은 올바른 값과 일치했다. 이 대조는 응력·trace 구현을 검사하며 물리적 열유속 배경을 새로 진화시킨 결과가 아니다.

## 기존 결합 진화에 적용한 결과

분류: Counterexample candidate. 단계 40의 각 끝점에서 셀별 바리온, Jordan 온도, 조성, 속도와 Jordan 열유속을 유지하고, 선도 scalar 배경의 방사 질량 제약에 맞게 밀도를 복원해 전하를 계산했다. 원 scalar 응력과 유한 frame 인자를 그대로 외삽하지 않았다. 이는 원 궤적 위에서 정의한 별도의 준정적 투영이며, 원 궤적의 방정식·결과를 수정하지 않았다. 세 경로 모두 동일한 `beta=-4` 전하 함수로 비교한다. 따라서 `beta=0` 진화 경로에 대한 이 읽기는 beta=0 이론의 전하 자체가 아니다.

분류: Counterexample candidate. 사전 기준은 전하 읽기 크기 `>=1e-12`, 차수 `>=0.8`, 최종 간격 차이/응답 `<=0.1`, 응답/(차이의 2배) `>=10`이다. 모두 통과했다. `1e-12`는 이번 저장 펄스 읽기의 수치 판정 바닥이며 선언 쌍성의 `1e-9` 목표를 바꾼 것이 아니다. 차이의 2배는 경험적 지표이며 엄밀한 시간 오차 상계가 아니다.

분류: Counterexample candidate. 최종 구동−무구동 변화의 초기 배경 선형 분해는 바리온 `−1.228752e-8`, 온도 `+3.579847e-10`, 속도 `−1.71e-25`, 나머지 `+2.085199e-10`이다. 구동−물질 결합 제거 대조의 나머지는 전체의 약 2.41%다. 나머지에는 조성·비선형·교차 항이 모두 남아 있으므로 이를 특정 물리 기작 하나로 해석하지 않는다.

분류: Counterexample candidate. 누적 바리온으로 추적한 물질 면의 최대 이동은 가장 촘촘한 구동 경로에서 `5.92222e-6 R`, 약 `408 m`다. 셀 내 부피에 대한 선형 보간으로 정의한 값이며 해상도 미분이나 연속 궤적 인증은 아니다. 외곽 벽의 이동은 0이고 내부 물질 이동은 0이 아니다. 투영 전후 총 바리온은 상대 약 `1.1e-17` 이내에서 유지됐다.

## 범위·비용·다음 의존성

분류: Conjectural. 이번에 해소한 것은 **움직이는 물질 상태와 반경 변화를 전하 함수에 전달하지 못하던 연결**이다. 자유 표면 동역학, 비영 scalar 배경의 실제 유체 증폭, 시간 의존 복사 외부장, 실제 궤도 주파수의 정적 비교 제거는 여전히 미완료다. 기존 펄스는 고정 벽과 기준 정수압 잔차를 빼는 공간식을 사용한다. 그 기준 보정의 통과만으로 물리적 정수압 평형이나 전체 공간 수렴이 증명되지 않는다. 따라서 현재 정상처럼 유지되는 무구동 수치 상태를 확인 없이 실제 항성의 정상 배경으로 승격하지 않는다.

분류: Conjectural. 다음 계산은 동일한 비영 배경에서 유체 선형 연산자·보존 전하 미분·시간 의존 외부 조건을 함께 구성해야 한다. 그 전에 기존 벽과 정수압 기준 보정이 해당 배경에서 어떤 외력 또는 수치 근사를 뜻하는지 고정한다. 정적 한계의 복원과 구동 제거 대조를 수락 기준으로 삼고, 실제 궤도 주파수의 응답은 가능한 경우 직접 선형계로 구한다. 이번 신호를 이유로 자유 표면·물리 EOS·관측 연결을 건너뛰거나 장기 궤도 적분을 시작하지 않는다.

분류: Counterexample candidate. 총 26개 native 구속 상태(초기 1, 방향 대조 16, 저장 끝점 9), EOS 호출 1,510회, 내부 벽시간 `24.76초`, 프로세스 전체 `26.86초`였다. 사전 상한은 180초·최대 27상태·상태당 24회 반복이며 모두 지켰다. worker 4개, BLAS 1스레드, user/system CPU 시간 `49.91/0.52초`, 최대 RSS `127,116 KiB`다. 사후 분해·양성 대조는 내부 약 0.29초, 추가 EOS 호출·적분 단계 0회다.
