# 단계 53 — 물리 열수송을 정하는 데 빠진 입력

분류: Proven. 평형 EOS·정상 열전도도·두 정적 불투명도 평균 및 일반적인 소산/속도 조건만으로는 시간 의존 열수송이 일반적으로 유일하게 정해지지 않는다. 양의 계수를 갖는 정확한 반례와 열전도 완화시간의 비유일성을 기호 검산했다. 이는 **현재 평균 계수만으로 물리적 결합 진화 완료를 선언하는 경로의 장애**를 확정한 theorem progress다. 실제 항성의 동적 전하가 없다는 no-go나 불확실성의 수치적 하한을 증명한 것은 아니다.

분류: Counterexample candidate. 단계 52의 실제 선형 반응·중성미자 경로와 사전 대조 통과는 유지한다. 이번에는 광자·전도까지 포함한 새 항성 경로를 실행하지 않았다. 앞서 제시한 “다음에는 열유속을 연결한다”는 작업에는 구현 외에 물리 구성식의 결정을 먼저 수행해야 한다. 결과 수렴이 임의의 구성식을 실제 물리로 보증해 주지는 않는다.

## 평균 둘이 같아도 동적 전달은 다르다

분류: Proven. 정규화된 Planck/Rosseland 가중치가 모두 1/4인 명시적 네 그룹 모형을 생각한다. 다음 두 양의 불투명도 집합은 산술 평균 `9/8`, 조화 평균 `8/9`가 정확히 같다.

```text
A = (1, 1, 1/2, 2)
B = (3/2, 2/3, (7+sqrt(13))/6, (7-sqrt(13))/6)
```

분류: Proven. 시간 완화의 Laplace 전달을 `H(s)=sum_j[1/(kappa_j+s)]/4`로 두면 `H_A(0)=H_B(0)`이다. 그러나

```text
H_A(s)-H_B(s)
 = s*(s-1)*(4*s²+9*s+4)
   / [4*(s+1)*(s+2)*(2*s+1)*(2*s+3)*(3*s+2)*(3*s²+7*s+3)]
```

분류: Proven. 실제 조화 주파수에 해당하는 `s=i`에서 차이는 정확히 `9/1820`이다. 두 평균을 모두 안다는 일반 조건은 이 예의 동적 전달을 식별하지 못한다. 모든 그룹 계수는 양수이며 같은 정상 수송 계수까지 유지한다.

분류: Conjectural. 이 동일 가중치 예를 실제 항성의 Planck 가중치·스펙트럼으로 사용하지 않는다. 실제 항성 자료의 불확실성이 `9/1820`이라는 뜻도 아니다. 기존 Rosseland 하나의 비유일성에 더해, 정적 평균의 개수를 늘렸다는 사실만으로 동적 충돌 연산자가 확보됐다고 판단할 수 없음을 보여 준다. 실제 불확실성 크기는 물리 충돌 모형과 그 오차를 따로 연결해야 한다.

## 정상 전도도는 완화시간을 보정하지 않는다

분류: Proven. 상수 양의 열용량 `C`, 전도도 `K`에 대해

```text
C*T_t + q_x = 0
tau*q_t + q = -K*T_x
```

분류: Proven. 주기/무유속 경계에서는 이차 에너지 `integral(C*T²+tau*q²/K)/2`의 시간 변화가 `-integral(q²/K)`다. 따라서 모든 `tau>0`가 같은 정상 전도도와 양의 소산을 갖는다. 특성속도는 `sqrt(K/(C*tau))`이므로 광속 제한은 `tau>=K/(C*c²)`라는 하한만 준다. 더 큰 `tau`를 모두 제거하거나 특정 값을 정하지 못한다.

분류: Proven. 공간 Fourier 모드 `k`에 열 원천을 가하면 온도 전달은 `(1+s*tau)/(C*s*(1+s*tau)+K*k²)`다. 같은 EOS 열용량과 같은 `K`라도 `tau`가 다르면 시간 응답이 달라진다. 저장 코드의 전도 완화시간을 수치 시간척도와 연결한 선택은 이런 자유도를 물리적으로 보정한 것이 아니다. 이 수학적 모형족의 모든 `tau`가 실제 항성 전자 플라스마에서 실현된다는 주장은 하지 않는다.

분류: Counterexample candidate. 같은 자유 표면 배경의 원 native 5,735셀에 `C=rho*cv`와 저장 `K`를 대입한 **이 단순 Cattaneo 부문의 조건부 하한**은 복사 채널에서 `8.25e-22–2.06e-4 s`, 전도 채널에서 `9.41e-20–1.45e-13 s`다. 이 값은 실제 충돌시간 추정도, 전체 상대론적 결합계의 인과성 인증도 아니다. 하한을 등식으로 넣어 미지의 시간을 정하지 않는다.

## 현 자료와 필요한 물리 입력

분류: Imported from prior work. 저장된 OP 연결은 옛 분자 기준 상태의 일부 원소/영역을 지원하며 고밀도 2,692셀과 Li/Be/B/F 자료의 결손을 이미 기록했다. 그 숫자를 새 비영 배경에 대한 재평가 결과로 사용하지 않는다. LANL의 선택된 혼합물·온도/밀도에서 확보한 스펙트럼과 16/32그룹 자료도 보존되어 있으나 전체 새 배경의 충돌 연산자에 해당하지 않는다. 원 스펙트럼 구적 실패와 수정 reader의 성공은 구별한다.

분류: Imported from prior work. 현재 [MESA `kap` 설명](https://docs.mesastar.org/en/latest/kap/overview.html)은 복사 출력을 Rosseland 평균으로, 전도 출력을 정상 열전도도에서 환산한 값으로 설명한다. [ÆSOPUS 제공 화면](https://stev.oapd.inaf.it/cgi-bin/aesopus_2.0)도 저온 Rosseland 평균을 제공하는 경로다. 이런 평균표를 더 확보하는 것만으로 아래 입력을 모두 얻었다고 할 수 없다.

분류: Conjectural. 다음 표는 물리 수송을 구현할 때 명시해야 하는 입력 계약이다. 특정 근사 구성식을 택하는 연구는 가능하지만 선택의 근거와 오차를 해당 주장에 포함해야 한다.

## 다음 실행의 변경

분류: Conjectural. 당장의 실행 대상은 새 장기 항성 적분이 아니라 **에너지 의존 충돌 모형의 원식과 적용 영역을 현재 전자 상태에 연결하는 일**이다. [Potekhin 연구진의 원 자료 안내](https://www.ioffe.ru/astro/conduct/conduct.html)와 [에너지 의존 완화시간 이론](https://arxiv.org/abs/astro-ph/9604130)을 다음 원천으로 좁혔다. 강한 자기장/축퇴 조건의 식을 현재 전체 항성에 그대로 쓰지 않으며, 비자화·축퇴/비축퇴·부분 이온화와 혼합물 적용 영역을 확인해야 한다. [공개 전도 표 설명](https://www.ioffe.ru/astro/conduct/condint.html)은 완전 이온화 가정의 적용 한계도 명시한다.

분류: Counterexample candidate. 원 안내 페이지의 직접 조회는 웹 도구 시간초과, WSL 및 Windows의 TLS 인증 실패로 본문 파일을 확보하지 못했다. 검색으로 확인된 원 출처와 실제 파일 확보를 구분한다. 인증 검사를 해제하거나 다른 내용을 원 소스로 간주하지 않았다. 이 접근 실패만으로 다른 원문 경로까지 모두 막혔다고 판정하지 않는다.

분류: Counterexample candidate. 기호 검산·같은 저장 상태 하한 계산은 30초 제한 아래 수행했고 새 native 호출과 항성 시간 단계는 0이다. 구현 및 원 입력 결속은 `verification/def_thermal_closure_identifiability.py`와 `outputs/direct-eos-gr33/def-thermal-closure-identifiability/`에 있다. 단계 52의 코드·계획·결과는 바꾸지 않았다.

분류: Conjectural. 전체 동적 전하 목표는 계속 미완료다. 이번 비유일성 정리를 실제 항성 신호의 부재, 물리 EOS 인증, 관측 추론의 완료로 바꾸지 않는다. 다음 작업의 성공 조건은 선택한 물리 수송 모형과 적용 영역·오차가 특정되어 같은 결합 연산자에 들어가는 것이며, 추가 평균표·manifest 또는 임의 완화시간 경로의 수렴 자체가 아니다.
