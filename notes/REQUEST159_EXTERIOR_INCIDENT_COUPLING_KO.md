분류: Counterexample candidate. **저장된 실제 배경 광자의 방출 이력을 입사 scalar의 외부 연산자에 적용했다.** 원 점 추정은 두 수렴 기준을 통과하지 못했다. 별도로 등록한 해석 상계에서는 아래에 열거한 외부 항들의 합이 단계158 저장 물질 전하의 **0.714224% 이하**였다. 저장 물질 전하를 기준값으로 고정하고 선언한 진공·유한 원천·방출 조건을 만족시키면, 이 항들만으로 그 음의 부호를 지울 수 없다. 전체 물리 전하나 전체 외부 문제의 해결은 아니다.

분류: Counterexample candidate. 기존 64/128 배경 이력, 4개 방출 각도 구간, 실제 Einstein 외곽 반경 6,909,966,304.355728cm, 3.4344311179287023ms 구간, 17개 판독 시각, 기존 입사 진폭과 펄스 길이를 유지했다. 이미 수락한 물질·EOS 적분을 다시 돌리지 않았다. 방출 단계 안의 구적점은 새 진화 단계가 아니다.

## 실제 연결과 경계항

분류: Proven. `ds²=-N²c²dt²+dr²/b+r²dΩ²`, `a=N sqrt(b)`, `dx=dr/a`, `U=r δphi`, `ζ=δν−δλ`로 둔다. 직접 방출 에너지 `e=GE/c⁴`의 패킷과 내부 질량 차감을 짝지으면, 패킷보다 안쪽 외부 진공에서 다음 항등식이 성립한다. 패킷보다 바깥에서는 이 직접 복사 계량 증분이 0이다.

```text
λB = -e/(r a)
ζB = e [I(r,rp) + 1/(r a) - μp²/(rp ap)]
I(r,rp) = ∫r^rp ds/(a b s²) = 1/(r a) - 1/(rp ap)
ζunit = 2 I(r,rp) + (1-μp²)/(rp ap)
```

분류: Proven. 동일한 정적 진공 위에서 scalar 파동 연산자의 일차 변화는 다음과 같다. 매끄러운 `ζx`와 움직이는 셸의 분포 항을 함께 포함한다.

```text
S = 2ζ(Uxx - Vgeom U) + ζx(Ux-aU/r) + ζt Ut/c²
Vgeom = a a'/r
ζx,smooth = -2e/(b r²)
ζx,shell = -e(1-μp²)/(rp ap) δ(x-xp)
```

분류: Proven. 정확한 입사 primary `U=g(t+x/c)`에서는 첫 미분 항들을 `(∂x+∂t/c)(ζ Ux)`로 합칠 수 있다. 무한원 판독의 인과면 항들은 상쇄되며 외부 구간의 안쪽 경계에 `-∫ζ(0,t)Ux(0,t)dt`가 남는다. 나머지는 체적 적분과 이동 셸 적분이다. 저장된 기호 항등식과 독립 평탄 시공간 패킷 검사가 이 환원을 확인한다.

분류: Proven. **이 경계항은 영역을 나눈 데서 생긴 항이다.** 내부 구간의 같은 장·계량 경계값을 사용하면 내부의 반대 부호 항과 정확히 상쇄된다. 이를 별도의 물리 표면 원천으로 더하면 안 된다. 이번 단계는 실제 내부의 시간 의존 배경 연산자를 반환하거나 그 경계 접합을 적용하지 않았다.

## 별도 질문: 선택한 외부 항이 저장 전하를 지울 수 있는가

분류: Counterexample candidate. 원 실패 뒤에 별도 `bound-plan.json`을 등록했다. 질문은 점 추정의 상대 정밀도가 아니라, **지정된 외부 항 전체의 절대 크기**다. 기준은 단계158 저장 물질 전하의 1% 미만이며 원 점 추정 기준의 완화가 아니다. 선언한 양의 방출 계열은 기존 64/128 두 이력을 포함하는 누적 에너지·각도별 광도 상한으로 제한한다. 미지의 연속 항성 방출 법칙을 인증한 것은 아니다.

분류: Proven. 정적 scalar 진공의 `m≤M`, `N≥N0`, `b≥1−2M/r0`, 펄스의 정확한 총변동 2와 Bernstein 미분 상계를 사용한다. 거의 접선인 광선의 도달 지연은 `h=δlnE−δν−δlnL`로 정리하면 적분 가능한 상계가 된다. 아래 두 적분이 발산하지 않는 것이 핵심이다.

```text
∫0¹ dz/sqrt(1−z²) = π/2
∫0¹ (1−z)/(1−z²)^(3/2) dz = 1
```

분류: Counterexample candidate. 저장 이진 입력에 대한 50자리 바깥 방향 구간 산술로 다음 상계를 얻었다. 유한 Born 원천은 저장한 이진 Legendre 역행렬 계수와 시간 선형 보간으로 정의한 연속 원천이다. 그 표현 자체의 오차, 노드 구적과 실제 유체에 공급한 장 보간 오차는 이 구간에 포함되지 않는다. 기존 potential 계수 상계를 재사용하되 새 원천의 장 크기는 다시 계산했다.

분류: Counterexample candidate. 독립 감사는 scalar 연산자 변화, null 광선 변화, 펄스 미분 상계, 거의 접선인 광선 적분과 입력 SHA를 검사했다. 독립 평탄 이동 셸에서 직접 분포 원천과 환원된 적분의 최대 상대차는 3.282e-14다. 곡선 광선 불변량 오차는 1.244e-14, 광학 좌표 대조는 1.649e-14, 독립 반경 원시함수 대조는 3.230e-14 이하다. 이 검사는 전체 물리 계의 인증이 아니다.
