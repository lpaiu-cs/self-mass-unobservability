# 단계162 — 혼합 GR 장을 실제 광자·자유 물질에 반환

분류: Counterexample candidate. **단계161의 내부 혼합 원천이 만든 scalar·질량 제약·lapse를 실제 광자 및 자유 물질 방정식에 반환했고, 두 번의 상호 교환 뒤 사전 선언한 유한 결합 기준을 통과했다.** 실제 signed 방출을 고정 연산자의 무한원 판독에 연결한 추가 전하 보정은 `−2.0088782264382117e-79`다. 이번 실제 수송 반환으로 기존 선택 성분의 음의 전하는 유지된다. 조건부 loophole progress이며 전체 물리 전하·EOS·관측 폐쇄는 미완료다.

## 반환하는 성분과 경계

분류: Imported from prior work. 원천과 canonical 응력의 중복 제거는 [단계161](REQUEST161_RECIPROCAL_MIXED_GR_KO.md)을 따른다. 배경·입사 계열의 저장 원천과 초기 파동 연산자를 재사용한다. 원 531셀, 광자 8각도·152주파수, 3.4344311179287023ms 구간 및 64/128 진화 경로를 유지했다.

분류: Counterexample candidate. 이번 입력은 **내부 compact 혼합 원천에 대한 장 성분**이다. 이 성분의 외부에서는 기존 초기 진공 연산자의 leading outgoing scalar와 homogeneous 질량 제약을 연결하고 무한대에서 lapse를 고정했다. 추가적인 외부 혼합 원천은 이 성분과 별도로 남아 있다. 바깥 lapse를 0으로 고정하지 않았다.

분류: Proven. 기존 표기에서 `a=N√b`, `ζ=ν−λ`, `f=U/r`이며 보조 제약량은 `J`다. 초기 진공의 homogeneous 성분 `C=J(r0)N0/√b0`와 `I=∫[r0,∞]dr/(N b^(3/2) r²)`에 대해 외부 접합값은 다음과 같다. 이 식은 이번 분리 성분의 선형 경계식이며, `C`를 물리적 혼합 ADM 질량으로 동일시하지 않는다.

```text
λ = r Φ0 f + J/(r b)
ζscalar(r0,t) = -∫[r0,∞] 2 Φ0(r) Uout(r,t)/(r b(r)) dr
ζJ(r0,t) = -C [I + 1/(r0 a0)]
ν(r0,t) = Φ0(r0) U(r0,t) + ζscalar(r0,t) - C I
```

분류: Counterexample candidate. 실제 광자 방출·도달 에너지는 수송이 생성한 signed packet에서만 읽는다. 위 보조 질량을 새 광자 에너지로 다시 더하지 않는다. 추가 외부 혼합 원천과 실제 혼합 질량 정규화까지 닫혔다고 주장하지 않는다.

분류: Proven. 원 primary pulse는 `g(y)=256 y⁴(1−y)⁴` (`0<y<1`)다. 원 공간 다항식과 구간별 선형 시간 계수 `K`의 곱 `K(t,x)g((t+x/c)/D)`는, pulse의 0차·1차 원시함수를 사용해 각 시간 구간에서 해석적으로 적분할 수 있다. 공간 계수의 차수가 `p−1`이면 해당 원시함수의 공간 차수는 최대 `p+9`다. 따라서 재구성에는 `p+10`개 값이 필요하지만, 매끄러운 부분 구간의 적분에는 `ceil((p+10)/2)`차 Gauss 규칙이면 충분하다.

분류: Counterexample candidate. 실제 원천에서 이 국소 primary trace 성분을 분리해 해석적 시간 적분으로 대체했다. 질량 제약 적분은 기존 셀 중심·원래 절점·primary 파면에서 나눴으며, 힘에 필요한 제약은 실제 물질 중심에서 평가했다. 변한 `J` 원천과 primary 장을 기존 wave/potential 연산자로 다시 전파했다. 판독 표만 고친 것이 아니다. 물리 셀·원천 시각·계수 차수는 늘리지 않았다.

분류: Counterexample candidate. 최초 정밀 경로는 저장됐지만 남은 계산의 비용 승인 기준을 넘었다. 완료한 경로를 재사용하고 같은 다항식 원시함수를 직접 평가해 남은 두 대조를 수행했다. 저장된 실제 입력의 32개 표적에서 기존 정확 적분과 상대차는 **3.634e-16 이하**였다. 부분 적분의 속도로 나머지 전체 비용을 예측한 값은 과소평가였으며, 실제 전체 실행 비용과 구분해 보존했다. 보정의 두 실행 본문 합계는 **386.883초**로 원 480초 한도 안이었다.

분류: Counterexample candidate. 보정 후 수송 입력의 최대 공간 상대차는 **1.64778e-5**, 최대 원천 시각 상대차는 **0.00137043**이다. 외부 접합식의 수치 상대차는 **5.258e-16 이하**다. 모든 원 입력 기준을 통과했다. 17/33 대조는 저장 원천 표현의 검사이며, 실제 배경의 시간 수렴이나 물리 오차를 인증하지 않는다.
