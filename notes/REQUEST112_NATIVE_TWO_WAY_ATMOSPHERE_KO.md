# 단계112 — 실제 양방향 광자·움직이는 대기 결합

분류: Counterexample candidate. **깊은 내부와 움직이는 대기가 같은 광자장을 양방향으로 주고받는 실제 진화를 수행했다.** 두 시간 경로가 원 3.4344311179 ms 구간을 완주했고 시간 비교·보존·실제 native 끝점 검사를 통과했다. 촘촘한 공간 경로는 128단계 중 108단계 뒤 저온 EOS 범위에서 멈췄다. 따라서 실제 연결은 성과이지만 전체 공간 수렴과 최종 전하는 미완료다.

## 적용한 연결

분류: Counterexample candidate. 같은 native 배경의 16개 내부 반경 셀, 152개 Killing 주파수, 8개 각도와 움직이는 대기 유체를 연결했다. 내부 마지막 체적은 실제 유체 안쪽 면인 −400 m에서 끝나도록 줄였다. 기존 native 표본점은 유지하며, 이 비중심 체적 적분의 공간 오차를 별도로 수락한 것은 아니다. 겹치는 물질 체적은 없다.

분류: Counterexample candidate. 대기의 안쪽 방향 광자를 풀어 내부 비선형 수소·열·광자 방정식의 incoming 조건으로 사용하고, 그 해의 outgoing 광자를 대기로 수송한다. 두 영역이 같은 면적과 lapse를 사용한다. 이전의 지정 Planck 가열장은 제거했다. 내부의 밀도·계량과 유체의 먼 안쪽 ghost 조건은 여전히 고정이다. 전체 항성의 기계적 되먹임을 완료한 것은 아니다.

분류: Counterexample candidate. 수소의 흡수·자발 및 유도 방출은 기체 정지계의 주파수 `E′=W(1−vμ)E∞/a`에서 평가했다. 움직이는 Thomson 산란은 양의 광자 패킷을 주파수 격자 사이에 나누며, 광자 수·에너지·운동량의 상자 밖 유출을 별도로 기록했다. 유출 에너지를 기체 열로 잘못 넣지 않는다. 같은 교환량을 반대 부호로 기체 에너지·운동량에 적용했고, bound-free 광자 생성량을 중성 수소 재고에 연결했다.

분류: Proven. 선언한 탄성 산란 사상 `Eout=Ein(1−vμin)/(1−vμout)`은 입출사 에너지를 기체 정지계에서 동일하게 만든다. 광자 및 기체에 반대 부호의 교환량을 넣으면 내부 교환은 총수지에서 상쇄된다. 또한 선형 수송에서 큰 운반 성분과 작은 물질 발생 성분을 나누어 저장하고 합치는 것은 동일 방정식의 대수적 재표현이다.

분류: Counterexample candidate. 위 두 성분의 합만 물리적 광자장이다. 작은 물질 발생 성분을 따로 저장하여 큰 복사 배경끼리 뺄 때 생기는 소거를 줄였다. 대기 에너지 오차는 훨씬 큰 내부 응답으로 나누지 않고 대기 자체 응답으로 판정했다. 이산 보존은 연속 수송·미시적 역반응의 완전한 인증과 다르다.

## 보존한 실패와 수정

분류: Counterexample candidate. 저장된 918개 native 제약 상태를 다시 풀지 않고 복원해 스펙트럼 준위 정보를 얻었다. 첫 보간은 affinity 지수와 준위 Boltzmann 항을 따로 보간해 상쇄를 깨뜨렸고, 최대 가중 오차가 6.199로 실패했다. 상쇄하는 항을 원 노드에서 로그로 먼저 합친 뒤 느린 계수만 보간하도록 수정했다. 같은 독립 상태·문턱에서 최대 가중 오차는 `8.495e-6`으로 통과했다. 차가운 미량 꼬리의 점별 상대 차이는 최대 약 24.2%이므로 균일 스펙트럼 오차 보증은 아니다.

분류: Counterexample candidate. 첫 결합 SDIRK 시험은 대기의 짧은 광행 시간 때문에 두 번째 단계에서 음의 점유를 만들어 실패했다. 실제 방정식·격자·문턱은 유지하면서 전체 광자/내부 단계에 backward Euler를 적용했다. 기체·충돌은 국소 SSP RK2로 적분한다. 이 분할법은 형식 1차이며, 원 64/128단계 대조를 통과한 범위만 주장한다. 점유·온도·재고를 절단하지 않았다.

## 다음 직접 병목과 재사용 경계

분류: Counterexample candidate. 109번째 거시 단계의 국소 유체 적분에서 EOS 온도 역산의 양 끝 잔차가 같은 부호가 됐다. 마지막 완전 저장 상태인 104단계에서 최대 다섯 단계만 재생해 같은 지점의 실패를 재현했다. 이 재생의 진단기 자체가 존재하지 않는 closure 항목을 읽어 저장에 실패한 기록도 보존했다. 이어 실패 끝점의 한 반 단계만 진단하여 416번 셀, 원 표면 바깥 250.78125 m에서 실패 상태를 저장했다. 실패 끝점 광자장은 부분 갱신됐을 수 있으므로 이 두 번째 진단을 수락한 재시작 경로로 세지 않는다.

분류: Counterexample candidate. 해당 보존 에너지는 기존 240–20000 K 표의 하한보다 낮은 온도를 요구한다. 240 K 실제 native 평가도 같은 방향의 양의 에너지 잔차를 확인했다. 표의 240/310 K 기울기로 추정한 약 170.3 K는 **선형 외삽 진단**이며 native 근이 아니다. 실제 160 K native 평가는 상태125, 즉 내부 시험 질량밀도 underflow로 실패했다. 기존 전자변수 역산으로 상태125를 처리하는 작은 수정도 같은 오류로 실패했다. 해당 공유 코드 수정은 되돌렸고 당시 소스·실패를 보존했다. 실제 저온 근을 구했다고 보고하지 않는다.

분류: Counterexample candidate. 재시작에는 마지막 완전 스냅샷 104단계의 `U/I/bulk_I/theta/eta`를 사용해야 한다. 실패 끝점은 국소 갱신 중이므로 그대로 재시작하면 안 된다. 완전 스냅샷에 누적 ledger가 함께 저장되지는 않았으므로, 이후 구간의 별도 수지 기준점과 이전 이력의 연결을 명시해야 한다. 원 누적 보존을 복구했다고 가정하지 않는다.

## 계산 비용과 보존

첫 양의 한 단계 시험 0.809초에서 생산 예상은 362.48초, 여유 상한 543.72초로 등록했다. fine 비용은 거친 경로의 두 배라는 가정이었고 후반 비용은 미측정으로 표시했다. 실제 생산은 **599.05초 / 600초 상한**, 경로별로 109.01초·123.79초·361.89초였다. 시간 초과가 아니라 위 EOS 역산 실패로 종료됐다. 짧은 초반 시험이 후반 fine 비용을 충분히 대표하지 못했다는 한계도 남긴다.

저장 상태 재생은 21.78초, 끝점 한 반 단계 진단은 3.28초, 전자변수 우회 시도는 0.93초였다. WSL 시작·파일 해시 시간은 이 수치에 포함되지 않는다. 원 세 경로 외에 전체 유체 경로를 추가하지 않았다. CPU 한 스레드 설정이며 관측한 생산 중 RSS는 약 531 MiB였다. 이것을 측정된 최대 메모리로 부르지 않는다.

native 호출은 정확히 기록한 부분 992회와 두 누락 구간의 상한 100·16회를 합쳐 **최대 1108회**로 관리한다. 최초 1100회 범위의 호출 상한은 1097회이며, 마지막 EOS 역산 시도는 별도로 40회/20초를 사전 재평가한 뒤 11회를 사용했다. 누락 호출 수를 측정값으로 꾸미지 않는다. 자세한 집계는 `resource-accounting.json`에 둔다.

단계 전 checkpoint는 `2029784c4`다. 원 분할·보간·음의 광자·fine 실패와 실행 소스는 보존했다. 여섯 연구 문서·증거 목록·OSK 상세와 scope에는 전체 공간 수렴·최종 전하 미완료를 유지한다.
