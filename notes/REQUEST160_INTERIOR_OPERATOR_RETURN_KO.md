# 단계160 — 내부 배경 연산자의 실제 반환과 경계 접합

분류: Counterexample candidate. **저장된 최신 배경 계량을 실제 입사 primary의 내부 scalar 전파식에 적용하고 무한원 전하 기여를 읽었다.** 이전 단계에서 식으로만 확인한 내부·외부 경계 상쇄도 실제 배경 값으로 연결했다. 선택한 내부 보정은 저장 물질 전하의 약 **0.01109%**이며 같은 음의 방향이다. 그 부문에서 빠진 유한 Born 입력과 추가 정적 potential 항은 별도 조건부 상계로 **0.1780% 이하**다. 전체 상호 GR 제약·물질 반환·물리 전하의 완료는 아니다.

분류: Counterexample candidate. 배경은 단계154가 선언한 현재 원천 합성을 사용했다. 단계152의 retained/native/운동 원천에 단계152 GR 반환과 단계153 native 음향 반환을 각각 한 번 더했다. 새로 합성한 배경장만 계산했으며 EOS나 유체 이력을 다시 적분하지 않았다. 초기 GR 계수, 기존 531셀·33개 원천 시각·4/8차 공간 표현·3.4344311179287023ms 구간을 유지했다. 17개 시각의 부분집합은 원천 보간 대조다. 상위 물질 진화의 독립 64/128 수렴을 새로 증명한 것은 아니다.

## 무엇을 실제로 적용했는가

분류: Proven. `U=r δphi`, `a=N sqrt(b)`, `dx=dr/a`, `ζ=δν−δλ`로 두면 계량 변화가 scalar 연산자에 주는 원천은 다음과 같다. 여기서 아래 첨자 B는 저장된 배경의 증분이며, 초기 정적 연산자 주위의 선택한 일차 계량 변화를 뜻한다.

```text
S_B[U] = 2 ζB Uxx + a ζB,r Ux
         + (-2 ζB Vgeom - a² ζB,r/r) U + ζB,t Ut/c²
Vgeom = N² [2m/r³ + 4π A⁴(P-E)]
```

분류: Proven. 초기의 순간 균형 polar 제약과 canonical 물질 응답에서 큰 미분 항을 먼저 소거하면 아래 식을 얻는다. `eF−pF`는 실제 저장 metric stress 원천이다. 배경의 큰 수를 더한 뒤 빼서 작은 증분을 구하지 않는다.

```text
ζB,r = [2/(r b) + 4π r A⁴/b (3Pg−Eg−Kg−Er+R4)] λB
       + 4π r A⁴/b [α(7Pg−Eg−3Kg) fB − (eF−pF)]
λB = r Φ fB + J/(r b)
```

분류: Proven. 정확한 기존 입사 primary `U=g(t+x/c)`에 대해서는 미분 원천이 `(∂x+∂t/c)(ζB Ux)`다. 이를 인과 영역에서 적분하면 내부의 바깥 경계에 `+∫ζB Ux dt`가 생기며 외부의 안쪽 경계에서는 반대 부호다. 남는 내부 체적 밀도는 `(-2ζB Vgeom−a²ζB,r/r)U`다. 두 경계의 장·계량 값이 같아야 상쇄되며, 이 항을 새 물리 표면 원천으로 세지 않는다.

분류: Counterexample candidate. 내부 trace는 내부 lapse와 질량 제약으로 계산했다. 외부 trace는 실제 방출 광자, 생성된 outgoing scalar의 기존 leading 연속, 별도로 측정한 ADM 원천 잔차에서 다시 구성했다. 원 128개 방출 구간과 단계151·152·153의 실제 signed SDIRK 패킷을 사용했다. 계산된 두 경계 기여의 최대 상대차는 2.166e-16 이하다. 단순히 내부 결과에 마이너스를 붙인 가상 외부 자료를 비교한 것이 아니다. 완전한 시간 의존 외부 scalar 문제는 여전히 남는다.

분류: Counterexample candidate. 입사 primary는 17개나 33개 파형 표본으로 바꾸지 않았다. 실제 C3 펄스와 저장 배경의 시간 구간, 입사면·나가는 판독면을 교차점에서 잘랐다. 원 공간 다항식과 8차 펄스의 곱에 필요한 Gauss 점을 사용했으며, 물리 격자나 원천의 공간 차수를 높이지 않았다.

## 빠진 Born·potential 항의 조건부 제한

분류: Counterexample candidate. 점 추정과 별도로 감사 계획을 등록했다. 같은 초기 연산자와 유한 연속 원천을 조건으로, 기존 첫 Born 장이 새 내부 계량과 만드는 반응 및 이 원천의 추가 정적 potential 반환을 제한했다. 계수의 전역 수축 상계는 재사용했지만 **새 내부 원천의 크기는 다시 계산했다.** 저장 이진 노드·역 Legendre 계수에 대한 50자리 바깥 방향 구간 산술이며, 실제 입력 장의 표현 오차나 EOS 인증은 아니다.

분류: Counterexample candidate. 단계159의 0.7143% 외부 상계와 이번 수치를 무조건 더해 전체 물리 오차라고 부르지 않는다. 경계항은 접합에서 상쇄되는 중복 영역 항이며, 두 상계가 포함하는 항과 전제가 다르다. 원 외부 점 추정의 배경 이력·셸 구적 실패, 단계157의 상위 GR 입력·전체 상태 변화 실패도 유지한다.
