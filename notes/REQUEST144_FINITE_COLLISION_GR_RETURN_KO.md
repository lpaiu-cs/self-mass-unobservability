# 단계144 — 유한 충돌 교정의 실제 광자·물질·GR 적용

분류: Counterexample candidate. **17개 시점의 충돌 원천을 완성하고, 실제 광자 적분 → 총 전달량의 유한 물질 진화 → 압력·응력 → GR 판독까지 완료했다.** 같은 저장 계수 모형의 합산 질량 정규화 판독은 +1.0211342924230259e-27로 양수를 유지했다. 단계143에서 남았던 실제 적용 병목은 해소됐으며, 전체 물리 오차와 최종 관측량의 인증은 아직 아니다.

## 실제 적용한 범위

분류: Counterexample candidate. 이미 계산한 9개 시점은 재사용하고 7, 9–15번의 8개 시점만 추가했다. 원 531셀·8각도·152주파수·3.434431ms와 fine 배경128을 유지했다. 저장 tangent와 기준 물질 운동을 고정한 광자/E/H 방정식에 충돌 잔여를 한 번 넣어 64/128 경로를 적분했다. 성공한 4/8단계 접두부를 이어서 사용했다.

분류: Proven. 같은 고정 선형 연산자의 두 응답은 더할 수 있다. 분류: Counterexample candidate. 새 증분을 저장된 단계142 광자 응답에 합산하고, 절댓값 L1 읽기는 합산 각도 분포에서 다시 계산했다. 원 광자 경로를 다시 적분하지 않았다. 그 **합산 전달량**으로 유한 진폭 물질 방정식을 새로 풀었으며, 같은 압력·반경 응력·trace를 실제 GR 연산자에 적용했다. 물질 반응까지 선형 합산한 것은 아니다.

분류: Counterexample candidate. 이 GR 읽기는 저장된 초기 기하에서 compact 원천의 첫 변분을 한 외부 관측점으로 전달하고 `-u/M_cm`으로 정규화한 `free_scalar`다. 전체 외부장·퍼텐셜·비선형 GR을 포함한 최종 전하로 바꾸어 부르지 않는다.

## 남은 과학적 경계

분류: Counterexample candidate. 이번에 계산한 잔여는 **같은 보간 EOS의 실제 유한 충돌 차분과 저장 tangent 사이의 차이**다. native 단면적의 binary64 호출은 유지된다. microscopic EOS의 연속 미분 오차, 갱신된 궤적 전체의 충돌 나머지, 반복 결합의 균일 증폭 및 시간 사이의 오차를 인증하지 않는다. 반 진폭 비교를 엄밀한 2차 오차 정리로 세지 않는다.

분류: Conjectural. 다음은 이번 합산 원천을 기준으로 EOS/미분·결합 오차와 외부·삭제 물질·퍼텐셜의 불확실성을 주 전하의 정확도 요구에 연결하는 일이다. 같은 작은 교정을 한 번 더 반복할 근거는 현재 결과에서 나오지 않는다. 비선형 GR, 같은 재고의 정적 비교·미분 nuisance 제거 및 관측 연결의 전체 완료 조건은 유지한다.

분류: Counterexample candidate. `finite_collision_remainder_applied_to_photons_material_and_GR`와 `residual_below_temporal_comparison_scale`는 true다. `uniform_EOS_derivative_bound`, `uniform_nonlinear_remainder_bound`, `coupled_fixed_point_verified`, `exterior_floor_feedback_closed`, `full_nonlinear_GR`, `final_charge_solved`, `full_goal_complete`는 false다. 이번 결과는 실제 연결을 완료한 loophole progress다.

보관 기록: 독립 검산 출력의 절대·상대 경로 비교가 달라 최초에는 상위 `applied`에 기록됐다. 검산 결과 세 파일을 `completed-return`으로 보관하고 단계143의 symbolic 기록을 원 바이트로 복원했다. 실행된 생산자는 `third-producer.py`로 고정했다. 현재 생산자의 수정은 보관 경로 비교의 정규화 한 줄뿐이며 물리 계산은 다시 실행하지 않았다.
