## 적용한 방정식과 중복 방지

분류: Counterexample candidate. 기존 531셀, 17개 저장 시점, 8각도·152주파수, 64/128 시간 경로와 3.4344311179287023ms를 유지했다. 각 시간 경로의 실제 물질 보존 상태 `Qm`과 광자 `x0`에서 유한 충돌식을 평가했다. 기존 native 배경 원천은 한 번만 유지하고, `R=Ctable(Qb+Qm,Ib+x0)-Ctable(Qb,Ib)-L0(x0,g0)`를 추가 응답의 원천으로 썼다. 보정 연산자는 기존 tangent이며 native 미분 인증으로 바꾸지 않는다.

분류: Proven. 기준 물질 에너지/H가 `gm'=L0+D+H`이고 유한 충돌 변경이 R이면, 기준식을 뺀 추가식에서 고정 native 원천 D와 알려진 기계 수송 H는 상쇄된다. 따라서 이 둘을 새 보정에 다시 더하면 중복이다. 기호 검산은 이 원천 분리에만 적용되며 반복의 수축을 증명하지 않는다.

분류: Counterexample candidate. 새 방사 물질 이력은 실제 `gm`에 추가 충돌 응답을 더해 기록했고, 별도의 `collision_transfer`에는 충돌 전달만 합쳤다. 이 전달과 기존 native 압력 힘으로 자유 물질을 다시 진화했다. 독립 검산은 실제 물질 기준, 전달 분리, 광자 선형 합성, 수락한 angular stage와 외부 에너지 유량, GR 원천 항등식을 확인했다. GR 압력은 새 유한 물질에서 직접 읽는다. photon 파일의 tangent 압력 moment6은 진단값이며 GR 압력의 근거로 쓰지 않는다.

분류: Counterexample candidate. 최대 셀별 실제 상대 상태 변화는 fine 경로에서 약`4.91e-4`다. 전하 증분이 작다는 사실을 모든 셀의 변화가 같은 비율로 작다는 주장으로 확대하지 않는다. 이전 infinitesimal 작은 상태 기준을 통과한 것으로 세지 않고 실제 유한 진폭 물질 방정식을 사용했다.

## 정밀도와 계산 범위

분류: Counterexample candidate. 기존 저온/고온 분기와 현재 저밀도 EOS·스펙트럼 분기까지 같은 spline의 longdouble 평가를 적용했다. 보존 상태의 복원과 구성식 차이를 긴 정밀도로 계산했으며 native 광이온화 단면적 ABI는 binary64다. 정확히 같은 영 입력은 정확한 영 차이를 내고, 산란수 투영은 에너지·운동량을 바꾸지 않는 두 주파수 보정으로 제한했다. 반 진폭은 대표 시점 진단에만 썼고 실제 결과의 진폭을 줄이지 않았다.

분류: Counterexample candidate. 유한 추가 충돌항의 최대 크기는 기존 선형 충돌 응답의 `1.90213087e-07`, 16eps 산술 지표는 그 선형 응답의 최대 `1.77010762e-08`다. 산술 지표를 작은 추가항 자체로 나눈 최대 비는 `0.0942477567`다. 등록한 0.2% 기준은 선형 응답을 분모로 하므로, 통과를 작은 추가항 자체의 0.2% 정확도로 해석하지 않는다. 이 지표는 균일 EOS·원시복원·단면적 오차의 상계도 아니다.
