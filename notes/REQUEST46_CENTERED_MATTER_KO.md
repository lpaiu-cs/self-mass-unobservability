# Phase46 — 비영 내부 결합의 시간 수렴 통과

분류: Counterexample candidate. **고정 벽 내부의 비영 물질·열·조성·scalar·계량 결합에서 온도·속도·scalar 읽기가 모두 원 시간 수렴 기준을 통과했다.** 단계 45의 지수 scalar 전파를 유지하고 물질의 유속·힘과 조성 이류를 시간 중심으로 바꿨다. 실제 항성의 자유 표면·동적 외부·궤도 전하는 아직 연결되지 않았다.

## 무엇을 수정했는가

분류: Imported from prior work. 단계 44는 세 읽기 모두 시간 기준 미달이었다. 단계 45에서 빠른 scalar 전파와 경계 에너지 공급을 일관되게 결합하자 scalar만 통과했고, 온도·속도는 여전히 미달했다. 두 실패 이력·소스·계획·수락 기준은 보존한다.

분류: Proven. 보존량 `U`와 공유 면 유속 `F`에 대해 현재 갱신은

`U1−U0+(h/2) div(F1+F0)=0`

이다. 모든 내부 면이 두 인접 셀에 반대 부호로 들어가므로 합한 재고에서는 내부 면 항이 상쇄된다. 바리온·핵종의 유속을 서로 다르게 평균하지 않는다.

분류: Proven. 조성의 implicit 갱신은 먼저 `B_eff=B0−(h/2) div(F_B0)`, `(BX)_eff=(BX)0−(h/2) div(F_BX0)`를 만들고, 남은 implicit 반 단계에 같은 native 이류 방정식을 푸는 형태로 구현했다. 이는 위 trapezoidal 보존식의 대수적 재배열이다. 재고의 양성 조건을 검사하며 실패하면 계산을 거부한다.

분류: Counterexample candidate. 물질 에너지 유속과 운동량 유속·힘도 양 끝 값을 평균한다. 물질 에너지의 metric work와 reciprocal scalar work는 원 질량 제약의 이산 미분을 유지한다. 따라서 단계 45의 경계 에너지 공급과 결합된 질량-일 항등식이 그대로 적용된다. Newton 행렬은 새 조성 갱신을 반영하지만, 최종 판정에는 실제 native 잔차를 사용한다.

분류: Counterexample candidate. **두 강직한 열유속 법칙은 backward Euler로 유지했다.** 물질 수송의 시간 중심화가 전체 방법의 보편적인 2차 정확도 정리라는 주장은 하지 않는다. 조성·열·metric을 동결하거나 결합 잔차를 물질 열로 보정하지 않았다.

## 같은 실험과 기준

분류: Counterexample candidate. 초기 상태, `phi_infinity=0.001`, 표면의 양·음·무구동 `sin^8` 파형, 진폭 `1e-5`, 읽기와 수락 기준은 단계 44–45와 같다. `R/c=0.2295566003초`까지 nominal 12/24/48 격자의 앞 6/12/24단계를 실행해 총 126단계다. 새 방법의 예비 두 단계만 재사용했다.

분류: Counterexample candidate. 온도는 Jordan log 온도, 속도는 `v/c`, scalar는 내부장의 바리온 가중 RMS다. odd 응답은 `(plus−minus)/2`, even 성분은 `(plus+minus)/2−undriven`이다. 원 수락 기준은 시간 차수 `>=0.7`, 마지막 격자 차이/응답 `<=0.2`, 응답/마지막 차이 `>=5`다. 기준을 완화하지 않았다.

| 읽기 | 가장 촘촘한 odd RMS | 시간 차수 | 응답/마지막 차이 | 판정 |
|---|---:|---:|---:|---|
| Jordan log 온도 | `1.31353e-7` | `1.72446` | `6.78333` | 통과 |
| 방사 속도/c | `6.13652e-9` | `1.92589` | `13.72977` | 통과 |
| 내부 scalar | `1.92275e-6` | `2.07680` | `3.77986e8` | 통과 |

분류: Counterexample candidate. 표는 지정된 24셀 유한 격자의 시간 비교 결과다. 엄밀한 연속 오차 상계, 공간 수렴 또는 미세한 물질 매개 scalar 전하의 검출은 아니다. 큰 직접 파동을 포함하는 scalar 읽기의 통과를 복사 전하의 통과로 바꾸어 쓰지 않는다.

## 실제 방정식과 보존 재생

분류: Counterexample candidate. 126개 저장 상태와 아홉 끝점을 검사했다. 새 EOS 호출 없이 끝점의 실제 31개 물질 방정식과 지수 scalar·metric 연산자를 재평가했고, 재생 잔차 차이는 0이었다. 최대 native 정규화 잔차는 `0.756023`이다.

| 검사 | 최대값 | 기준 |
|---|---:|---:|
| 질량-경계 일 항등식 상대 결함 | `1.026e-15` | `<2e-15` |
| 총 바리온 상대 결함 | `1.383e-16` | `<1e-9` |
| 핵종 재고 상대 결함 | `1.350e-16` | `<1e-9` |
| 표본 열 특성속도/c | `0.180998` | `<1` |
| 표본 특성속도 허수부 | `0` | `<1e-10` |
| 선언한 scalar 표면 파형의 차이 | `1.589e-21` | `<2e-19` |

분류: Counterexample candidate. 특이·부정부호 reference Hamiltonian, 반 주기 및 이산 일 대조도 함께 재검사했다. 이 검사는 선언한 구현의 수지를 다루며 물리적 EOS 또는 대기 인증을 대신하지 않는다.

## 비용과 재현

분류: Counterexample candidate. native 호출은 21,736회다. 예비 두 단계의 내부 타이머는 8.56초, 본 비교는 436.32초였다. `/usr/bin/time`은 본 비교의 wall을 6분 58.22초, RSS 최대를 130,976 KiB로 기록했다. 600초 hard timeout을 지켰고, 기존 실패 경로의 세분화나 새 장기 궤도 적분은 실행하지 않았다. 저장 해 감사는 3.54초, 새 native 호출·물질 단계 0이었다.

분류: Counterexample candidate. 코드는 `verification/def_centered_matter.py`다. 단계 45의 실행·감사 함수를 별도 namespace에 재사용하고 새 잔차·조성 반복을 연결했으며, 원 모듈은 바꾸지 않는다. 출력은 `outputs/direct-eos-gr33/def-centered-matter/`, 실행 전 checkpoint는 `c840ee93`다. `pilot`, `prepare`, `run`, `audit` 작업과 고정된 계획·입력 SHA를 보존했다. 완료된 출력에 대한 재실행은 거부한다.

## 전체 목표에서 남은 직접 병목

분류: Conjectural. 이번 성과는 비영 내부 결합의 **수치 시간 병목**을 해소한 것이다. 원 coarse Cauchy 배경의 압력 불균형과 열수송을 물리 항성의 정상성으로 인정하지 않는다. 저장된 실제 분자 GR 구조와 같은 재고·EOS를 재사용해 비영 scalar 배경과 물질 표면을 정당화하고, 그 내부 해를 단계 43의 동적 외부에 연결해야 한다.

분류: Conjectural. 실제 선언 구동의 주기는 약 15,666초로 이번 빠른 펄스와 다르다. 이 펄스의 진폭·시간을 단순 외삽하지 않는다. 실제 구동에서는 정규화 응답이나 상계를 먼저 구해, 선언한 `1e-9` 전하 잔여 목표에 못 미치는 것이 보증되면 장기 궤도를 실행하지 않고 조건부 no-go로 닫는 기존 규칙을 유지한다. [전체 완료 장부](../docs/dynamic-charge-completion.md)의 자유 표면·동적 전하·정적 비교 제거·오차·관측 요구사항은 아직 미완료다.
