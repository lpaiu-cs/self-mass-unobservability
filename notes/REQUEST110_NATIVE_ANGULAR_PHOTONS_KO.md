# 단계110 — 각도별 광자 진화와 남은 내부 시간 오차

분류: Counterexample candidate. **깊은 내부의 광자를 각도별 비음수 분포로 실제 진화시켜, 이전 P1 재구성의 모멘트 문제를 수정했다.** 같은 셀의 분포에서 평균·유속·압력을 계산한다. 실제 native 수소·열과 함께 3.434ms를 완주했다. 표면 방출 스펙트럼의 시간·각도 대조는 통과했지만 **전체 내부 trace의 시간 차이 4.89%는 원 2% 기준에 미달**한다. 전체 광자·물질 해나 최종 전하를 수락하지 않았다.

## 실제 변경과 유지한 조건

분류: Counterexample candidate. 단계109의 실제 16개 반경 셀·152개 주파수·저장 계량과 native EOS를 재사용했다. P1 압력 폐쇄 대신 8/16개 각도 구간의 광자 점유를 직접 수송했다. 주파수는 Killing 에너지로 표시했고, 반경·각도 이류는 같은 보존 측도를 사용한다. 같은 EOS의 수소 흡수·자발/유도 방출과 정규화한 Thomson 각도 산란을 연결했다. 밀도·계량 고정, 다른 종의 현지 초기 재고 고정, 열역학 상호성 역반응이라는 조건은 남는다.

분류: Counterexample candidate. 초기 Planck 평균·저장 회색 유속·압력 모멘트는 유지했다. 그 세 모멘트만으로 고차 각도 분포는 정해지지 않으므로, 선언한 비음수 반구 함수로 보충했다. 유속 비가 1/2 이하면 두 상수 반구, 조금 더 크면 같은 세 모멘트를 갖는 양의 이차 outgoing 반구를 사용했다. 바깥쪽 incoming 분포는 진공이며, 안쪽 incoming 분포는 실제 저장 배경에 고정했다. 이 추가 각도 조건을 유일한 실제 항성 분포로 간주하지 않는다.

분류: Proven. `r²B/a³ dr dμ`를 측도로 쓰면 반경·각도 수송은 보존형이 되며, 동일 면적 차이로 이산화한 두 발산은 상수 점유에서 상쇄한다. 비음수 각도 분포는 `J≥0`, `H²≤JK`, `K≤J`를 만족한다. `P₂`로 표현한 Thomson 각도 커널은 비음수이고 정규화된다. 이는 선언한 연산자와 모멘트에 관한 명제이며 연속 반경·주파수 수렴 인증은 아니다.

## 공통 native 제약의 근본 오류 수정

분류: Counterexample candidate. 낮은 중성 수소를 평가할 때, 보존 대상 H₂ 재고가 `3.7733433e-12`인데 현재 값은 `3.4059990e-20`으로 떨어졌다. 공통 제약 함수는 **현재 재고가 `1e-18`보다 클 때만** 복원했다. 그래서 목표 재고가 남아 있어도 사라진 분자를 갱신 대상에서 제외했고, H⁺ 초과 `3.331e-12` 때문에 전체 점유 문턱을 실패했다. 전자 초기 추정값을 바꿔도 같은 실패가 재현됐다.

분류: Counterexample candidate. 공통 소유 함수 `def_native_ion_closure.Ions.constrain`에서 현재 **또는 목표** 재고가 문턱을 넘으면 갱신하도록 수정했다. 모든 호출 경로를 확인했으며 고정 재고와 수소 반응 경로가 이 함수를 공유한다. 원 `1e-12` 허용 오차와 16회 반복 한도는 바꾸지 않았다. 정확한 실패 상태의 전체 점유 오차는 `1.1390e-14`, H₂ 상대 오차는 `3.2614e-12`로 복구됐다. 기존 정상 비평형 한 상태의 21개 EOS 출력은 수정 전후 동일했다. 이 제한된 대조를 모든 상태의 인증으로 확대하지 않는다.

## 입력 범위와 시간법의 실패 보존

분류: Counterexample candidate. 첫 각도 진화는 중성 수소가 기존 하한인 초기 재고의 25% 아래로 내려가 5단계에서 멈췄다. 위 제약 오류를 고친 뒤 낮은 재고의 같은 native 상태 48개만 추가했다. 다음 계산은 깊이 378.125km 셀에서 약 18058.5K였던 기체가 19076.8K까지 가열되고 다음 시도가 기존 `ΔlogT=0.06` 상한에 걸려 16단계에서 멈췄다. 두 실패를 보존했다.

분류: Counterexample candidate. 이 관측된 입력 부족을 해결하려고, 기존 데이터를 유지하고 `ΔlogT=0.12, 0.18`의 native 상태 64개만 추가했다. 정확한 이상기체 온도 항과 광자 Boltzmann 인자는 직접 계산하고 나머지는 구간별 보간했다. 독립 native 대조의 최대 반응률 차이는 `7.730e-6`으로 원 `0.002` 기준 이내였다. **이는 그 입력 상태를 계산 가능하게 만든 것이며, 거친 반경 수송이 예측한 가열을 실제 항성 가열로 검증한 것은 아니다.** 반경·주파수·기간을 늘리지 않았다.

분류: Counterexample candidate. 64단계 경로에서 작은 광자 차이 `J_new−J_old`의 소거 때문에 Newton 잔차가 내부 문턱 바로 위에서 멈춘 실패도 보존했다. 동일한 순 교환량을 직접 계산하는 대수식으로 바꿔 허용 오차를 유지했다. 이후 세 경로는 완주했지만 1차 분할의 시간 대조는 trace `11.218%`, 표면 스펙트럼 `8.464%`로 실패했다.

분류: Counterexample candidate. 격자를 늘리는 대신 양의 지수 수송·보존 지수 중점 반응·대칭 분할을 같은 64/128 시간 경로에 적용했다. 내부 반응의 수용 가능한 상태를 얻기 위한 국소 분할 상한도 먼저 정했으나 실제로는 추가 국소 분할을 쓰지 않았다. 시간 차이는 감소했지만 전체 trace는 여전히 실패한다. 명목상 대칭 시간법이 강하게 결합된 실제 문제에서 기대 차수를 달성했다고 주장하지 않는다.

## 다음 직접 작업

분류: Conjectural. 먼저 광자 수송과 물질 반응을 같은 시간식에서 풀어, 강한 결합을 연산자 분할로 처리하는 오차를 줄여야 한다. 기존 native 표·각도 수송·Jacobian 구조·저장 실패 상태를 재사용한다. 256단계 같은 추가 경로를 자동 실행하거나 같은 표면 대조를 반복하지 않는다. 정확한 실패 원인이 분할 하나뿐이라는 증명은 아직 없으므로, 비분할 결과로 판별해야 한다.

분류: Counterexample candidate. 이산 각도 분포의 모멘트 문제와 공통 미량 분자 제약 오류는 수정했다. 전체 시간·반경·주파수 수렴, 움직이는 대기와의 실제 공유 광자 유속, 누락 화학/광학 채널, 전체 GR/scalar 되먹임·질량 정규화·최종 전하는 미완료다. 이번 결과는 **loophole progress**, 보존·양수성 식은 **theorem progress**다. 전체 목표는 active다.

## 비용과 재현

기록된 추가 native 평가는 낮은 재고 395회, 높은 온도 443회, 진단·회귀·실제 상태 감사 77회로 **915회**다. 첫 낮은 재고 계산은 제약 오류로 종료되면서 부분 상태와 정확한 호출 수를 저장하지 못했다. 그 계산의 400회 상한을 별도로 보존하므로 전체 호출 수는 정확한 숫자 대신 **최대 1315회**로만 말할 수 있다. 이후 부분 실패 저장을 추가했다.

모든 실제 시간 경로의 solver 실측 합은 약 20초이며, native 지원 범위 보충 두 작업은 약 15.14초다. 하네스·WSL 시작, 진단·저장·감사 비용은 이 solver 합에 포함하지 않는다. 처음 정한 시간 진화 120초 상한 안에서 끝났고, 새 장기 전체 항성 계산이나 실행 중인 작업은 없다. 마지막 편집은 중첩 실행 함수가 세부 시간 상한을 덮어쓰지 않도록 한 실행 예산 전달 수정이며, 수치 방정식·기준은 바꾸지 않았다. 실행 당시 소스는 별도 보존했다.
