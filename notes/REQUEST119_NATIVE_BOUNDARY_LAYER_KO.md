# 단계119 — native 내부 경계층의 실제 공간 세분

분류: Counterexample candidate. 단계118의 마지막 내부 계산점과 깊이400m 공유 면 사이 거리는33,975m였다. 이 큰 간격의 열·밀도·중성수소·속도 변화량을 면에 일정하게 재구성하는 근사를 실제 native 셀로 대체했다. 원16개 내부 셀 중 처음15개를 유지하고 마지막 한 셀을 네 개로 나누어 총19개로 만들었다. 새 내부 면은 깊이4000/2000/1000m이며, 공유 면은 원400m다. 실제 계산점은 깊이36,375/3000/1500/700m이고 최근접 점–면 거리는300m다.

분류: Counterexample candidate. 새 네 위치에서 각자의 실제 저장 밀도·온도·초기 ionic 재고로 native EOS와 비선형 수소·복사 계수를 계산했다. 기존15개 위치의 기하·초기 thermodynamics·thermal/rate 표·밀도 및 주파수 미분을 재사용한다. 단순히 기존 마지막 셀의 EOS를 여러 셀에 복사하거나 점의 이름만 바꾸지 않는다. 처음15개의 실제 입력은 비트 단위로 유지한다.

분류: Counterexample candidate. 새 native 입력은273호출·7.00s였고, 독립 온도/중성수소 상태의 구성 관계 상대 오차는 최대 `2.226e-11`, 복사 계수는 `1.009e-6`, 초기 열역학 미분 대조는 `1.722e-9`였다. 모두 원 `0.002` 기준 안이다. 이 유한 상태 대조는 연속 EOS·미분의 전역 보증이 아니다.

분류: Counterexample candidate. 실제 진화에는 단계118에서 수정한 내부 중앙 유속, 공유 HLL 물질 유속, 양방향 각도·주파수 광자 수송과 native 열·수소 교환을 그대로 적용한다. 비수소 재고·밀도 구성 관계의 일차 근사와 고정 계량도 그대로다. 기존 대기512셀·152주파수·8각도·3.434ms를 유지하며, 이미 완료한16셀 경로는 다시 실행하지 않는다.

분류: Proven. 세분하면서 추가한 내부 면의 공통 유속은 인접 체적의 합에서 반대 부호로 소거된다. 원 두 외부 면은 유지된다. 이 대수적 항등식은 새 셀의 native 정확도나 공간 수렴을 증명하지 않는다.

분류: Counterexample candidate. 두 예비 경로는 각2단계를 실행해2.47s/2.01s가 걸렸으며 보존·native 영역·광자 양수성 기준을 통과했다. 저장된 접두 구간을 제외한 실행 예상은203.55s,1.8배와 시작 여유를 포함하면376.39s였다. 생산은 원64/128 두 경로에 한해500s 상한을 적용했다. 이후 반경·시간·주파수·각도를 자동 확대하지 않는다.

분류: Conjectural. 이 대조는 마지막 내부 셀의 공간 오차를 겨냥한다. 나머지15개 셀의 반경 오차, 시간·공간 오차의 상호작용, 주파수/내부 각도, 일차 재고 구성 관계, 전체 중성수소 반응 원장, 초기 Einstein 제약과 완전한 동적 GR는 별도다. 국소 대조를 전체 물리 전하의 인증으로 바꾸지 않는다.


## 실제 결합 결과와 판정 범위

분류: Counterexample candidate. 새19셀64/128 경로는 모두 원 구간을 완주했다. 생산은 합계333.10s로500s 상한 안이었다. 실제 native 끝점 압력/에너지 오차는1.32709e-07, fine 에너지 잔차는6.02149e-13, 바리온 잔차는 초기 대기량 대비8.59443e-17였다. 처음15개 위치의 기하·thermal/rate·밀도/주파수 미분 표가 비트 단위로 유지되었고 공유 광자 면 면적도 일치했다.

| 관심량의 대조 | 상대 차이 |
|---|---:|
|새19셀 직접 전하의64/128 시간 대조 |1.233648% |
|16→19셀 직접 전하 공간 대조 |0.003351% |
|직접+광자 질량 합의 공간 대조 |0.133996% |
|전체 출사 주파수 스펙트럼의 공간 대조 |0.142624% |
|64/128 두 시계에서 공간 차이의 혼합 대조 / fine 직접 전하 |0.00006675% |

분류: Counterexample candidate. 원2% 기준을 적용한 직접 전하·총합·출사 스펙트럼의 국소 공간 대조가 통과했다. 추가 혼합 차이는 두 시계에서 공간 대비가 크게 바뀌는지 확인한 기술 통계이며, 전역 시간/공간 오차 상계가 아니다. 관측 시계는 이전16셀 결과와 비트 단위로 같고, 새 계산만 다른 시각에 평가해 차이를 줄이지 않았다.

분류: Counterexample candidate. 새 정규화 직접 전하 변화는 `+1.0175542675e-27`, 광자 질량 항과 합친 명목값은 `+5.1636284534e-27`다. 같은 새 원천의 실제 GR 응력·질량 기여와 외부 광자/퍼텐셜 상계 뒤에도 조건부 직접 하한은 `+1.0153711781e-27`로 양수다. 추가 GR 항만 포함한 명목 합 구간은 `[5.16144536e-27,5.16578090e-27]`다. 이 좁은 구간에 원천의 공간·EOS·초기 제약 오차가 포함된다고 표시하지 않는다.

분류: Counterexample candidate. 작은 공유 물질 포트는 위 전하와 다르게 아직 수렴했다고 할 수 없다. fine 누적 질량은 기존 `-1.46492992e+07g`에서 새 `1.55584709e+05g`로 부호까지 바뀌었다. 새64/128 경로끼리도 `4.17207951e+04/1.55584709e+05g`여서 상대 시간 차이는73.18%다. 바깥 방향이 양수다. 누적 Killing 에너지·중성수소 포트도 큰 상대 차이를 보였다. 이를 전체 물질 유출 예측의 통과로 세지 않는다. 관심 전하의 원 기준 통과와 작은 포트 자체의 미수렴을 함께 보존한다.

분류: Counterexample candidate. 이번 성과는 기존34km 면 재구성을 실제 native 경계층으로 바꾸어 결합 진화를 완주하고, 그 국소 세분이 직접 전하를 거의 바꾸지 않는다는 유한 대조를 얻은 loophole progress다. 같은 국소 격자를 자동으로 더 세분할 근거는 약해졌다. 전체 방사·물질 원천이 연속 한계에서 인증되거나 최종 물리 전하가 정해진 것은 아니다.

분류: Conjectural. 다음 우선순위는 실제 초기 물질·광자 상태가 저장 GR 배경의 Einstein 제약과 맞는지 확인하고 불일치가 있으면 초기 상태에 반영하는 일이다. 나머지15개 내부 셀의 공간 오차도 남는다. 작은 추가 GR 구적이나 이번 국소 경계를 계속 자동 세분하는 대신, 초기 제약과 전체 원천 오차 중 잔여 전하를 실제로 흔들 수 있는 항을 먼저 닫아야 한다.
