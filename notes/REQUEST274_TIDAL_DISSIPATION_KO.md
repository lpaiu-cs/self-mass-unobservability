# 조석(l≥2) 채널과 소산 — 궤도 시간척도 붕괴 경계의 확장

분류: Conjectural. **목표는 단계273의 반경(단극) no-go 경계를 조석(l≥2) 채널과 소산(지연·직교 성분)까지 넓힐 수 있는지 판정하는 것이다.** 단계273은 자유낙하 기억이 궤도 시간척도에서 정적 계수로 붕괴함을 반경 채널에서만 보였고, 조석 채널과 소산은 계산하지 않았다. 사용자는 2026-09-27에 남은 과제를 모두 진행하라고 지시했다. 기록=2026-09-27 KST.

## 선택 규칙

분류: Proven. 선언된 배경은 정적이고 구대칭이다. 따라서 선형 응답 연산자는 회전과 시간 이동에 대해 불변이고, 응답은 (l, m) 성분별로, 그리고 구동 진동수별로 분리된다. compact 전하는 외부 단극(l=0) 장이므로 선형 차수에서 구동의 l=0 성분에만 반응한다. 쌍극·조석(l≥1) 구동은 단극 전하를 2차에서만 바꾸고, 선형 응답은 구동 진동수 밖의 측파대를 만들지 않는다. 이 규칙은 백색왜성 자전(구대칭 파괴, (Ω_s/ω_dyn)² 차수)을 무시한다.

## 방법

분류: Conjectural. 선언 배경의 표본 배열(6005점: ρ, P, Γ₁, T, m, φ₀, 경과 lapse, 바닥 광도 L)만 쓴다. 뉴턴 약한장 근사이며(조밀도 4e−6), 스칼라 결합은 선형이다.
1. 정적 조석 Love 수 k₂: Clairaut–Radau 방정식 r η′ + η² − η − 6 + 6(ρ/ρ̄)(η+1) = 0, η(0)=0, k₂ = (3 − η(R))/(2(2 + η(R))).
2. 부력 진동수 N² = g(d ln P/dr/Γ₁ − d ln ρ/dr)(배열의 수치 미분). ∫N/r dr로 점근 g모드 주기 간격 ΔΠ_l = 2π²/(√(l(l+1)) ∫N/r dr)을 구하고, J0337 조석 구동 진동수에서 g모드 차수와 상대 간격을 적는다.
3. 진행파 판정: 봉투(광도원 없음)에서 열확산도 K = L/(4πr²|dT/dr| ρ c_p), c_p ≈ (5/2)P/(ρT)로 두고, l=2 중력파의 한 방향 감쇠 깊이 τ_w(ω) = ∫ K k_r³/ω dr, k_r = √6 N/(ω r)를 계산한다. τ_w ≫ 1이면 파가 반사 전에 소멸하므로 이산 g모드 공명이 없다(진행파 영역). 핵 구간을 빼므로 τ_w는 하한이다.
4. 열 시간: 위 층의 열 함량 τ_th(r) = ∫_r^R (5/2)P 4πr² dr / L. 전하 층(깊이 240–465 km)의 값과 τ_th가 궤도 주기와 같아지는 깊이를 적는다.
5. 단극 정적 구조 응답: 균일한 스칼라 이동 δφ는 유효 중력을 비율 ε만큼 바꾼다(|ε/δφ| ≤ 4|α₀| + 2|α₀β|). 단계273의 단열 반경 연산자를 ω=0에서 외력 −εg로 풀어 변위 ξ를 얻고, 정적 전하 변화 δq = (1/M)∫ξ w′ dm(w = α(φ₀)·lapse, 약한장 정적 가중)를 구한다. 이것이 궤도 시간척도에서 자유낙하 기억이 붕괴해 들어가는 정적 구조 계수 κ_struct = δq/δφ다. 직접 정적 계수 β = −4와 비교한다.
6. 소산 상한: 단일 완화에서 직교 성분은 완화되는 부분의 절반을 넘지 않는다. 단극 채널의 직교 전하는 |κ_struct|δφ 이하로 둔다. 조석 채널은 공명이 없을 때 직교 성분이 평형 조석의 크기 이하라고 둔다.
7. J0337 비교(Imported from prior work: 질량 1.4378/0.19754/0.41010 M☉, 상대 장반경 4.776e11/1.7649e13 cm, 주기 1.62940/327.255일은 저장소의 parameter_set=6 규약; 이심률 e_in≈6.92e−4, e_out≈0.0354는 Ransom et al. 2014): 구동 δφ의 궤도 변조, 조석 매개변수 q(R/a)³, 정적 조석의 근점 이동 비, 채널별 지연 SEP 신호를 Paper B의 지연 응답 한계(|δΔ|<1.7e−9, τ_χ=2일)와 비교한다.

분류: Conjectural. 판정 규칙: (i) 조석 채널이 선형으로 단극 전하에 들어가지 않고, (ii) 궤도 구동에서 진행파 영역이어서 이산 공명이 없으며, (iii) 단극 직교 성분의 상한이 J0337 지연 한계보다 여러 자릿수 작으면, 자유낙하 기억의 no-go 경계를 조석·소산 채널까지 확장해 적는다. 하나라도 성립하지 않으면 해당 채널을 열린 반례 후보로 남긴다. 자전·비선형·공명 포착(resonance locking)은 가정으로 명시한다. 예산은 CPU 수 초–수 분이며 장기 계산이 없다.

### 4. 단극 채널의 정적 구조 계수와 소산

분류: Counterexample candidate. 균일한 유효 중력 변화 ε에 대한 단열 정적 응답은 거의 균질 수축이다(ζ=−1.05 중심, −1.013 전하 층). 그 재배치가 만드는 정적 전하는 δq/ε=−1.84e−7이다. |ε/δφ|≤4|α₀|+2|α₀β|=0.048(φ_∞=1e−3)이므로, 자유낙하 기억이 궤도 시간척도에서 붕괴해 들어가는 정적 구조 계수는 |κ_struct|≤8.8e−9이고 직접 정적 계수 |β|=4의 2.2e−9다. 두 인자가 모두 φ_∞에 비례하므로 κ_struct∝φ_∞²다.

분류: Conjectural. 단일 완화에서 직교 성분은 완화되는 부분의 절반을 넘지 않는다. 그래서 단극 전하의 지연 성분을 |κ_struct|δφ 이하로 보수적으로 둔다. 실제로는 전하 층이 1초 안에 열평형으로 돌아가므로, 지연은 열 시간이 궤도 주기와 비슷한 더 깊은 층에서만 생긴다.
