# 단계106 — 고정 화학 입력의 실제 유출·전하 연결

분류: Counterexample candidate. 수정한 native EOS의 화학 재고 조건을 실제 구면 보존 유출에 적용하고, 원 시간 구간0.0034344311초를 완결했다. 최종448/896셀 경로는 원 바리온·에너지 수지와2% 공간 비교 기준을 통과했다. 저장된 이력을 같은 지연 Green 전하 계산에 적용한 결과, 직접 전하 성분은 약−2.593e−30으로 남았다. **유한 반응·흡수 광자·전체 물질/GR 되먹임을 푼 최종 전하는 아니다.**

## 실제로 바뀐 입력

분류: Counterexample candidate. 원 자유에너지·원자 분배함수와 동위원소 조성을 유지했다. 초기 표면의24원소 이온 재고를 고정하고, 조건부 내부 준위 평형을 유지한 EOS의 압력·내부에너지·엔트로피를 계산했다. 평형 EOS의 열용량이나 Gamma1을 그대로 쓰지 않고 고정 재고 상태의 밀도·온도 미분을 사용했다. 작은 비이상 잔차만 보간해 이상기체의 정확한 온도 의존성을 보존했다.

분류: Counterexample candidate. 초기 rho,T 및 계량·반경·안쪽 속도 이력은 기존 값을 사용했다. 다만 표면 이온 재고를 층 전체에 동일하게 부여한 대조이므로, 기존 비균일 초기 이온 분포를 정확히 이류한 실험은 아니다. 초기 압력은 최대2.394e−6, 내부에너지는7.768e−6 상대 차이를 보였다. 이를 숨기지 않고 별도 초기화 파일에 남겼다.

분류: Counterexample candidate. 기존 단열 경로 밖의 고온·희박 상태에서는 처음에 극미량이던 높은 전하 단계가 점유되어 활성 좌표만 제약하던 근 찾기가 실패했다. 처음 점유된 좌표는 그대로 고정하고, 새로 점유된 극미량 좌표는 초기 원소 재고의1e−18 이하로 억제하도록 제약을 명시적으로 확장했다. underflow된0을 유한 양의 재고로 역산하지 않았고, 전체 재고 오차1e−12 및16회 반복 한도는 유지했다. 이전 자유로운 극미량 조건이 그 상태에서도 작동했다고 주장하지 않는다.

분류: Counterexample candidate. 이전 광자 코드의 일부 원자 분배함수는 현재 대기와 다르므로 해당 반응 계수를 이식하지 않았다. 이번에는 화학 반응을 끈 대조와 원래의 탄성 전자 산란·반대 광자 일만 결합했다. 실제 완전 동결의 물리적 입증이나 흡수·방출 폐쇄로 세지 않는다.

## 절단 실패를 실제 계산에서 수정

분류: Counterexample candidate. 처음에는 단계105의 단열 밀도 범위ln(rho/rho0)≥−6에 맞춘 EOS 표를 사용했다. 세 경로는 완주했지만448/896셀 trace 비교가12.337%로 실패했다. 이 문턱에서 외부 재고의약3%를 삭제했으며, 그 재고의 에너지·화학 저장량이 해석하려던 trace와 비슷했다. 원 실패 판정과 상태를 보존했다.

분류: Proven. D=rho W, u=u0+3p/(2rho)+du, 정지 에너지 계수c_rest를 정의하면 다음 국소 항등식이 성립한다.

```text
E_nr = [rho(c_rest+u)+p] W² − p − c_rest D
T_nr = rho(c_rest+u) − 3p − c_rest D
T_nr = −E_nr + 2u0 D
       + (c_rest+u0)rho(W−1)² + (5/2)p(W²−1)
       + rho du(1+W²)
```

분류: Proven. 따라서 고정 화학 저장 에너지와 비상대론적 단원자 기체에서는 적분 trace의 선도 변화가 질량·에너지 보존에 의해 제한된다. 이 식은 국소 응력 항등식이며 지연·공간 가중치가 있는 전하 자체의 상쇄 정리는 아니다.

분류: Counterexample candidate. 삭제 재고에 공통 lapse와 이상기체 항등식을 적용하면 최초 실패의 대부분을 설명할 수 있었다. 그 사후 진단값을 수락 결과로 바꾸지 않았다. 대신 기존 LTE 계산의−18 밀도 문턱까지 같은 native EOS를 실제로 연결했다. 원81개 상태를 재사용하고72개를 추가했으며, 온도 범위240–20000K·유체 격자·반경·시간·문턱은 유지했다. 비용과 판정 이유를 별도 재평가 계획에 기록한 뒤 같은 경로를 다시 실행했다.

분류: Counterexample candidate. 수정 후 삭제 재고는 외부 재고의2.970e−7 이하로 줄었고 실제 trace 비교가 통과했다. 아래 수치는 사후 꼬리 보정이 없는 유체 출력이다. 그 밖의 물리적 꼬리 응력·위치는 아직 인증하지 않았다.
