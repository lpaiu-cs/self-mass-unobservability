분류: Counterexample candidate. **새 EOS 충돌 입력을 실제 광자·열·중성수소 결합 방정식에 넣어 3.434431 ms 전체 구간의 64/128단계 응답을 완주했다.** 입력 검사에서 끝내지 않았다. 두 경로의 최대 시간 대조 차이는 0.1737491%이며 보존·선형 풀이 기준을 통과했다. 다만 새 교정을 자유 물질과 GR까지 전달하는 단계는 아직 통과하지 못했다. 기존 단계139의 압력 원천 GR 결과와 이번 충돌 응답의 완료 범위를 구분한다.

## 수정과 철회

분류: Counterexample candidate. 원 입력의 첫 시점 광자 수 결속 오차 1.835233537e-10은 1e-12 기준을 넘었다. 대기 산란의 두 큰 값을 직접 빼는 부분은 같은 속도에서 부호 있는 불투명도 차이를 기존 선형 산란 연산자에 적용하는 방식으로 고쳤다. native와 기존 속도가 다른 41셀은 그 차이를 버리지 않고 같은 연산을 확장 정밀도로 계산했다.

분류: Counterexample candidate. 심부 H 전달항에도 차분 괄호 순서 불일치가 있었다. 광자항과 같은 `(nr0-old0)-(nr1-old1)`을 사용하도록 고쳤다. 이후에도 거의 평형인 순 산란에 반올림 잔여가 남아, 에너지와 반경 운동량을 보존하는 두 주파수 성분의 수 보정을 명시적으로 적용·저장했다. 독립 감사에서 보정의 셀별 에너지 가중 L1 비율은 최대 1.129647312e-12, 에너지 모멘트 변화는 약 3.8e-26 이하, 최종 수 결속 오차는 6.7e-17 이하였다. 보정을 물질 열이나 탈출 광자에 숨기지 않았다.

분류: Proven. 잔여 광자 수를 R, 두 에너지를 L,H라 하면 `dN_L=-R*H/(H-L)`, `dN_H=R*L/(H-L)`은 합계 -R, 에너지 합계 0을 준다. 같은 각도에 적용하면 반경 운동량 변화도 0이다. 이는 정확 산술의 항등식이며 전체 EOS/수송 오차 정리가 아니다.

분류: Counterexample candidate. 원 산란 차분 자체의 0.2% 대조는 최대 약 1.3743%로 실패했다. 그 실패를 보존했다. 분해 성분의 부정확한 옛 차분을 정확한 기준으로 삼는 대신, 실제로 전달되는 전체 충돌 원천의 대조와 보존을 확인했다. 이 변경을 원 산란 상대 오차 인증의 성공으로 부르지 않는다. 생성기의 `export_number_before_projection` 필드는 두 번째 보정 잔여를 기록한 이름 오류가 있어 독립 감사의 `number_before_projection`만 사용한다.

분류: Counterexample candidate. 처음 제기한 **j 복원 누락이 속도 오류라는 진단은 철회**한다. 실제 동적 호출은 `def_native_material_join.Coupled.velocity`이며 Pi를 사용한다. 새로 만든 17시점 계수 은행은 이전 것과 모든 검사 배열이 정확히 같았다. 이를 물리 연산자 개선으로 세지 않는다.

## 자유 물질에서 확인한 실제 경계

분류: Counterexample candidate. 실제 충돌 에너지/H/운동량을 자유 물질에 전달했다. 64단계 경로의 첫 두 단계, t=0.1073259724 ms에서 **심부 11번 셀의 중성수소 상대 변화 1.465821457e-6**이 원 선형 응답 기준 1e-6을 넘었다. H는 양수이며, 물질 보존 약 1.65e-16, 방향 미분 차이 2.82e-5, donor 변동 2.37e-4는 각각의 기준을 통과했다. 이는 보존·적분 파탄 또는 별의 물리적 불안정성 판정이 아니다. 원 선형 적용 범위의 실패다.

분류: Counterexample candidate. 따라서 실제 진폭의 유한 차이 `F(Q+dQ)-F(Q)`를 쓰는 비선형 물질 대체식도 같은 초기 두 단계에서 시험했다. 실제 donor와 native 보간 EOS/primitive 복원을 사용하고, 진폭을 줄이지 않았다. 완전히 같은 입력의 `F(Q)-F(Q)=0`을 명시적으로 처리한 뒤에도 큰 배경 유량 차분의 수치 해상도 지표가 **0.002425358383**으로 기준 0.002를 넘었다. 전체 경로·새 GR 판독은 시작하지 않았다. 이 지표는 16 eps 기반의 산술 진단으로, 엄밀한 EOS/primitive 오차 상계는 아니다.

분류: Counterexample candidate. 같은 두 단계의 선형/유한 진폭 이력 차이는 성분별 약 `[4.54e-5,5.61e-5,1.03e-13,2.68e-18]`이다. 짧은 구간의 유사성을 전체 구간의 비선형 오차 보증으로 바꾸지 않는다. 정확한 초기 0 차이 처리는 저장 물리 이력을 바꾸지 않았다.

## 자원·완료 범위·다음 결정

분류: Counterexample candidate. 실제 광자 응답 pilot는 24.39초, 이어서 저장 접두 구간을 재사용한 두 전체 경로 생산은 185.14초였다. 원 900초 cap 이내다. 이 시간은 입력 준비·라이브러리 import·문서 작업을 포함한 전체 세션 벽시간이 아니다. source 산술 수정의 원 실패와 세 차례 재평가, 작은 물질 pilot 실패를 모두 보존했다. 실패 시 정확 driver 시간이 저장되지 않은 항목은 원 60/40/90초 cap을 보수적으로 부과하고, 미사용 source/bank/물질 생산 allowance를 명시적으로 재배분했다. 별도 읽기 진단과 import의 정확 연산 시간은 계측하지 않았으므로 전체 세션 자원 상계 인증을 주장하지 않는다. 원 900초 물질 생산 중 재배분 뒤 780초는 미사용이며 자동 실행하지 않았다.

분류: Conjectural. 다음에는 **물질 보존 유량과 primitive 압력의 차이를 처음부터 차이로 계산하는 보상 연산**을 구현해야 한다. 동일한 저장 충돌 이력과 첫 두 단계에서 기존 HLL/보존/primitive 의미, 진폭, 시간, 0.2% 해상도 기준을 유지해 대조한다. 이를 통과하면 같은 64/128 물질 경로를 완주하고 실제 압력·trace와 GR 전하로 전달한다. 지금 더 긴 경로를 돌리거나 선형 기준을 완화할 이유가 없다.

분류: Conjectural. 전체 EOS 연속/미분 인증, 자유 물질의 완전한 반환, 새 운동의 광자 재반환·결합 증폭/고정점, floor/외부·공간 오차, 비선형 GR, 정적 비흡수성·관측 연결과 최종 전하 완료 조건은 유지한다. 단계139의 양의 compact 전하가 이번 충돌 교정까지 포함해 살아남는지는 **아직 판정하지 못했다**. 관련 상태는 `milestone.json`에 false로 명시했다.
