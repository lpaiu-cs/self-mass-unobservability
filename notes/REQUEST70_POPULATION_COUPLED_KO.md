# 단계70 — 유한 이온 점유와 광자·물질의 실제 시간 결합

분류: Counterexample candidate. 같은 EOS의 유지된 이온화 18개 경로에 유한 점유 변화를 넣고 기존 광자·물질·공간 시간식에 연결했다. 저장된 순간 LTE 경로를 대조로 사용하며 같은 초기 에너지·격자·물리 시간 구간을 유지했다. 원자 에너지를 별도로 저장하면서 평형 열용량을 그대로 쓰는 중복 계산을 제거했다. 전체 원자 비평형·반경 GR·기존 속도 실패의 해결을 뜻하지 않는다.

## 열역학과 실제 반응의 연결

분류: Proven. 온도 T에서 유지된 누적 이온 점유를 x, 평형 온도 접선을 a=dx_eq/dT, 제약된 화학 Hessian을 H라 하자. 평형 주변의 국소 자유에너지와 열용량은 다음과 같이 연결된다. 수식은 양의 H와 양의 C_f 아래의 선형 조건부 결과다.

```text
F(T,x) = F_eq(T) + 1/2 (x-x_eq(T))^T H (x-x_eq(T))
l = T H a
C_f = C_eq - T a^T H a
delta E_material = C_f delta T + l^T delta x
norm_material = C_f |delta T|^2 + T delta x^* H delta x
```

분류: Proven. 외부 화학 퍼텐셜을 kT lambda로 쓰면 고정 밀도·온도의 제약 평형 감수율 S=dx/dlambda에 대해 H=kT S^-1이다. 각 이온화 면 q에 공액인 x_q는 해당 원소의 전하 q보다 높은 모든 원자 단계의 수밀도 합이다. 내부 준위 및 나머지 화학 좌표를 조건부로 최소화한 Hessian이다. 이 정의를 전체 준위가 독립적으로 진화하는 Hessian으로 바꾸어 읽지 않는다.

분류: Counterexample candidate. native EOS의 공통 `eos_calc` 경로에서 이 공액 퍼텐셜을 일정한 Saha 지수 이동으로 적용했다. 밀도·전하·분자·비이상 보정의 자체 일관 반복은 그대로 사용했다. 장을 끈 상태와 재생은 저장 EOS 및 재고와 비트 일치했다. 장을 켠 EOS의 에너지·엔트로피 반환값은 비평형 물리값으로 사용하지 않고 점유 응답만 썼다. 두 장 크기에서 얻은 감수율의 정규화 최대 차이는7.9944e−6, Maxwell 대칭 결함은1.6347e−6으로 사전1e−5 기준을 통과했다. 정규화 감수율의 최소 고유값은0.99086이다.

분류: Counterexample candidate. 열용량은 C_eq=0.5831402394, 이온 점유 기여0.1484642992, C_f=0.4346759402 erg·cm⁻³·K⁻¹다. 평형 온도 접선은 기존 두 온도 차분 쌍을 재사용했다. 이에 따른 백색화 접선 차이는 초기 열용량 척도로2.8298e−7이다. 이 유한 차분 대조를 연속 영역 전체의 엄밀 오차 보증으로 부르지 않는다.

분류: Proven. 에너지 e인 광자 하나가 반응 j를 일으키면 광자에서 e를 빼고, 이온 점유에 하나를 더하며, 물질 열에 e-l_j를 넣는다. 원자 저장 에너지는 l_j만큼 증가하므로 합계는 보존된다. U^T U=T H와 광자 셀 열용량 C_i를 쓰면 각 사건의 백색화 방향은 다음과 같다.

```text
v = ((e-l_j)/sqrt(C_f), U e_j, -e/sqrt(C_i))
collision = - R_eq/(k T^2) v v^T
v · (sqrt(C_f), U a, sqrt(C_i)) = 0
```

분류: Proven. 양의 평형 사건률 R_eq는 소산적 연산자를 만든다. 광자 에너지에 대해 기존 bound-free 입력의 세 양의 모멘트 G0, G1=integral(dG0/e), G2=integral(dG0/e²)를 적분하여 같은 연산자를 조립했다. 선·자유-자유·집단 산란·공간 이동은 기존 경로를 재사용하되 열 저장고에 C_f를 쓴다. 초기 delta T=1 K, delta x=a, 광자 교란0은 기존 LTE 초기 상태와 총에너지 및 노름 C_eq가 같다.

분류: Counterexample candidate. 실제 반응률은 기존 광이온화 진폭과 역반응의 평형 활동도에서 얻었다. 별도 완화시간을 추측하거나 반응률 배수를 맞추지 않았다. 이온 내부 준위, 속도분포와 미유지 화학 좌표는 여전히 조건부 평형이고 전자 충돌 이온화/재결합은 추가하지 않았다. 따라서 전체 물리 kinetics 인증은 아니다.

## 실제 진화의 판정

분류: Proven. 재조립한 연산자의 에너지 영모드와 사건별 보존 항등식을 검산했다. 분류: Counterexample candidate. 독립 저장 재검사는 다섯 끝점의 차이·차수·LTE 비교, native 열용량 분해와 정정된 선 꼬리 상계를 재계산했다. 이 검사는 새로운 EOS나 시간 경로를 실행하지 않는다.

## 원 실패와 다음 연결

분류: Counterexample candidate. 이번에 해소한 부분은 **유지된 이온 점유가 시간식에 없는 것과 평형 열용량의 중복 문제**다. 입력이 실제 시간을 따라 광자와 에너지를 교환했고 LTE와 구별되는 응답을 얻었다. 하지만 전체 반경 유체·scalar·계량을 진화시킨 실험이 아니므로 `original_complete_input_failure_resolved=false`, `full_GR_photon_feedback_evolved=false`, `full_dynamic_charge_solved=false`를 유지한다. 단계56의 속도 수렴 실패도 그대로 남는다.

분류: Conjectural. 다음 우선순위는 국소 원자 검증의 추가 확장이 아니라 **저장된 반경 열수송 입력과 이 광자 에너지·운동량 교환을 실제 GR 물질식에 연결하여 원 속도 실패를 다시 판정하는 것**이다. 현재 한 외곽 상태의 원자 표를 전 반경의 인증된 표로 사용하지 않는다. 필요한 상태 적용 범위를 정한 뒤 같은 실패 성분·원 기준을 대상으로 최소 결합 경로를 수행해야 한다. 조건부 내부 준위 LTE, 누락 충돌·원자 성분·대기와 전체 전하·구동·비교·관측은 여전히 남는다.
