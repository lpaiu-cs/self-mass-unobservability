# 단계84 — 전체 단열 외부 응답·정적 질량 정규화·전파를 포함한 비교

분류: Counterexample candidate. **단계83의 유체 운동만의 차이를 넘어, 직접 scalar와 물질·계량을 포함한 전체 단열 별의 외부 응답을 읽었다.** 원16개 GR 주파수 해의 외곽 반력을 재사용하여 실제 표면까지 옮기고, 같은 입사장 아래 별의 정적 표면 응답과 비교했다. 실제 반경에 놓인 정적 비교와 정확한 진공 전파를 분리했으며 공간·외곽·구적 기준을 통과했다. 새 EOS·FEM·시간 적분은0이다.

분류: Counterexample candidate. 표면 관계를 단순히 주파수 독립으로 고정하면 실제 세 궤도 조화의 정규화 복사 전하 차이 진폭 합은1.72111820e-10이다. 그러나 이는 빈 공간 안에서도 생기는 파동 저장을 포함한다. 같은 내부 계량의 시험 scalar 전파를 비교에 넣으면 합은2.84403183e-15가 된다. 따라서 앞의 큰 값을 미시적 완화 신호로 해석하지 않는다. 전체 비단열 항성·열 배경 변화·실제 binary sensitivity와 관측 nuisance의 연결은 여전히 미완료다.

## 같은 별의 표면에 정적 비교를 고정

분류: Imported from prior work. 단계83의 전체 내부 impedance는 Z_free=Z_clamped+delta Z다. clamped는 이 값을 안정적으로 구하기 위한 분해일 뿐, 이번 최종 비교의 상대 별은 아니다. 원2R·3R 지점의 해를 단계43의 정확한 scalar·계량 진공식으로 r/R=1까지 운반했다. 저장된 입력·native EOS·바리온·엔트로피·조성과 기계적 배경을 유지한다. 표면의 영 주파수 해는 그 조건부 단열 기계적 기준이며 전체 열 평형 항성의 재구성이 아니다.

분류: Proven. 같은 입사장과 진공 outgoing impedance Z_out 아래에서 표면 응답이 Z0와 Z0+delta Z인 두 모형의 나가는 파 차이는

```text
delta a = -drive * delta Z / [(Z0-Z_out)(Z0+delta Z-Z_out)]
delta outgoing = delta a / h
delta alpha_radiative = -R/M_ADM * delta outgoing
```

분류: Proven. 이 차이는 큰 입사·반사 파를 빼지 않고 계산된다. 실수 내부 impedance의 S=-[(Z-Z_out*)/(Z-Z_out)]h*/h는 절댓값1이다. 따라서 이번 무손실 단열 산란의 복소 위상 자체를 열적 소산이나 완화시간 검출로 볼 수 없다. 같은 incoming 차이의 복사 ADM 질량 변화는0이지만, 유한 반경의 Misner–Sharp 질량 변화는 r² b Phi delta phi로 일반적으로0이 아니다. 이 두 질량과 유효 점입자의 질량 계수를 동일시하지 않는다.

분류: Counterexample candidate. 기존 외곽 해를 표면에 복원한 진폭과 독립 outgoing 계산의 상대 차이는최대6.7e-16, 두 진공 적분 허용오차의 impedance 차이는1.13566e-12다. 전체 응답에서 정적 표면 관계를 뺀 차이의 공간·외곽·구적 대조는 각각최대5.79e-9,2.57e-8,1.28e-8다. 단열 S의 단위성 오차는2.22e-16이다. 표면의 정적 impedance는 -1.68633581096e-5다.

## 직접 scalar와 정적 질량 정규화

분류: Proven. 정적 Just 외부 해에서 Q=alpha M, 표면 mu=m/R, q=R Phi라 하면 delta alpha=delta Q/M-alpha delta M/M이다. 저장된 방사형 제약 delta mu=(1-2mu)q delta phi와 정확한 외부 지도 미분을 함께 사용하면 delta M/(M delta phi_infinity)=alpha가 성립한다. 이 조건부 정적 식의 누락된 정규화 항은 -alpha²다. 유효 점입자 scalar 전하와 외부장 의존 질량의 관계는 [Khalil 등의 유효 작용](https://arxiv.org/html/2206.13233v2#S2)에서 q_physical=-dm_E/dphi로 정의하며, 여기서 Q는 그 q_physical과 반대 부호다. 이 문헌이 이번 EOS 매칭을 검증한 것은 아니다.

분류: Counterexample candidate. 저장된 동일 배경과 전체 정적 해를70자리 외부 미분에 넣으면 다음을 얻는다. 입력 정적 scalar 진폭의 무한원점 보정은0.9999999999999998이다.

| 양 | 값 |
|---|---:|
| 배경 alpha | -0.00400035668661 |
| 질량 분모를 고정한 delta Q/(M delta phi_infinity) | -4.00034175582 |
| 질량 정규화 기여 | -1.60028536201e-5 |
| 정규화한 d alpha/d phi_infinity | -4.00035775867 |

분류: Counterexample candidate. 따라서 이전 약6e-9의 기계적 gain을 전체 별의 직접 scalar 민감도로 대신하면 안 된다. 이번에 정적 직접 응답과 질량 분모를 함께 계산했다. 다만 비영 주파수 복사 해에 정적 Q/M 지도를 그대로 적용하면 유한 반경에 저장된 파동까지 전하로 셀 수 있다. 이번 비영 주파수 읽기는 같은 incoming 조건의 **복사 꼬리 차이**이며, 궤도에 넣을 완전한 시간 의존 점입자 민감도까지 인증한 것이 아니다. 동반성 구동은 단계40의 선도 alpha_B=-0.004를 유지하므로 이번 정적 매칭값으로 동반성·주기를 함께 갱신한 binary 계산도 아니다.

## 파동 전파를 정적 비교에 포함

분류: Proven. 평탄한 빈 구의 정칙 시험 scalar는 j0(omega r)이며 표면 impedance는 omega cot(omega)-1=-omega²/3+O(omega⁴)다. 따라서 내부 관계를 Z(0)으로만 고정하면 물질 완화가 없어도 O(omega²) 차이를 만든다. 이 사실을 대조군으로 검사해야 한다.

분류: Counterexample candidate. 전체 응답에서 이 규모가 지배함을 확인한 뒤 별도 비교 계획을 고정했다. 같은 저장 내부 계량 F=N sqrt(b)에서

```text
(r² F psi')' + omega² r²/F psi = 0,  psi(0)=1, psi'(0)=0
Z_compare(omega) = Z_star(0) + Z_test_wave(omega)
```

분류: Counterexample candidate. 즉 정적 물질 민감도와 이미 알려진 시험파 전파를 함께 유지한다. 이는 명시한 하나의 비교 모형이며 일반적인 정적 EFT 전체나 다른 실제 항성을 뜻하지 않는다. psi=1+omega² u로 풀어 작은 곡률을 직접 계산했다. 평탄한 해와의 상대 차이는최대9.99e-16이다. 원 결과와 원 비교는 보존하고 해상도·조화 수는 늘리지 않았다.

| 조화 | 정적 관계만 고정한 차이 | 같은 계량 전파를 포함한 차이 |
|---|---:|---:|
| 1 | 1.14743142e-10 | 1.89591275e-15 |
| 2 | 4.58016849e-11 | 7.56957178e-16 |
| 3 | 1.15669925e-11 | 1.91161895e-16 |

분류: Counterexample candidate. 표의 단위는 복사 꼬리 차이로 정의한 abs(delta alpha_radiative/phi0)다. 전파를 포함한 잔여 자체의 최대 공간 차이0.0351%, 외곽0.1551%, 구적0.0774%, 전파 적분 허용오차0.0000048%로 등록된2%·0.2% 기준을 통과했다. 이는 고정 모형의 유한 수치 대조이며 물리 EOS·열·관측 오차의 상계가 아니다.

## 미분 비교와 현재 식별 한계

분류: Counterexample candidate. 외부 전파·질량 미분 내부 계산은0.23초, 추가 시험파 비교는1.21초 미만이었다. 두 별도120초 예산을 지켰고 기존16개 FEM 해와 EOS를 재사용했다. 이 시간은 WSL·import·문서 작성 시간을 포함하지 않는다. 기호 검사·원 해의 결속·독립 정적 미분·평탄 전파·유한 대조를 실행했다.

분류: Conjectural. 이번 결과는 **loophole progress: 전체 단열 외부 응답, 정적 질량 정규화, 전파를 포함한 비교 및 그 수치 식별 한계**다. 남은 결정적 물리는 비정상 열 배경과 전 반경 광자·전도의 응답이다. 현재 작은 단열 잔여만으로 전체 물리 신호를 제한하지 않는다. 미시적으로 맞춘 동반성 구동·동일 재고 열적 정적 비교·물리 오차 및 실제 관측 nuisance의 연결도 남았으며 전체 목표는 미완료다.
