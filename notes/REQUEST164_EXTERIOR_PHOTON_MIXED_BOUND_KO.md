# 단계164 — 외부 광자의 혼합 GR 원천을 최종 전하의 상계에 연결

분류: Counterexample candidate. **누락된 직접 방출 광자의 계량 측도·에너지·이동 경로와 혼합 제약 원천을 함께 제한하고, 단계163의 선택 전하에 적용했다.** 새 부문의 전하 상계는 `1.3690315879582209e-57`이다. 기존 외부 기여 상계와 합한 값은 `1.8117175154965646e-53`, 선택 전하 크기의 `0.00713952276984648`배다. 지정한 부문을 모두 허용해도 끝점의 음의 부호는 유지된다. 조건부 loophole progress이며 전체 물리적 전하의 완료는 아니다.

## 이번에 판정한 범위

분류: Counterexample candidate. 다음 입력을 고정했다. 원래의 양의 64/128 accepted-port 방출 이력, 이를 포함하는 비음수 방출량·광도 상계, 같은 초기 scalar 진공, 기존 primary와 연속 유한 원천의 첫 Born 입력이다. 구동 크기·기간·셀·시각·방출 방향을 바꾸지 않았다. 저장된 scalar 입력의 균일 크기·일차 미분 상계를 재사용했으며, EOS 근·유체 진화·광선 이력의 신규 계산은 없다.

분류: Counterexample candidate. 이 범위는 **나중에 더한 signed 방출 반환과 이미 생성된 배경 scalar를 포함하지 않는다.** 외부 입력의 실제 물질 반환 성분, 내부·외부 추가 접합항, 정확한 초기 ADM/운동량/flux 보존도 이번 상계 밖이다. 이전 배경 이력의 점 추정 기준 실패는 그대로 남는다. 아래 구간은 통계적 신뢰구간이나 전체 물리 오차 구간이 아니다.

## 원천의 유도

분류: Proven. 저장소의 polar Einstein-frame 표기를 사용한다. `a=N√b`, `Φ=K/(a r²)`, 경계 반경 `R`, 광자의 질량 길이 `e=G E/c⁴`다. 직접 방출 성분 B는 내부의 동일 에너지 debit과 짝지으며 `λ_B=−e H(r_p−r)/(ar)`다. 지정한 scalar 입력 I는 `λ_I=ΦU`, `ζ_I=ν_I−λ_I`, `∂rζ_I=2λ_I/(rb)`를 따른다. `g`는 Killing 에너지의 일차 로그 변화, `ρ`는 고정 시각에서 광자 반경의 변화다.

분류: Proven. 광자의 밀도와 제약식의 계량 prefactor를 모두 변분하면 고정 위치 항은 `−ζ_I e`다. 이를 알려진 혼합 계량 곱과 함께 적분하면, 추가 내부 질량 포트를 0으로 둔 **이 외부 원천 성분**의 제약은 다음과 같다.

```text
C = N J_ext / √b
∂r C = e [ (∂r ζ_I) H(r_p−r)
            + (g−ζ_I(r_p)) δ(r−r_p) − ρ δ′(r−r_p) ]

C = e [ (ζ_I(r)−ζ_I(R)) H(r_p−r)
        + (g−ζ_I(R)) H(r−r_p) − ρ δ(r−r_p) ]
```

분류: Proven. scalar 방정식에서 이 질량 원천의 측도는 `2Φ C/(rb) dr`이고, 알려진 매끄러운 제약 응력은 `−4eΦλ_I H(r_p−r)/(rb) dr`다. 이것만으로는 혼합 scalar 원천이 끝나지 않는다. 초기 scalar 기울기와 두 계량의 곱도 필요하다.

```text
S_gradient dx = 2 a r Φ (ζ_B ∂rζ_I + ζ_I ∂rζ_B) dr
```

분류: Proven. 위 기울기 항의 매끄러운 부분은 `4aΦλ_Iζ_B/b−4eΦζ_I/(br)`이고, 광자 껍질 부분은 `−2eΦζ_I(1−μ²)δ(r−r_p)`다. 이동 껍질의 적분을 고정 반경으로 바꾸면 광선 시간 Jacobian에서 또 하나의 `−ζ_I`가 생긴다. 밀도 측도의 `−ζ_I`, 이 Jacobian, 기울기 껍질 항을 합하면 다음의 진폭·방향 변화와 별도 도달 파면 변화가 남는다.

```text
δU_shell = −e/2 ∫ (Φ/a)
            [ g (1−μ²)/μ − (1+μ²) δμ/μ² ] H_observer dr
            + arrival-front term

δμ = (1−μ²) h/μ,       |h| ≤ H_max (1−R/r)
```

분류: Proven. 따라서 계량 prefactor만 광자 밀도에 곱하거나 광선 위치 변화만 추가하는 식은 불완전하다. 여기서는 제약 원천의 이동 delta, 방향 변화, 방출 시각을 적분한 도달 파면을 각각 포함했다. `μ→0`의 표면 접선 방향은 `μ²≥(1−κ_geo)(1−R²/r²)` 및 `h(R)=0`으로 적분 가능하게 제한한다. 이 주장은 선언한 일차 변화에 관한 것이며 유한 진폭 광선의 비선형 잔차 보증은 아니다.

## 무한원까지의 균일 상계

분류: Proven. 혼합 제약의 바깥 질량 꼬리 `e(g−ζ_I(R))`를 임의로 0으로 만들지 않았다. 그러므로 원천의 시간 적분 길이를 모든 반경에서 단순히 `T`로 둘 수 없다. `t≥0`, `t−x/c≤T`인 관측 영역에서는 최대 길이가 `T+x(r)/c`이고, `x(r)≤(r−R)/a_min`을 적용한다. 질량 원천의 공통 반경 적분 상계는 다음과 같다.

```text
W = |K|/(2 a_min b_min) [ T/R² + 1/(c a_min R) ]
```

분류: Proven. 정적 scalar 퍼텐셜의 반복에도 같은 시간 가중치가 필요하다. 진공에서 `|V|dx≤[2M/r³+2K²/(a_min²r⁴)]dr/√b_min`을 사용하면, 기존 수축 상계에 다음의 양의 항을 추가할 수 있다.

```text
Δη = [ M/R + K²/(3 a_min² R²) ] / (2 a_min √b_min)
η_weighted = η_old + Δη
```

분류: Counterexample candidate. 새 가중 수축 상계는 `2.1430858601669983e-6 < 1`이다. 지정한 새 자유 원천의 전 영역 크기에 `η_weighted/(1−η_weighted)`를 곱해 정적 퍼텐셜의 나머지 반복을 제한했다. 기존 직접 방출 계량의 인과적 원천 상계는 유지한다. 이번에 생긴 바깥 제약 꼬리에만 기존 짧은 구간 상계를 그대로 적용하지 않았다.

분류: Counterexample candidate. 실제 저장 상계를 넣은 결과는 다음과 같다. scalar 표의 수치는 `|δU|/M`의 상계이며, 마지막 공통 질량 분모 적용은 별도로 수행했다.
