## 실제 적용과 범위

## 자원과 원 판정 보존

운영 기록: 전체 배경, native 상태와 collision bank는 재계산하지 않았다. 광자 pilot은 과학 기준을 통과했지만 두 배 안전 여유를 둔 예상 `1051.843`초가 최초1000초 배정을 넘어 원 부적격으로 남겼다. 실제 완료된 계량 비용을 확인한 뒤 미사용 계량 예산100초를 광자로 옮겼다. 전체 상한2050초, 두 기존 경로, 진폭·기간·격자·오차 기준을 유지했다. 예산 거절을 지우거나 새 경로를 추가하지 않았다.

운영 기록: 수락한 광자·물질 prefix에서 이어 실행했다. 과학 실행 합계는 벽시간 `748.633`초, CPU `690.290`초다. 코드 작성·발행·Git 시간은 이 합계 밖이다. 1 BLAS 스레드와3GiB 가상 메모리 상한을 적용했다. 모든 입력 결속과 이전 산출물 보존, 문서 byte prefix를 검산했다.

운영 기록: 미분 실패 수정에는 미사용 광자 예산250초를 진단50초와 물질200초로 재배분했다. 원 물질 계산과 수정 fine의 합산 생산 상한은550초이며 전체2050초 상한은 유지했다. 수정 fine의 새 prefix 실측 두 배 예측은 `244.021`초다. 전체 경로나 광자를 자동 반복한 것이 아니다.
