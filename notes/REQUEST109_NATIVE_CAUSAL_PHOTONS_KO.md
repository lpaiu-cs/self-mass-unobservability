# 단계109 — 깊은 내부의 비선형 수소·열·광자 결합

분류: Counterexample candidate. **실제 저장 배경의 깊은 내부에 수소 재고·물질 열에너지·주파수별 광자 수송을 함께 적용하고 3.434ms를 완주했다.** 선형 물질 근사가 실패하자 같은 격자에서 비선형 native EOS로 교체했다. 보존·시간 대조·실제 native 상태 대조를 통과했다. 다만 거친 광자 공간·각도 표현의 물리 해석은 아직 수락하지 않았으며, 최종 전하를 계산하거나 선언하지 않았다.

## 이번에 실제로 연결한 영역과 방정식

분류: Counterexample candidate. 단계108의 국소 유체는 표면 아래 400m까지만 포함한다. 같은 기간의 스칼라 과거 광원뿔은 약 1029.61km이며, 저장 복사 외피의 깊이는 약 624.41km다. 따라서 핵 일부의 체적 열·화학 원천도 판단해야 한다. 이번 영역은 표면 아래 1100km부터 표면까지, **16개 물질 셀·152개 광자 주파수**다. 원 구면 저장 밀도·온도·계량을 읽었으며 이 영역의 초기 핵종 조성이 같음을 직접 확인했다. 각 반경의 원 native LTE 이온 재고를 사용하고 수소만 유한 반응으로 진화시켰다.

분류: Counterexample candidate. 기체 밀도·반경·계량은 고정했다. 중성 수소와 총 내부에너지는 비선형 보존 변수로 진화시키고 매 단계 native 표에서 온도를 복원했다. 광자는 평균 점유와 반경 유속의 P1 모멘트로 풀었다. 같은 수소의 bound-free 흡수·자발/유도 방출, 변하는 전자 수의 탄성 Thomson 산란을 사용했다. 다른 이온·분자 재고는 해당 반경의 초기 값에 고정했다. 역반응은 기존 열역학 상호성 모형이며 독립적인 미시적 Milne 인증은 아니다.

분류: Proven. 정적 Jordan 계량의 lapse를 `a`, 반경 계수를 `B`, areal radius를 `r`로 쓰고 Killing 주파수를 고정하면, 선언한 P1 평균식의 보존 측도는 `r²B/a³`다. 물질 반응과 광자 원천에 같은 순 반응 수와 광자 에너지를 쓰면, 화학 저장 에너지를 포함한 물질 내부에너지 변화와 광자 Killing 에너지 변화가 정확히 상쇄한다. `symbolic.json`은 이 두 대수적 명제를 검산한다.

## 초기 광자장 조건을 바꾼 범위

분류: Counterexample candidate. 이번 초기 광자 평균은 각 반경의 기체 온도에 대응하는 Planck 분포다. 주파수별 유속은 그 스펙트럼 모양을 유지하면서 저장 회색 광도에 맞췄다. 외피 아래에서는 실제 저장 온도·계량 기울기와 Rosseland 계수로 초기 유속을 계산했다. Rosseland 계수를 주파수별 흡수율로 대신 쓰지 않았다. 핵과 외피의 초기 열 불일치를 제거하는 인공 열원도 넣지 않았다.

분류: Counterexample candidate. 이는 단계107–108의 **더 뜨거운 희석 Planck 장과 다른 명시적 Cauchy 조건**이다. 총광도만으로 둘 중 하나가 유일하게 선택되지는 않는다. 이번 계산을 이전 광자장에 대한 단순 해상도 개선이나 실제 관측 스펙트럼으로 부르지 않는다. 외부 대기는 이번 내부 광자장과 아직 함께 진화시키지 않았다.

## 실패를 수정한 실제 경로

분류: Counterexample candidate. 첫 선형 결합 계산의 에너지 잔차는 `3.584e-12`였지만 최대 `|ΔlogT|=0.02546`, 중성 수소 상대 변화 `0.61663`으로 원 작은 변화 기준 `0.02`, `0.1`을 실패했다. 이 값은 수락된 전하 원천이 아니다. 이 실패 때문에 격자를 확대하지 않고 **동일 16셀에서 비선형 물질 폐쇄**를 적용했다.

분류: Counterexample candidate. 비선형 native 표의 첫 반응률 보간은 최대 `0.004064`로 원 `0.002` 기준을 실패했다. 원인은 고주파의 알려진 `exp(-hν/kT)`까지 온도 보간에 넣은 것이었다. 이 인자는 직접 계산하고 나머지 완만한 계수만 보간하도록 수정했다. 기존 **96개 native 상태를 모두 재사용**했으며 표 노드·온도 범위·격자·문턱을 늘리지 않았다. 같은 독립 대조에서 최대 반응률 차이는 `1.4072e-4`로 감소했다. 원 실패 데이터와 실행 소스는 보존했다.

첫 선형 bank 저장 뒤 보고서 직렬화가 NumPy 부울 형식 때문에 실패했다. NPZ는 살아 있었고 그대로 재사용했다. 해당 첫 실행의 정확한 native 공개 호출 수는 저장되지 않았으므로 알 수 없다. `3500회`는 실행 상한이다. 이후 NPZ는 보고서보다 먼저 호출 수와 대조 오차를 저장한다. 초기 각도 검사의 `F/(cE)≤0.5`도 잘못된 내부 조건이었다. `0.5`는 반구 표면 값이며 P1의 양의 모멘트 조건은 `(F/cE)²≤1/3`이다. 그 검사에서 멈췄을 때에는 시간 진화를 실행하지 않았다.

## 다음에 해결할 물리 병목

분류: Counterexample candidate. 양의 평균 광자 점유와 에너지 보존만으로 물리적 각도 분포를 보장할 수 없다. 현재 엇갈린 격자의 양옆 면 유속을 셀 중심으로 평균해 읽으면 최대 bolometric `|F|/(cE)=0.59495`로 P1 양의 모멘트 한계 `1/√3=0.57735`를 넘는다. 고주파에서는 초기부터 이 재구성이 강하게 미해상이다. 반면 초기 실제 면에서 직접 정의한 모멘트의 최대 비는 `0.50228`로 허용 범위다. 따라서 이 지표만으로 연속 초기 광자장이 비물리적이라고 단정할 수는 없지만, **현재 거친 공간 표현으로 진화한 광자장의 물리적 해석은 인증되지 않았다.**

분류: Conjectural. 다음 결정적 작업은 기존 결과를 재사용하면서 광자 평균과 유속을 동일한 공간 표현에서 다루고 양의 각도 분포와 연결하는 것이다. 공간·주파수 대조가 필요한 범위를 실제 오차 원인에 맞춰 정한 뒤, 그 내부 광자 유속을 단계108의 움직이는 반응 대기와 같은 면에서 교환해야 한다. 16셀 시간 통과를 더 큰 전체 항성 계산의 자동 실행 근거로 쓰지 않는다.

분류: Counterexample candidate. 전체 GR/scalar 되먹임, 다른 화학 종과 누락 광학 채널, 물리적 꼬리·질량 정규화, 실제 구동·정적 비교·관측 식별성은 계속 미완료다. 이번에는 깊은 내부의 **비선형 물질·광자 실제 시간 결합**을 수행한 loophole progress를 남겼다. 보존 측도·교환식은 theorem progress다. 전체 목표는 active다.
