# 단계142 — native 충돌·유한 물질 운동의 실제 광자·물질·GR 귀환

분류: Counterexample candidate. **단계141의 실제 유한 물질 운동을 광자·열·중성수소 동시 방정식에 되돌리고, 새 충돌 전달량을 다시 유한 물질·압력·GR까지 연결했다.** 같은 64/128 시간 경로가 원 3.434431ms 구간을 완주했다. 합산 원천의 자유 compact 전하 끝점은 **+1.021134292423207e-27**로 양수를 유지했다. 지정 수치 모형의 한 번의 결합 귀환이며 최종 물리 전하 인증은 아니다.

## 실제로 적용한 입력

분류: Counterexample candidate. 각 시간 경로에 대응하는 단계141 물질 이력의 바리온·운동량·재고 이동과 비충돌 에너지/H 수송을 사용했다. 단계140의 동일 native 충돌 교정을 한 번만 더하고, 에너지/H는 광자와 각 SDIRK 단계에서 동시에 풀었다. 추가 GR 구동은 0으로 유지했다. 주파수 이탈을 물질 열로 넘기지 않았으며, 충돌 전달과 비충돌 수송을 별도로 저장했다.

분류: Counterexample candidate. 531셀·8각도·152주파수·17개 배경 시점과 기존 EOS/충돌 계수 은행을 재사용했다. 새 native 보존 역산, 물리 배경 재생, 더 조밀한 시간·공간 격자는 실행하지 않았다. 성공한 광자 4/8단계와 물질 두 단계 접두부를 이어 사용했다.

분류: Counterexample candidate. 물질 부문은 보상 유량을 사용하는 실제 진폭의 비선형 유량/primitive 차분이다. 광자 부문은 기존 보존 변수의 선형 primitive 지도와 충돌 계수를 사용한다. 이 조합을 완전한 비선형 복사 유체 진화로 부르지 않는다. 원 작은 상태 선형 적용 기준의 실패도 보존한다.

## 결합 불일치와 전하

분류: Counterexample candidate. 공통 17시점에서 fine 광자 풀이와 새 물질 풀이의 에너지/H 상대 불일치는 각각 **4.7530e-12 / 7.7409e-12**다. 이전 값 6.6238e-8 / 1.0805e-8보다 줄었다. 절대 잔차의 전후 비율은 7.1757e-5 / 7.1642e-4이며, 광자·물질 시간 대조 중 큰 절대 차이의 1.6981e-8 / 4.4552e-9배다. 이 비교는 계산 오차 규모 아래의 파형 일치를 보여 주지만 연속시간 오차 상계나 균일 수축 상수는 아니다.

분류: Counterexample candidate. native 충돌·물질 교정의 자유 compact 끝점은 +1.380775373034631e-34다. 단계141의 같은 성분과의 유한 차이는 -2.337475768e-41이며, 이 차이는 해당 성분의 시간 대조 오차 규모보다 작다. 따라서 음의 피드백 효과가 물리적으로 분해·검출됐다고 해석하지 않는다. 원 주 원천과 native 압력 교정에 이번 원천을 합쳐 GR에 직접 적용한 끝점은 +1.021134292423207e-27이다.

분류: Counterexample candidate. 끝점의 최대 상대 상태 변화는 대기 전역 셀 236의 중성수소에서 4.15355e-4였다. 해당 H 변화는 1.01883e17개, 배경은 2.45292e20개다. 작은 전역 결합 잔차가 모든 셀의 물리 변화 또는 EOS 선형화 나머지를 보증하지 않는다. 특히 이 상태를 포함한 실제 EOS/충돌 응답의 오차는 다음 판정 대상이다.

## 다음 결정과 남은 범위

분류: Conjectural. native 입력의 물질→광자→물질→GR 연결은 이번에 실제로 완료됐다. 같은 파형 반복의 잔차는 이미 시간 대조 규모보다 작으므로, 추가 반복보다 **실제 EOS/충돌 선형화 나머지·결합 증폭·외부/floor 원천을 전하 오차 예산에 연결하는 일**을 우선한다. 작은 반복 차이를 전체 오차 상계로 대체하지 않는다.

분류: Conjectural. 전체 EOS 이력/미분과 연속시간 오차, 초기 GR 계수 일치, compact 퍼텐셜·외부 scalar·삭제 물질의 후속 작용, 포트 공간 오차, 비선형 GR, 실제 구동의 정적 비흡수성·관측 연결 및 최종 전하 완료 기준은 계속 열려 있다. 전체 목표를 이번 부분 성공으로 축소하지 않는다.
