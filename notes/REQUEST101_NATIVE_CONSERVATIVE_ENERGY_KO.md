# 단계101 — 대기 에너지 보존 병목 해결과 직접 전하 재계산

분류: Counterexample candidate. **저장된 대기 유출의 에너지 잔여를 실제 보존 에너지 진화로 제거했다.** 원3.434431ms 구간의224셀 파일럿과896/1792셀 경로를 모두 완료했다.1792셀의 에너지 장부 잔여는 응답 대비5.59e-16으로, 원 엔트로피 진화의 에너지 잔여보다 약10¹²배 작다. 이 새 유출 이력을 기존 직접 전하 계산에 적용해 파형이 남는 것도 확인했다. 고정된 저장 계량 위의 물질·광자 성분을 연결한 결과이며 전체 GR/scalar의 최종 전하는 아직 미완료다.

## 무엇을 바꿨는가

분류: Proven. 물질 좌표계의 계량을`a=A*N`, 고정 기준 lapse를`a0`라 하면, 바리온`D=rho*W`, 총 물질 에너지`E`에서 다음 보존 변수를 사용할 수 있다. 이 절의 에너지 식은 광속 단위다.

```text
K = a*(E-c_X*D) + (a-a0)*c_X*D = a*E-a0*c_X*D
F_K = (K+a*p)*v = a*(E+p)*v-a0*c_X*D*v
```

분류: Proven. 고정 계량의 Killing 에너지 보존식에서 정확히 보존되는 바리온 식에 상수`a0*c_X`를 곱해 빼면 이 식이 나온다. 큰 정지 에너지를 계산한 뒤 빼지 않고, 비정지 성분을 직접 계산할 수 있다. 계량이 시간에 따라 변하는 전체 문제에서는 추가 계량 일이 필요하므로 이 식만으로 동적 Einstein 방정식까지 닫혔다고 할 수 없다.

분류: Counterexample candidate. 기존의`D`, 반경 운동량, 엔트로피 진화 중 마지막 변수를`K`로 교체했다. 같은 구면 면적·lapse 유속과 같은 SSPRK2 단계에서 에너지를 진화하며, 기체가 받은 탄성 산란 일은 광자 장부에서 반대로 차감한다. 내부 경계 유속과 native 하한 아래로 제거한 물질의 바리온·운동량·에너지도 별도 장부로 보존한다. 이전에 측정한 잔여를 열로 주입하거나 최종 에너지를 사후 맞추지 않았다.

## 실제 유출 상태를 복원하는 EOS

분류: Counterexample candidate. 보존 에너지 진화의 첫 실제 단계를 native EOS로 직접 풀었더니 새 유출 셀의 엔트로피 매개변수가0.79893이었다. 기존3개 등엔트로피면만으로 처리할 수 없었다. 넓은 엔트로피 표를 먼저 구성했지만 독립 검사에서 최대21.18% 오차가 발생하여 원 실패를 보존하고 생산에 쓰지 않았다.

분류: Counterexample candidate. 온도를 직접 복원하도록 바꾸고, 기존 native 상태를`rho,T` 좌표에서 사용했다. 압력·비에너지의 온도 미분에는`chi_T`, `cvT`, 밀도 미분에는`chi_rho`, `u_lnrho`를 적용했다. 온도 범위가 이웃 밀도 열과 겹치지 않는 첫 실패도 보존했다. 필요한 native 온도 열을 보충한 뒤 원12개 독립 검사점 모두가 같은0.2% 기준을 통과했다. 최대 차이는0.009551%다.

분류: Counterexample candidate. 실제 희박 유출은 표의 초기 온도 상한을 일부 넘었다. 임의 외삽을 사용하는 대신 처음부터 명시한 native100–10⁷K 영역 안에서 실제 요청한 상태만 추가 평가하고 세 경로에서 공유했다. 이 추가 호출은2726회로3000회 상한 안이다. 기체의 순간 화학평형은 여전히 모델 전제이며 이 수치 대조가 비평형 반응 속도를 인증하지는 않는다.

분류: Counterexample candidate. 보존 상태의 온도 복원에서 Newton 진동, 이전 온도의 압력을 사용한 근 구간, 반복 한도 실패를 각각 보존했다. 현재 온도에서 운동량을 먼저 수렴시키고, 남는 소수 셀은 독립 대조한 Brent 근 찾기로 해결했다.1792셀 경로에서 이 보조 근 찾기는18회였으며 최대 원시 상태 에너지 오차는2.00e-11 미만이다. 원1e-8 수락 기준은 완화하지 않았다.

## 계산 비용과 실패 보존

최초 엔트로피 표와 독립 검사에는3296 native 호출/55.79초가 들었으며 실패로 보존했다. 첫 실제 단계의 직접 native 복원은16회/0.996초였다. 온도 열 보충은6000회 한도에서125/147열을 완료한 뒤 멈췄다.7249개 저장 상태를 재사용하여 남은22열만 따로 등록한3000회/60초 한도 안에서1554회/26.41초로 마쳤다. 온도 열의 총 native 호출은7554회다. 후속 원12점 대조는42회/1.554초였다. 첫 온도 열 겹침 실패에서 사용한 호출 수는 별도로 저장되지 않아 총 호출 수를 정확한 값으로 꾸미지 않는다.

생산 전 문법 오류와 원시 상태 복원 실패의 소스·실패 상태를 남겼다. 파일럿은125단계/5.349초,896셀은708단계/14.325초,1792셀은1586단계/33.718초였다. 이미 끝난 경로를 다시 실행하지 않았다. 중간의 완료된 수락 상태도 저장해 중단 시 초기 상태부터 재계산하지 않도록 했다.

기존 전체 비용 외삽, 실제 커널 측정, 실제896셀 비용에 따른 판단을 각각 보존했다. 최초 생산 예산은240초였다. 마지막 경로에 필요한 보수적 예상83.55초와 측정한 준비 시간 약5.53초가 잔여80.15초를 넘었으므로, 마지막 경로에 한해서 생산 총예산을250초로 명시적으로 재평가하고90초 하드 상한을 뒀다. 최종 경로는 준비를 포함해37.256초에 끝났다. 물리적 수락 문턱이나 경로·기간을 바꾸지 않았다. 최종 독립 감사2.581초와 직접 전하 후처리8.722초는 별도 등록한 짧은 검증/후처리다.

## 완료 경계

분류: Proven. 고정 계량에서 정지 에너지를 안전하게 뺀 보존 변수·유속의 항등식을 확인했다. 분류: Counterexample candidate. 실제 보존 에너지 진화, 세 경로의 독립 상태 대조, 등록한 두 격자 적분량 대조, 새 이력의 직접 전하 적용을 완료했다. 에너지 장부의 수치 병목을 해결한 theorem/loophole progress다. 전체 목표는 유지하며 아직 완료로 표시하지 않는다.

분류: Conjectural. 다음은 보존된 내부 유입·광자 일·희박 물질 에너지를 전체 GR/scalar 질량 제약과 지연 원천에 실제 적용하는 것이다. 고정 계량에서 닫힌 에너지를 동적 계량에서도 닫힌 것으로 대체하지 않는다. 화학평형·흡수 가정과 기존 GR 공간 오차도 최종 전하 판정 전에 해소하거나 명시한 조건 아래 통제해야 한다.
