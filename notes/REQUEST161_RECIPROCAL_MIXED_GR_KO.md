# 단계161 — 상호 혼합 GR 원천의 실제 전파

분류: Counterexample candidate. **빠져 있던 내부 상호 혼합 Einstein–scalar 원천을 구성하고, 기존 파동 연산자로 전파해 같은 outgoing 전하 성분에 적용했다.** 새 보정은 `-8.784791844740518e-55`이며 기존 저장 물질 전하의 **0.0346344%**, 같은 음의 방향이다. 원 공간·원천 시각 대조를 통과했다. 새 scalar 장을 저장했지만 이 장의 실제 물질·광자 반환, 외부 혼합 원천·질량 정규화와 전체 물리 폐쇄는 아직 완료하지 않았다.

## 재사용한 실제 입력과 중복 제거

분류: Counterexample candidate. 배경 B는 단계160과 동일한 단계152/153 원천 합성과 저장 장이다. 입사 계열 I는 단계155의 기존 primary와 첫 Born, 단계156의 실제 물질·광자 응답, 단계157의 물리적 자체 GR 반환이다. 증폭해 저장된 자체 반환만 정확히 `2^63`으로 나눴다. 원 531셀, 4/8차 공간 표현, 33개 B 원천 시각과 3.4344311179287023ms 구간을 유지했다. 기존 I 원천은 17개 저장 시각 사이에서 선형 보간했다. 새로운 EOS 근이나 유체 이력을 계산하지 않았다.

분류: Proven. 동결된 원천 내보내기 식에서 `eF,pF,tF`는 실제 변화에 초기 canonical 기하 응답을 보정한 양이다. 따라서 알려진 물리적 일차 응력을 복원할 때 아래 초기 항을 한 번만 뺀다. 실제 수송으로 이미 얻은 물질 응답을 새 혼합 원천으로 다시 더하지 않는다. `H=Eg+Pg`, `v=3αf+λ`이며 기체의 trace만 남는다.

```text
δE = eF - H v - 4α Er f - (Er+Pr) λ
δP = pF - Kg v - 4α Pr f - (3Pr-R4) λ
δT = tF - (H-3Kg) v
```

분류: Counterexample candidate. 여기서 쓰는 일차 장은 기존 초기 canonical 연산자의 해와 실제 수송 반환을 합친 조건부 표현이다. 아직 수송에 재입력하지 않은 장의 canonical 응답까지 완전한 물리적 혼합 물질 해로 승격하지 않는다. 원 전체 상태 반복 실패와 상위 GR 입력의 시간 비교 실패도 보존한다.

## 실제로 추가한 방정식

분류: Imported from prior work. 구면 polar Einstein–scalar 방정식의 배경은 기존 저장소의 anisotropic 초기 연산자이며, tensor–scalar 구면 진화의 문헌 맥락은 [Novak (1998)](https://arxiv.org/abs/gr-qc/9707041)이다. 아래 혼합 식은 이 저장소의 표기와 가정에서 새로 미분·확인한 식이며 그 논문의 수치 결과를 가져온 것이 아니다.

분류: Proven. `a=N√b`, `A4=A⁴`, `α=-4φ0`, `β=-4`로 둔다. 두 독립 증분 B,I의 혼합 계수에서 `kB=2λB+4αfB`, `kI=2λI+4αfI`, `kBI=kB kI+4βfB fI`다. 알려진 혼합 제약 원천은 다음과 같다. 아래 식은 알려진 일차 증분을 고정하고 미지의 혼합 변화는 기존 선형 연산자의 왼쪽에 둔 것이다.

```text
qλ = -2 λB λI/(r b)
     +4π r A4/b [E0 kBI+kB δEI+kI δEB]
     +r fB,r fI,r+r fB,t fI,t/(c² a²)

qν = +2 λB λI/(r b)
     +4π r A4/b [P0 kBI+kB δPI+kI δPB]
     +r fB,r fI,r+r fB,t fI,t/(c² a²)

Jx,r+(ν0,r+λ0,r)Jx=r b qλ
Jx=√b/N ∫ a r qλ dr
Sconstraint=Keff Jx+r a² Φ0(qν-qλ)
```

분류: Proven. `Jx`의 적분에는 새로 지정한 안쪽 원천이 없다는 조건을 사용했다. 이 보조량을 새로운 물질 에너지로 세면 안 된다. 특히 물리적 혼합 질량에는 `δmBI=r b λBI−2 r b λBλI`가 들어가므로, 이번 `Jx`를 그대로 외부 ADM 질량 변화로 읽지 않는다.

분류: Proven. `hB=2νB+4αfB`, `hI=2νI+4αfI`이면 conformal trace 원천은 다음과 같다. `T0=Eg−3Pg`다.

```text
HBI = [α(hB hI+4β fB fI)+β(hB fI+hI fB)] T0
      +(α hB+β fB)δTI+(α hI+β fI)δTB
Strace = -4π r N² A4 HBI
```

분류: Proven. 위 원천에 초기 scalar 기울기의 혼합 항과, 입사 계량이 이미 생성된 배경 scalar에 작용하는 항을 더했다. `ζ=ν−λ`, `UB=r fB`이며 `Vgeom`은 단계160과 같다.

```text
Sgradient = 4 ζB ζI (4π r N² A4 α T0)
            +2 a² r Φ0(ζB ζI,r+ζI ζB,r)

SI[UB] = 2 ζI UB,xx+a ζI,r UB,x
         +(-2ζI Vgeom-a²ζI,r/r)UB+ζI,t UB,t/c²
```

분류: Counterexample candidate. 이 네 원천을 합쳐 기존 characteristic-cut 연산자로 전파하고 동일한 초기 potential 반환을 계산했다. 단계160의 배경 계량이 primary에 작용하는 항은 다시 더하지 않았다. 새로 계산한 장·원천·각 성분의 판독을 독립 배열로 보존했다. 단순히 원천의 크기만 진단한 것이 아니다.

## 이차 미분의 중단과 수정

분류: Counterexample candidate. 첫 실행은 초기 원천이 0이라는 보호 조건에서 중단됐다. 실제 저장 초기 weighted 원천의 최대치는 약 `1.4951e-37`이고 전체 최대치는 약 `4.3921e-29`였다. 이 초기 값을 지우거나 0으로 바꾸지 않았다. 중단 영수증과 원 프로그램을 보존하고, 추가 시간·격자 없이 정확한 초기 파면 항을 구현했다.

분류: Proven. 공간별로 유한한 원천 `S`의 retarded 해에 대해, 원천가 없는 영역에서는 `S=0`으로 이어 붙인다. 선형 시간 보간의 각 열린 구간에서 다음 식으로 이차 미분을 직접 평가할 수 있다. 저장 파형의 작은 차이를 유한차분하지 않는다.

```text
Uxx(t,x) = (1/2c) ∫ S_t(t-|x-y|/c,y) Θ(t-|x-y|/c) dy
           +[S(0,x-ct)+S(0,x+ct)]/2-S(t,x)
```

분류: Counterexample candidate. 실제 배경의 마지막 potential 반복에 사용한 원천까지 포함해 이 식을 적용했다. 독립 검사에는 `S=2+x²+ct(1+x)`를 `[-1,1]`에 두어 비영 초기 원천과 두 파면을 모두 시험했다. 정확한 다항식 적분과의 최대 절대차는 4/8차에서 각각 `1.055e-15`, `2.359e-15`였다. 물리적 보간 오차가 이 값으로 인증된 것은 아니다.
