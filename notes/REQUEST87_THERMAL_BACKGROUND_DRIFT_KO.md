# 단계87 — 같은 전 반경 열·GR 식의 실제 배경 진화

분류: Counterexample candidate. 단계86의 전 native 내부 회색 복사·미시 전도·물질·scalar·계량 연립식을 비균일 초기 온도와 영 초기 열유속에서 실제로 적분했다. 궤도 조화 강제는 이번 배경 시험에 넣지 않았다. 고정 계수·조성·선형 열역학 접선과 생략된 native 외곽 유속 0이 선언 모형이다. 물리적인 대기나 비선형 항성 진화의 인증은 아니다.

## 사전 판정과 실제 실행

분류: Counterexample candidate. 정지 물질의 저장 수송 시작 해에서 최대 |delta lnT|=0.02가 되는 시각 0.0004964909061413661초를 공통 끝점으로 선택했다. 실제 접선 변화 0.05에서 중단하고, p4의 16/32/64 단계와 p2의 64 단계만 비교하도록 동결했다. 온도 시간 차이 1%, 차수 1.5 초과, 공간 차이 1%, GR·열 원식 잔차 1e-9, 내부 에너지 수지 2e-13이 사전 기준이다. 속도와 scalar는 별도 진단이며 전체 성분 수렴을 승인하는 계획이 아니다.

분류: Proven. 물리 좌표 q, 운동량 변수 w, 면 누적 적색편이 열에너지 E, pole 전류 f에 대해 사용한 식은 다음과 같다. 단계 소거식은 기호 대수로 확인했다.

```text
qdot = w - H Edot
M wdot = -K q + F_source E
Edot = sum_l f_l
fdot_l = lambda_l [tc conductance_l (theta0_difference + Gq q + GE E) - f_l]
```

분류: Counterexample candidate. SDIRK2의 두 단계에서 같은 인수분해를 재사용했다. 열 원천은 원 구적식으로 조립하고, 결합 해 뒤 물리적 GR 블록으로 작은 scalar 성분을 복원한 다음 두 원식을 모두 재검사했다. EOS·충돌 상태의 재계산은 없다. 직접 native 핵반응의 열 접선 변화는 이 구간에서 최대 7.3265e-14, 조성 증분은 1.0993e-16이었다. 이 두 값은 직접 원천의 평가이며 비선형 결합 오차 상계가 아니다.

## 정확한 조건부 외곽 실패

분류: Proven. 정지한 고정 셀의 선언 에너지식 Udot=L_inner-L_outer+Q에서 정상 상태는 L_outer=L_inner+Q를 필요로 한다. L_inner+Q<0이면 L_outer>=0인 모든 외향 전용 경계는 그 셀을 정상 상태로 유지할 수 없다.

분류: Counterexample candidate. 실제 사용한 회색+미시 전도 모형의 최외곽 내부 면 광도는 -1.1445599912e34 erg/s이고, 직접 native 핵 가열은 8.97866e-18 erg/s다. 온도가 외곽 18827.9472K, 그 안쪽 18103.7658K인 이 고정 배경을 그대로 유지하려면 외곽에서 순 에너지가 들어와야 한다. 이는 해당 입력·유속 법칙·정지 조건의 실패다. native 외곽은 실제 진공 표면이 아니며 얇은 층의 LTE 확산과 대기 연결이 인증되지 않았으므로, 물리적인 항성 전체에 대한 no-go로 일반화하지 않는다.
