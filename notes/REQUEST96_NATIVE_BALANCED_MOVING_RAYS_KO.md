# 단계96 — 표면 운동의 상쇄 오류 수정과 이동 광자 원천의 실제 GR 적용

분류: Counterexample candidate. 같은 비영 열유속을 큰 누적량으로 표현하면서 생기던 국소 열 손실과 표면 속도의 산술 상쇄를 수정했다. 수정한 실제 물질 표면 이력을 광선 지연·방출 방향·압력 일에 적용하고, 그 광자 원천이 만드는 추가 물질·열·scalar·계량 응답까지 진화했다. **전체 이동 경계와 최종 전하는 아직 미완료**다. 원 내부 속도 공간 실패도 유지한다.

## 실제로 해결한 오류

분류: Counterexample candidate. 일정한 면 에너지에는 중앙 주입 부근을 제외하면 국소 열 차감이 없어야 한다. 기존 행렬 곱에서는 외피의 가짜 온도 항이 최대3.37e-17까지 생겼다. 또 표면 물리 속도를 약81.45m/s의 열 lift와 canonical 속도의 차로 복원하고 있었다. 작은 전체 선형 잔여만으로 이 표면 값의 정확도를 보장할 수 없었다.

분류: Proven. 기준 유속 f0를 고정하고 `E=f0*t+e`, `f=f0+d`, `v=w-H*f`로 바꾸면 원 반이산 방정식과 동치다. q와 물리 속도 v를 직접 진화하고, 기준 원천은 면 차분을 먼저 수행한 뒤 보간한다. 초기 물리 열유속 f0는 그대로 유지된다. 단일 SDIRK 단계에서 `delta=h*(d-dr)`, `pred=er+h*dr`를 쓰면 기계 블록은 그대로이고 우변은 `M*(qr/h²+vr/h)+t*F0+F*pred+photons`, 열 우변은 `t*LE0+LE*pred-dr`가 된다. 심볼릭 검산을 통과했다.

분류: Counterexample candidate. 실제 EOS·배경·C1 원천·p4 일관 질량·3.434431ms 구간을 유지했다. 일정 흐름의 국소 손실은 새 표현에서 정확히0이다. 일반 입력에 대한 직접 원천과 기존 행렬 작용의 상대 차이는6.87e-17 이하이다. 원 큰 기준값을 분모로 사용하지 않는 셀별 변화분 열수지 검사도 통과했다.

분류: Counterexample candidate. 같은 p4 전체 시공간 최대값으로 정규화한 전후 차이는 온도2.29e-12, 속도6.68e-11, scalar1.84e-15다. 내부 응답은 거의 같고 작은 표면 운동이 크게 달라졌다. 따라서 이 오류가 원 내부 속도 공간 실패를 설명한다고 주장하지 않는다. 저장 p6와 수정 p4의 속도 차이는 여전히6.91206%로 원3% 문턱을 넘는다. p6를 다시 실행하거나 차수·격자를 늘리지 않았다.

## 이동 광자 원천과 결합 응답

분류: Proven. 고정된 곡률 계량에서 표면 변위 ζ와 속도 β=ζdot/Cs에 따른 광선 impact parameter 변화는 `δlnB=(1−ν′_s)ζ−μ0 β`다. 도착 지연 변화 `δT=DR ζ+DB β`와 각도별 압력 일 `f0 μ0 ζ/Cs`를 같이 넣어 지연된 누적 에너지, 에너지−반경 압력, 반경 압력의 변화를 구했다. 접선 방출 부근의 상쇄는 부분적분으로 제거했다. 반구 방출의 각도 가중 적분은 압력 일 `Wγ=(2/3)f0 ζ/Cs`를 준다.

분류: Counterexample candidate. 독립적인 유한 진폭 평탄 광선 대조는 세 모멘트에서1.18e-9 이하, 실제 곡률의 이동 하한·impact 독립 구적은 지연 미분에서1.79e-8 이하의 상대 차이를 보였다. 생산 계산에는 합성 표면 운동 대신 위에서 저장한 실제 ζ와 직접 계산한 ζdot를 넣었다. 저장32/64 표면 이력에 따른 광자 원천 차이는 최대0.4355%였다.

분류: Counterexample candidate. 이 추가 광자 원천을 **동일한 결합 GR·물질·열 연산자**에 넣어32/64단계 경로를 완결했다. 기준 응답을 다시 계산해 작은 값끼리 빼는 방식 대신 선형 추가 응답을 직접 풀었다. 끝점 광자 압력 일은1.10447erg, 명시된 외부 기체 압력의 일은0.0137104erg다. 광자 일/기준 방출 에너지는1.47960e-31이다. 외부 기체 일은 공급 장부의 계산값이며, 그 응력을 공급할 외부 물질의 동역학을 푼 것은 아니다.

분류: Counterexample candidate. 추가 응답이 매우 작으므로 절대 잔여 분모의 바닥값에 기대지 않도록 동일 경로의 입력 진폭을 재정규화했다. 물리 진폭을 다시 곱한 결과와의 최대 차이는2.54e-13이며, 임의 단위 변위를 가진 실제 항성을 계산한 것으로 해석하지 않는다. 최대 선형 상대 잔여2.34e-15, 셀별 변화분 열수지4.82e-11은 원1e-9 문턱을 통과했다.

## 수락 경계와 다음 결정

분류: Counterexample candidate. 이번 성과는 **실제 결합 진화의 수치 오류 수정 및 실제 이동 이력의 광자·GR 적용**이라는 loophole progress다. 이동 광자 추가 응답은 고정 계량에서의 `L0*ζ` 운동학적 혼합차수 성분이다. 같은 차수의 모든 항을 완성한 계산이 아니다. 작은 이 성분만으로 전체 되먹임이나 최종 전하 오차를 제한하지 않는다.

분류: Conjectural. 다음 결정적인 병목은 유한 외부 기체 응력을 포함한 물질–광자 이동 접합, 면적·lapse에 따른 광도 변화, 광선 위 동적 계량 항을 같은 차수에서 닫는 것이다. 그 뒤 원 내부 속도 공간 오차가 최종 정규화 전하에 미치는 영향과 정적 비교 모형의 흡수 여부를 판정해야 한다. 전체 비선형 항성 진화, 물리적인 비LTE 스펙트럼 대기, 최종 전하 및 관측 연결은 미완료다. 기존 실패를 작은 표면 보정이나 시간 수렴으로 대체하지 않는다.

실행 기록: CPU1스레드, 새 EOS 호출·배경 근 계산0회, 최대 측정 메모리0.747GB. 실측 수치 구간의 누적 계상은140.19초, 등록 계산 한도는180초였다. Python import·외부 프로세스 시작 비용과 문서 작업은 이 계상에 포함되지 않으므로140.19초를 전체 작업 벽시간으로 보고하지 않는다. 두 기준 경로, 두 추가 응답 경로와 각8단계 시험, 한 진폭 대조로 종료했다. 장기 계산은 실행 중이지 않다.

기억 기록: OSK MCP의 적재 엔진/디스크 엔진 불일치로 단계94–96 통합 쓰기가 거부됐다. 저장소 근거는 보존했으며 장기 기억에 반영됐다고 보고하지 않는다.
