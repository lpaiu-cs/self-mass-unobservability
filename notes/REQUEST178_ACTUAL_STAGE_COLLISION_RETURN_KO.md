# 실제 충돌 단계 이력의 자유 물질 반환

분류: Counterexample candidate. 최종 전하 결론은 미판정이다. 177의 실제 Radau H 수송은 수락했지만 동일 예비 광자 이력을 선형 보간하여 받은 자유 물질의 H-C 수송은 약66% 불일치했다. 그 실패를 보존하고 전체 기간 계산을 시작하지 않았다.

분류: Conjectural. 원인은 실제 단계 충돌 이력과 물질 입력 사이의 보간 손실일 수 있다. 177은 원 수송 단계만 저장하여 실제 gas·충돌·충격량 단계는 복원할 수 없다. T/16 예비 구간만 같은 방정식으로 재생해 누락한 단계 입력을 저장하고 기존 물리 배열이 bit 단위로 동일한지 검사한다. 이전 실측152.8초를 근거로220초를 상한으로 둔다. 전체 기간이나 새 시계는 계산하지 않는다.

분류: Conjectural. 두 실제 Radau 단계의 충돌률을 적분한 조각별 이차 C(t)를 자유 물질에 전달한다. z=U+C(t)로 놓고 Udot=F(U+C(t))를 적분한다. 이는 외부 이력이 정해진 물질식의 원천 전달이며 stiff 광자·열·수소 방정식은 그대로다. 원 hydro CFL과64/128macro 시계에서, 기록한 원천 구간 경계를 넘어가지 않도록 고정 SSPRK3를 적용한다. 실제 상태의 floor 투영과 보존 장부를 기록한다. H를 강제로 다른 해의 값으로 덮어쓰지 않는다.

분류: Conjectural. 준비10초·실제 단계 저장220초·반환 물질60초, CPU1스레드·가상메모리3GiB를 상한으로 둔다. 물질 비용은 이전13.8초에서 추가 단계와 입력 구간 경계로 늘어나는15–60초를 가정한다. 원0.2% 수송·미분,2% 시간,1e-8 보존·owner,1% branch 기준을 유지한다. 한 번의 같은 예비 물리 반환 뒤 실패하면 기간·시계·방법을 자동 확대하지 않는다. 통과해도 최종 전하 성과로 대신하지 않는다.

## 실제 결과와 원 판정

분류: Counterexample candidate. **최종 전하 결론은 미판정이다.** 수소 연결 병목은 이 예비 해에서 원 기준 이내로 줄였지만 전체 결합 해를 수락하지 않았다. 두 경로의 원 광자·gas 상태, 충돌 누적량, 순간 경계 배열, 시각 및 가중치 등12종 물리 배열은 재생 후 수치 원소가 정확히 같았다. NPZ 압축 바이트·longdouble padding의 동일성을 주장하는 것은 아니다. 충돌 단계 적분은 기존 충돌 장부와1e-12 이내로 일치했다.

| 같은 T/16 구간의 대조 | 64시계 | 128시계 |
|---|---:|---:|
| 이전177 H-C 수송 불일치 | 66.0471% | 65.9694% |
| 실제 단계 반환 뒤 H-C 수송 불일치 | 0.134886% | 0.0159003% |
| 실제 단계 원 수송률 불일치 | 0.171023% | 0.0452819% |
| 실제 단계 H 상태 차이 | 3.81768e-7 | 9.70463e-8 |
| 물질 보존 잔차 | 8.30982e-16 | 2.40904e-15 |

분류: Counterexample candidate. 위 수소 수송 두 대조는 원0.2%를 통과했다. 전체 H가 비슷하다는 검사만이 아니라 실제 원 수송률과 H-C 적분을 각각 비교했다. 원 광자 단계식은 그대로 두고 같은 해의 실제 충돌 이력을 물질에 전달한 결과다. 다만 C(t) 전달과 물질 적분법을 함께 바꾸었으므로 이 대조만으로 두 변화의 개별 기여나 전 구간 오차를 분리하지 않는다.

분류: Counterexample candidate. 물질 B/S/E/H 시간 차이는 각각2.28261%,0.557816%,0.446138%,0.380542%다. **B가 원2%를 실패했다.** 저장 상태만 추가 대조했을 때 새 물질 B/S와 광자가 소비한 기존 물질 입력 차이도64시계470.583%/24.8015%,128시계457.800%/24.5922%로 원0.2%를 실패했다. 작고 상쇄된 B의 상대 차이는 큰 분모로 숨기지 않는다. 최초 읽기 검사에서 B 정규화에 절대1을 사용한 오류도 보존하고 원1e-290 바닥의 성분별 L1으로 수정했다. 새 진화는 하지 않았으며 실패 판정은 변하지 않았다.

분류: Counterexample candidate. 바리온 시간 차이의 상위 셀은 대기143–149에 집중됐다. 이는 저장된 두 해의 유한 비교이며 유일 원인이나 균일 미분 보장의 증명은 아니다. H 전달 통과로 이 실패를 상쇄하거나 전체 결합 수락을 선언하지 않는다. 전체 기간·GR·최종 전하를 실행하지 않았다.

준비0.683초, 실제 단계 저장147.924초, 물질 반환15.543초로 각 등록 상한 이내에서 종료했다. 별도 저장 배열 읽기 비교는 총0.446초였다. 실제 단계 저장의 최대 RSS는약2.49GB, 물질 반환은약0.59GB였다. GPU나 새 배경 계산은 사용하지 않았다.

분류: Conjectural. 다음 진행 조건은 실제 단계 이력을 소비한 바리온·운동량 진화를 광자 입력에 상호 연결하고, 대기 바리온의 원 시간 기준까지 같은 예비 해에서 충족하는 것이다. 현재 새 물질 결과를 기존 입력에 손으로 더하거나 H만 강제 일치시키지 않는다. 새 격자·기간·연속 sweep을 자동 실행하지 않으며, 구체적인 연산자 수리와 측정 예산을 등록한 뒤 실제 결합 방정식에서 평가한다.
