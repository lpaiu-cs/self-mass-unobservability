# 단계129 — 보존 상태의 native EOS 압력을 실제 GR 전하에 적용

분류: Counterexample candidate. 저장된 내부19셀의 실제 보존 궤적에서 native EOS의 온도를 다시 풀고, 그 압력 차이를 기존 GR trace·반경 응력 원천에 적용했다. 정규화 내부 자유 scalar 끝점은 +1.021135582147e-27에서 +1.021133892155e-27로 바뀌었다. 변화는 -1.689992e-33, 원 신호 대비 약-0.000165501%다. 이 압력 표현 오차는 등록한2% 중요도 기준보다 작다. native EOS 전체 또는 최종 물리 전하를 인증한 결과는 아니다.

## 무엇을 고정하고 바꾸었는가

분류: Counterexample candidate. 기존128단계 경로의17개 저장 시각×19셀, 총323상태를 사용했다. 밀도·특정 내부에너지·중성수소를 유지하고 native 에너지 역산으로 온도를 구했다. 다른 이온·분자 재고는 기존 셀별 anchor를 따르며, 이동 재고의 기존 일차 보정은 명시적으로 유지했다. 따라서 native 역산 목표는 saved_u+inventory_u*xi, 판독 압력은 native_P-inventory_P*xi다. 실제 advected 조성 전체를 native로 다시 푼 것은 아니다.

분류: Counterexample candidate. 초기 체적 보정의 밀도 이동과 현재 질량 이동을 함께 반영했다. 온도 반복의 가속에는 기존 고정 재고 표의 ut를 사용했으나 수락은 native 에너지 잔차로 판정했다. 평형 EOS의 열미분을 고정 재고 미분으로 사용하지 않았다. native 전체323상태의 최대 상대 에너지 잔차는9.5814e-13, 밀도 차이는1.1546e-14, 기존 온도와의 최대 logT 차이는5.7623e-7이다.

분류: Proven. 선언한 내부 음향 모형에서 보존 에너지·질량·운동량을 고정하고 등방 압력만 delta_P만큼 바꾸면 셀 trace의 차이는-3*delta_P*V, E-P_r 응력의 차이는-delta_P*V다. 이를 기호 계산으로 확인했다. 이 항등식은 추가 물질 운동·복사 수송이나 완전한 GR 유체 역산을 증명하지 않는다.
