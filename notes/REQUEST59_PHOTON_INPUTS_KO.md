# 단계 59 — 같은 EOS의 광자 분리와 수송 입력의 수락 경계

분류: Counterexample candidate. **현재 5,735셀 배경에서 독립 광자를 도입할 때 필요한 물질 EOS 분리는 완료했다. 광자 충돌 응답과 물리 표면 유출의 결합은 아직 수락하지 못했다.** 실제 표면 조성·밀도에서 받은 평균 불투명도 자료는 통과했지만, 더 세밀한 그룹들이 같은 불투명도 함수의 적분이라는 전제가 후속 대조에서 실패했다. 이 실패를 보존하고 장기 GR 계산에는 투입하지 않았다. 이번 결과는 물질/광자 입력 연결의 loophole progress와 조건부 오차식의 theorem progress이며 전체 동적 전하 문제의 완료가 아니다.

## 완료한 물질/광자 분리

분류: Proven. native EOS가 포함하는 LTE 광자 에너지를 독립 복사장에 다시 더하면 중복 계산이다. 같은 컴파일 상수와 자유에너지를 사용하면 전체 텐서 수준에서 다음처럼 분리된다.

```text
T_total = T_native_LTE + (R - R_LTE) = T_matter + R
div R = -G,  div T_matter = +G
```

분류: Proven. 초기 R=R_LTE이면 기존 기계적 배경을 유지한다. 진공 분산의 질량 없는 광자에서는 trace(R)=trace(R_LTE)=0이므로 같은 rho,T,X에서 물질 trace가 native LTE trace와 같다. 이는 온도·계량·운동을 통한 광자 되먹임이 없다는 뜻이 아니다. 플라스마의 분산·편극 자유에너지는 이 항등식으로 해결되지 않는다.

분류: Counterexample candidate. 저장 원자료는 압력 모드이므로 밀도 모드 미분으로 변환한 다음 광자 압력·에너지·엔트로피·열용량과 밀도/온도 미분을 함께 뺐다. 전 5,735셀에서 물질 압력과 열용량이 양수다. 실제 6곳을 native 광자 제외 EOS 호출과 비교해 기존 상대 미분 기준 1e-7 및 에너지/엔트로피 기준 max(2 erg/g, 32 ULP)를 통과했다. 생산 시간은 0.371초다. 채택 입력은 `def-photon-matter-split/matter.npz`이며, 독립 광자의 실제 시간 진화에 사용됐다는 뜻은 아니다.

## 실제 표면의 원 불투명도

분류: Counterexample candidate. 실제 바깥 셀의 온도는 18827.947 K, 중성 원자 질량으로 환산한 밀도는 1.91629314435e-9 g/cm³다. 양의 조성 종을 빠뜨리지 않고 전하별 동위원소 평균 질량을 사용했다. TOPS의 사용 가능한 인접 온도 0.0015/0.002 keV에서 각각 256/999개 그룹과 단색 자료를 받았다. **실제 온도에서의 보간 오차 인증은 하지 않았다.** 표에 인쇄된 밀도 1.9163e-9를 실제 제출 밀도와 동일한 정밀도로 취급하면 안 된다. 저장 시험 loss 파일의 밀도 필드는 인쇄값이며, 향후 물리 충돌률에는 원 제출값과 그 오차 처분이 필요하다.

분류: Imported from prior work. [TOPS 공식 설명](https://aphysics2.lanl.gov/static/opacdocs/opac-help.html)은 그룹 평균과 단색 자료를 제공하고, 밀도 범위 밖 대체 및 plasma cutoff 규약을 설명한다. [ATOMIC 원 논문](https://arxiv.org/abs/1601.01005)의 흡수·산란 물리 모형도 사용 범위에 속한다. 이 자료의 내부 LTE 원자 모형이 현재 물질 EOS와 모든 원자 상태에서 일치한다는 인증은 없다. 이번 쿼리는 cutoff를 끈 기존 진공 광자 EOS의 조건부 입력이며, in-medium 광자 모형 완성이 아니다.

분류: Counterexample candidate. 4개 원 쿼리는 입력 인쇄 구간·조성 ID·경고 부재·양수 및 유한성·1e10 sentinel 배제를 통과했다. 그룹을 재합성한 Planck/Rosseland 평균은 native 값과 최대 4.7103e-5, 두 그룹 수의 재합성 차이는 최대 4.7516e-5로 원 1e-3 기준 이내다. 하지만 그룹 Planck 흡수를 주파수에 일정한 계수로 대체하면 999개 그룹에서도 Rosseland 평균이 14.0–18.6% 바뀐다. 평균을 통과한 자료로 유일한 동적 충돌률을 정할 수 없다. 단색 자료의 Planck 재적분 불일치도 보존하며 임의 정규화를 곱하지 않았다.

## 동적 손실 응답의 조건부 오차식

분류: Proven. 정규화된 양의 주파수 측도 mu와 k>=f>0을 가정한다. H=E_mu[1/k], M=E_mu[k], a=1/H로 두고 dnu=dmu/(kH)로 재가중하면 E_nu[k]=a, Var_nu[k]=M/H-a²다. c=(M-f)/(1-fH)인 두 점 Radau 측도는 이 두 모멘트를 보존한다. f=a인 상수 분포는 별도 극한으로 오차가 0이다.

분류: Proven. r>0에 대해 다음 식이 성립한다. 이 문단의 주장은 정확한 모멘트와 공통 측도의 존재를 가정한 해석적 정리다.

```text
0 <= 1/(a+r) - E_mu[1/(k+r)]
  <= r (M-a) / [(f+r)(a+r)(c+r)]

|1/(a+i*w) - E_mu[1/(k+i*w)]|
  <= 2 sqrt(2) * real_bound(r=|w|)
```

분류: Proven. Radau 상계는 이차 다항식 P2의 나머지
`P2(x)-1/(x+r)=(x-f)(x-c)^2/[(x+r)(f+r)(c+r)^2]>=0`
에서 따른다. 복소 상계는 정확한 중심 모멘트 전개와 `|k+iw| >= (k+|w|)/sqrt(2)`를 사용한다. r 또는 r²의 유리함수 최대점을 구하면 손실 resolvent와 `1-s*resolvent`의 전 시간 주파수 상계가 된다. 이는 산란의 각도 gain이나 방출/흡수의 물질 교환 연산자가 아니다.

분류: Counterexample candidate. 구현은 인쇄 불투명도 상대 구간 ±5e-5, 단조적인 Bprime/B의 그룹 내 범위, 선언한 log-PCHIP 산란 곡선의 최솟값을 사용했다. 산란 보간 및 원 물리 모형의 오차 인증은 없다. 24/48점 구적 비교와 배정밀도 최대점 탐색도 엄밀한 부동소수점 구간 인증이 아니다. 기호 항등식 및 100개 양의 유한 분포의 8,200개 복소 주파수 대조는 통과했다. 이후 실제 native 그룹 사이에 공통 측도 합치성이 실패했으므로, 이 정리를 실패한 표에 적용한 숫자는 실제 광자 응답의 인증으로 채택하지 않는다.

## 예산, 채택 상태와 다음 결정

분류: Counterexample candidate. 장기 항성 적분은 추가하지 않았다. native EOS는 6회, CPU/BLAS 작업자 1개, GPU 0이다. 기록된 성공 회수 및 대조의 합계는 약 131.3초이며 준비·분석·문서 작업과 시간이 기록되지 않은 두 실패 pilot은 제외한다. 전체 물리 submit 시도는 73회(긴 명시 목록의 403 포함)다. 원 32쿼리, 집중 16쿼리, 출력 수정 16쿼리 등은 각 사전 예산과 저장 계획을 따랐고, 마지막 원자료 가법성 대조는 새 쿼리 2회·약 2.94초로 끝냈다. 후보 실패 뒤 해상도를 자동 확대하지 않는다.

분류: Conjectural. 다음에 필요한 것은 같은 흡수·산란 함수에서 Planck와 Rosseland 적분 및 동적 응답을 함께 재현하는 **일관된 원자료/적분 규약**이다. 현재 웹 그룹표를 더 세밀하게 받는 것만으로 이 병목이 해결된다고 가정하지 않는다. 원 단색 자료의 누락·구적 규약을 닫거나, 독립적으로 재현 가능한 다른 미시 입력을 확보해야 한다. 이 조건을 닫기 전에는 실패한 표를 정규화해 통과시키거나 새 장기 GR 경로를 시작하지 않는다.

분류: Conjectural. 그 다음에 같은 물질 EOS의 교환 원천, 각도·에너지 재분배, 실제 온도/밀도/조성 변화, 물리 대기의 광자 유출을 연결해야 한다. native 마지막 셀은 물리적 진공 경계가 아니므로 그곳에 임의의 vacuum 조건을 붙이지 않았다. 이전 속도 수렴 미달, 전체 열 원천, 비선형 되먹임·전하 공간·실제 구동·정적 비교·관측은 남는다.
