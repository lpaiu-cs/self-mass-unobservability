# 단계73 — 원 GR 식의 직접 전파와 남은 국소 속도 실패

분류: Counterexample candidate. **원 GR 방정식과 반경 열 입력을 그대로 적용한 직접 시간 응답에서 전체 평균은 개선됐지만, 기존 절단면 부근 속도는 미수렴이다. 원 실패와 전체 동적 전하 목표는 미완료로 유지한다.** 역변환의 주파수 범위를 자동 확대하거나 국소 성분을 판정에서 제거하지 않았다.

## 실제 적용

분류: Imported from prior work. 단계71의 같은 K,D, 반경 전도표, 처음 열유속0, 정확한 열 에너지 debit과 운동량 lift, 공간 격자 및 0.23080495568542375초 기간을 재사용했다. 이 계는 고정 배경에서 열 채널 강도에 대한 선형 유체·scalar·계량 응답이다. 단계70의 한 외곽 상태 광자 표를 전 반경에 넣은 결과나 완전한 비선형 진화가 아니다.

분류: Proven. 무차원 시간 tau, 미시 rate lambda에 대한 한 pole의 누적 에너지는 다음 변환을 갖는다.

```text
E(tau) = amplitude * tc * [tau + (exp(-lambda*tau)-1)/lambda]
E_hat(s) = amplitude * tc * lambda / [s^2*(s+lambda)]
(K - s^2 D) u_hat = F_hat + K H_hat
y = u - H,  u(0)=u_prime(0)=0
```

분류: Proven. 이 식은 원 제약과 원천의 대수적 재표현이다. D를 역행렬로 만들거나 관성을 수정하지 않는다. 실제 유한 주파수 역변환의 오차가 작다는 정리는 아니다.

분류: Counterexample candidate. Bromwich 선 sigma=6, 주기4의 주파수513개를 풀고, 같은65개 시각에서 128/256/512 절단의 비가중 Fourier 합으로 응답을 복원했다. 필터·평활화·수송 pole 변경은 없다. 세 수는 주파수 구적 절단이며 기존16/32/64 시간 단계를 통과했다고 바꿔 부르지 않는다. 기준의 상대 차이2%, 차수1.5와 원 네 성분을 유지했다.

| 성분 | 256–512 차이 | 구적 수렴 차수 | 판정 |
|---|---:|---:|---|
| 전체 속도 질량 RMS | 0.00578329% | 3.69099 | 해당 대조 통과 |
| 전체 scalar RMS | 0.000207859% | 5.47679 | 해당 대조 통과 |
| 기존 절단면 부근 속도 | **37.4005%** | **−3.85859** | 실패 |
| 새 지지 경계 부근 속도 | 0.000450269% | 3.37762 | 해당 대조 통과 |

분류: Counterexample candidate. 기존 절단면 끝점 속도는 절단128에서7.25471e-14, 256에서7.53340e-14, 512에서1.08089e-13 m/s로 변했다. 전체 평균에서 작은 차이가 나온다고 이 국소 민감도를 숨기지 않는다. 원 실패 해소 플래그는 false이며, 계획대로 계수·외부 경계·다른 Bromwich 선 대조는 실행하지 않았다. 전체 스펙트럼의 안정성과 엄밀한 인과 역변환 오차도 인증하지 않았다.

## 저장 해 재사용과 기각

분류: Counterexample candidate. 추가 GR 풀이 없이 같은513개 저장 해에 de Hoog 연분수 가속을 적용했다. 기존 절단면의 차이는16.7904%, 차수−6.63099로 여전히 미달했고 새 지지 경계도 차수 미달이었다. 알고리즘은 설치된 mpmath의 Q-D/연분수 구현을 벡터화했으며, binary64 구현을 임의 정밀도 계산으로 부르지 않는다. [원 방법](https://doi.org/10.1137/0903022).

분류: Counterexample candidate. 알려진 진동자 대조에서 느린 omega=3은 작은 오차였지만 빠른 omega=300/600은 가장 큰 절단에서도 진폭 척도 오차가 약1.48/1.00이었다. 따라서 느린 대조 하나의 통과를 빠른 GR 파동의 정확성으로 확대하지 않고 이 가속 구현을 기각했다. 실행 전 첫 호출의 Python 구문 오류를 수정한 뒤 계산했으며 그 호출에서는 GR 풀이가 없었다.

## 비용과 다음 병목

분류: Counterexample candidate. 실제16개 선형 풀이가1.549초였다. 최초 전체 조건부 경로의240초 예산은 실측 보수 추정343.53초를 담지 못해, 생산 전에 같은 경로 수의 상한을400초로 재평가하고 원 pilot 계획·소스를 보존했다. 실제 생산은54.806초·최대0.740GB에서 실패 분기로 종료했다. pilot의16개 해를 재사용해 총 새 GR 선형 풀이는513회이며, 저장 해의 가속 역변환은22.880초였다. 새 EOS 호출과 충돌 상태 계산은0이다. 기동·기호 대조·저장 재검사 시간은 이 생산 시간과 구분한다.

분류: Counterexample candidate. 독립 저장 검사는 소스 결속, pilot 재사용, 직접 Fourier 끝점, 원 네 읽기와 두 미달 판정을 재현했다. 주파수 해·실제 상태·실패 원본을 함께 보존했다.

분류: Conjectural. 다음은 원 descriptor 계의 강제되는 파동을 직접 전파하면서 국소 속도의 미해상 꼬리 오차를 제어하는 것이다. 기존 감쇠 적분법에서 작았던 성분을 참값으로 고정하거나 역변환 평활화로 없애지 않는다. 같은 K,D의 제약을 유지한 모드/행렬함수 전파와 그 잔여 오차를 다뤄야 한다. 추가 입력 인증, 자동 주파수 확대, 전체 RMS만의 수락은 이번 병목의 해법으로 세지 않는다.
