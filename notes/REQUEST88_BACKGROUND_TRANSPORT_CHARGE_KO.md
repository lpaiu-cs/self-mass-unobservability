# 단계88 — 실제 배경 변화의 수송 경로를 궤도 전하에 전달

분류: Counterexample candidate. 단계87에서 실제 진화한 온도·밀도 변화를 반경별 복사 불투명도에 적용하고, 갱신된 복사 전도도·유속 완화율·적색편이 온도 인자를 같은 궤도 구동의 열·GR 연립식에 넣었다. 첫 세 조화의 외부 전하를 다시 계산했다. 짧은 시간의 경계 scalar 자체를 관측 신호로 읽거나 작은 외곽 질량 비중으로 영향이 없다고 가정하지 않았다.

분류: Counterexample candidate. 이것은 **수송 입력을 통한 유한 변화**다. GR 구조·계량·EOS 열역학 접선·미시적 전자 전도와 외부 파동 전파는 고정했다. 원래 비균일 배경을 새 평형 별로 재구성한 계산, 계수의 순간 미분까지 포함한 전체 되먹임, 실제 대기, 궤도 기간의 비선형 배경 진화는 아니다. 이 범위를 넓혀 전체 배경 오차 상계로 쓰지 않는다.

## 실제 입력과 원래 수락 기준

분류: Proven. Eulerian 밀도 변화는 Lagrangian 바리온·계량 변화에서 변위 곱하기 배경 밀도 기울기를 뺀 값이다. 열 에너지는 온도식에 독립적으로 들어가므로 delta lnT를 단열 계수로 나눈 값만을 밀도 변화로 쓸 수 없다. 온도식에서 복원한 밀도와 직접 바리온·계량식을 각각 사용했다.

분류: Counterexample candidate. 단계87의 p4-64, p4-32, p2-64 끝점을 재사용했다. 원 조성을 유지하고 rho_new=rho_old exp(delta lnrho), T_new=T_old exp(delta lnT)에서 같은 불투명도 표를 다시 평가했다. 각 셀의 Krad=16 sigma T^3/(3 rho kappa_R), 각 면의 복사 유속 완화율 및 theta=A N T를 갱신했다. 새 EOS 계산과 새 시간 적분은 없다.

분류: Counterexample candidate. 사전 기준은 GR·열 원식 잔차 1e-9, 에너지 수지 2e-13, 상호성 1e-5, **전하 변화 자체**의 시간 대조 1%와 공간 대조 2%다. 큰 원 응답의 수렴으로 작은 차이의 수렴을 대신하지 않는다. 실패 시 자동 해상도·기간 확대를 금지했다.

## 첫 실패의 원인과 수정

분류: Counterexample candidate. 첫 결합 인수분해는 원 4GB 상한에서 MemoryError로 종료했다. 무변화 입력 대조를 하자 온도 맵의 상대 변화가 1로 나왔다. 원인은 native 열 배열의 바깥→안쪽 면 번호와 누적 에너지의 안쪽→바깥쪽 면 번호를 혼용한 것이었다. 본 단계의 새 갱신 코드에 생긴 오류이며 단계86 원 계산은 수정하지 않았다.

분류: Counterexample candidate. 원 bank의 native 면 순서로 계수·온도 행을 조립하고 에너지 열에만 active edge 번호를 사용하도록 수정했다. 갱신은 원 맵에 delta theta 항만 더한다. 변화 0에서 Gq·GE·gL·전도도·완화율이 기존 값을 정확히 재현하는 대조를 추가했다. 원 입력·문턱·해상도·메모리 상한은 유지했고 최초 소스·계획·실패·진단을 보존했다. 수정 후 첫 결합 해는 0.544초, 관측 메모리 약0.771GB로 통과했다.

## 정적 비교의 결론과 다음 결정

분류: Proven. 고정 선형 연산자 L의 affine 식 xdot=Lx+b0+b_drive에서 배경 particular 해와 조화 강제 해는 중첩된다. 배경이 움직였다는 사실만으로 조화 전달함수의 변화량을 얻을 수 없으며, 그 주장을 하려면 상태에 따른 연산자·입력·읽기의 변화를 포함해야 한다. 이번 유한 수송 갱신은 그 일부만 측정한다.

분류: Conjectural. 성과는 loophole progress: 실제 배경 변화에서 수송 입력, 결합 GR 해, 외부 전하, 정적 비교까지 한 경로를 계산했다. 이 작은 항만을 위해 공간·기간을 늘릴 근거는 얻지 못했다. 남은 주된 물리는 동일 배경의 물질/EOS·구조 변화와 실제 native 외부·대기 연결이다. 실패한 공간 판정은 보존하고, 전체 목표는 미완료로 유지한다.
