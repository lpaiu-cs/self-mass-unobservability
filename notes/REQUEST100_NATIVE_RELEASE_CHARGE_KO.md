# 단계100 — 보존 대기 유출의 직접 지연 전하 응답

분류: Counterexample candidate. 단계99에서 저장한 비선형 구면 기체 유출을 **바깥으로 전파되는 스칼라 파의 직접 Green 성분에 실제 적용했다.** 내부로 넘어간 바리온은 반대 부호의 국소 음향 응답으로 연결했다. 끝점의 정규화된 직접 성분은 `delta_alpha_direct=-2.5896961e-30`이다. 고정 배경의 지정 원천에 대한 직접 전파 결과이며, 계량·스칼라·물질의 전체 되먹임을 포함한 최종 전하는 아니다.

## 계산한 양과 큰 정지질량의 상쇄

분류: Proven. Einstein 반경을 `r`, 스칼라 결합을 `alpha`, 물질의 Jordan 계량을 `a=A*N`으로 쓰자. `U=r*delta_phi`, `dr_star/dr=1/(N*sqrt(b))`에 대해 퍼텐셜과 간접 계량 원천을 제외한 방정식은 다음과 같다.

```text
U_tt - c² U_rstar_rstar = -4*pi*G/c² * N²*alpha*A⁴*r*delta(e-3p)
Q_direct(u) = -G/(2*c³) * integral w(r) * H_delta(trace*dV)(u+d(r))
w(r)=alpha*A*N/r
d(r)=[r_star(r)-r_star(R)]/c
dV=4*pi*A³*r²*dr/sqrt(b)
```

분류: Proven. 이는 외향 직접 파동의 적분식이다. 현재 짧은 인과 구간에는 중심에서 되돌아오는 항이 없다. 이 식을 사용했다고 배경 퍼텐셜의 산란이나 물질·광자 응력의 간접 계량 원천이 사라지는 것은 아니다. `delta_alpha_direct=-Q_direct/M_geom`으로 정규화하고, Bondi 질량 변화는 별도 항으로 남긴다.

분류: Proven. `D=rho*W`일 때 `e-3p=c_X*c²*D + [rho*u-3p+c_X*c²*(rho-D)]`다. 전체 바리온 변화의 합은 층, 내부와 희박 꼬리를 합치면0이다. 따라서 정지질량 항을 셀마다 다음처럼 계산할 수 있다.

```text
w_i*[H_deltaB_i(u+d_i)-H_deltaB_i(u)] + (w_i-w_ref)*H_deltaB_i(u)
```

분류: Counterexample candidate. 큰 기존 항성 질량에서 작은 변화를 빼지 않았다. 저장된 변화량, 보존식을 유지하는 공통 선형 시간 보간과 위 중심화식을 사용했다. `rho-D`도 `-D*v²/(1+sqrt(1-v²))`로 계산했다. 배경 함수가 표면 밖에서 스칼라 값을 상수로 반환하는 부분은 기존 진공 해의 실제 미분을 적분해 전하 가중치와 광행시간을 구성했다. 저장된 기체 진화 자체는 수정하거나 재실행하지 않았다.

## 내부로 넘어간 물질의 실제 음향 응답

분류: Proven. 내부 경계의 누적 바리온 유입을 `B_port(t)`라 하고 내부 방향 깊이를 `y`로 잡으면, 일정한 국소 음향 계수 아래의 입사 응답은 `deltaB/dy=-B_port'(t-y/v_ac)/v_ac`이며 `v_ac=(a/B)*c_s*c`다. 공간 적분은 정확히 `-B_port(t)`다. 광행 지연까지 적용하면 그 시간 적분은 `-H_Bport(u+d_i)/(1+c_s)`가 된다. 이 국소 음향 문제의 해와 전체 비선형 내부 경계 접합은 구분한다.

분류: Counterexample candidate. 경계와 안쪽80m에서 native 기체 EOS를4회만 새로 평가했다. 경계 음속은17.892km/s이고, 끝점에 약61.38m 안쪽까지 응답이 전파됐다. 계산한 최대 밀도 변화율은3.16e-6, 최대 속도 변화는0.0565m/s다. 전하 원천에 이 음향 응답을 적용하고 실제 밀도·압력·속도 프로파일도 저장했다. 해당80m에서 배경 밀도 변화는0.218%였다. 이 측정은 국소 계수 근사의 엄밀한 오차 보증은 아니다.

분류: Counterexample candidate. 실제 내부 에너지 유입과 순수 단열 음향 에너지의 끝점 차이 `4.86015e18 erg`는 별도 이력으로 보존했다. 이를 임의 열원으로 넣지 않았다. 그러므로 내부 바리온의 음향 연결은 실행했지만 내부 에너지·응력 경계 전체가 닫혔다고 보고하지 않는다.

## 희박 꼬리·질량 정규화와 아직 빠진 항

분류: Proven. 양의 꼬리 바리온이 `M_tail` 이하이고, 위치·지연 범위와 가중치의 진짜 상계가 주어진다면 중심화된 정지질량 직접 성분은 `G*c_X/(2*c*M_geom)*M_tail*(sup|w-w_ref|*T+|w_ref|*sup|d|)`로 제한된다. 비정지 trace도 특정 에너지·압력·속도 상계가 있으면 같은 Green 적분으로 제한된다.

분류: Counterexample candidate. 저장된 가중치 표본과 명시한 꼬리 전제에서 계산한 수치 추정은 정지질량 성분1.624e-35, 비정지 성분6.93e-39이다. 전제는 꼬리가 원 표면부터+1200m 사이에 있고, 속도가0.001c 이하이며, 비에너지와`p/rho`가 native 하한 상태의 지정 최댓값 이하라는 것이다. 이는 누락 EOS와 연속 가중치 극값을 구간 인증한 상계가 아니다. 최초 출력의 `Proven` 표지가 수치 추정까지 포괄한 문제를 발견해 원 파일·생산 소스를 보존하고 `Counterexample candidate`로 정정했다. 수치나 수락 문턱은 바꾸지 않았다.

분류: Counterexample candidate. 지정한 짧은 구간에 방출된 광자, 두 이력의 광학 깊이 제한과 탄성 산란만을 전제하면 질량 정규화 성분의 추정 척도는6.11e-34다. 이미 바깥에 존재하던 광자, 흡수·방출, 비평형 화학이나 광자 응력의 간접 스칼라 원천을 포함하는 전체 전하 상계가 아니다.

분류: Conjectural. **다음 결정적 병목은 고정 원천의 직접 전파를 완전한 물리 응답으로 닫는 것**이다. 특히 빠진 내부 에너지·응력 접합과 계량 매개 원천을 적용하고,3.4ms 팽창 동안의 화학평형·흡수 가정이 유출을 바꾸는지 판정해야 한다. 새 장기 적분이나 촘촘한 기체 경로를 자동 실행할 근거는 현재 없다. 단일 경계 해제의 직접 파형이 존재한다는 사실만으로 자유로운 정적 EFT 비교군을 벗어났거나 관측 가능한 완화 상태를 발견했다고 결론 내리지 않는다.

## 완료 경계와 예산

분류: Counterexample candidate. 이번은 저장된 비선형 유출에서 실제 외향 직접 전하를 계산한 loophole progress다. 보존 중심화와 음향 적분 항등식은 theorem progress다. 전체 GR/scalar 되먹임, 완전한 광자·화학, 물리적 희박 꼬리, 최종 전하, 관측 비흡수성 및 전체 목표는 미완료다.

최초 실제 판독과 native4회에는1.775초가 걸렸고, 등록한120초 상한에 대해 전체 예상은8.875초였다. 실제 네 판독은 총4.036초, 별도 기호·제조 원천 대조0.181초, 원 저장 이력의 독립 대조0.953초였다. 유체 추가 단계와 전체 항성 추가 적분은0이다. 프로세스 시작·import 시간은 이 내부 시간과 별개다. OSK의 기존 엔진 불일치에는 해소 근거가 없어 장기 기억 갱신 완료로 보고하지 않는다.
