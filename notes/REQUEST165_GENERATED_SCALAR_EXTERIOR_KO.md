# 단계165 — 생성된 scalar의 외부 혼합 응력과 에너지 흐름

분류: Counterexample candidate. **저장 원천으로 생성된 scalar의 외부 혼합 기여를 전하 상계에 연결하고, 빠져 있던 scalar 방출 에너지 채널을 질량 정규화에 포함했다.** 새 선택 부문의 전하 상계는 `2.2814693565846563e-57`이다. 기존 외부 기여와 합해도 저장 선택 전하의 `0.7140422%` 이하여서 조건부 음의 부호가 유지된다.

분류: Counterexample candidate. 그러나 더 결정적인 결과는 **이번 외부 광자·scalar 부문만으로 종료 시각의 질량 잔여를 없앨 수 없다는 것**이다. 그 성분들을 모두 허용한 질량 구간은 `[-3.539414890019726e-50, -1.5398290888839834e-50] cm`이며 0을 포함하지 않는다. 이것은 지정 부문에 대한 제외 결과다. 아직 포함하지 않은 원천까지 배제한 전체 GR no-go나 정확한 ADM 보존 실패의 확정은 아니다. 다음 우선순위는 질량 경계값·에너지 기준과 남은 원천의 연결이다.

## 실제 재사용한 배경

분류: Counterexample candidate. 단계160에서 합친 현재 compact 원천의 **531셀·33시각** 표현을 사용했다. 초기 canonical scalar 연산자에 대한 실제 물질·광자 forcing이며, 해당 원천의 공간 다항식과 선형 시간 표현 전체를 절댓값으로 제한했다. 원래 양의 광자 방출 외에도 단계151·152·153의 실제 signed SDIRK 방출 기록을 생성 scalar의 원천에 포함했다. 새 EOS 근·유체 단계·광선 이력은 계산하지 않았다.

분류: Counterexample candidate. 계산한 상계는 `|U_B|≤6.548073663242518e-19 cm`, `|∂xU_B|, |∂tU_B|/c≤6.359720405835653e-27`이다. 여기서 `U_B=r f_B`다. 이는 보수적인 원천 상계이며 측정한 파동 진폭이나 전체 EOS 오차의 인증값이 아니다. 입력 I는 이전과 같은 정확 primary와 유한 원천의 첫 Born 성분이다.

분류: Proven. 생성 scalar의 외부 미분 상계는 moving-shell 원천을 과거 광원뿔과 교차시켜 얻을 수 있다. 광자 껍질의 `(1−μ²)`와 교차 Jacobian의 `1−μ`가 결합해 `1+μ≤2`가 되므로 접선/방사 방향의 겉보기 특이성을 그대로 확대하지 않는다. 정적 퍼텐셜 반복은 원 저장 연산자의 수축 상계를 통해 포함했다.

## 혼합 질량·일·에너지 흐름의 항등식

분류: Proven. 외부 진공에서 `x_r=1/a`, `a=N√b`, `Φ=K/(ar²)`를 사용한다. 두 scalar 성분의 일차 질량 적분상수는 이 분해에서 각각 0이고, 계량 성분은 `λ_B=ΦU_B`, `λ_I=ΦU_I`다. 혼합 제약의 보조 질량 `C=N J_BI/√b`에는 다음 항들이 함께 들어간다.

```text
E_cross = U_B,x U_I,x + U_B,t U_I,t / c² + V U_B U_I
∂x C = E_cross − ∂x(a U_B U_I / r)
V = a a_r/r − 2 N² Φ²
```

분류: Proven. 공간 미분의 곱만 질량으로 세면 잘못이다. 자유로운 incoming/outgoing 성분은 `U_I,x=U_I,t/c`, `U_B,x=−U_B,t/c`이므로 앞의 두 에너지 항이 정확히 상쇄된다. 반면 두 outgoing 성분은 무한원에 에너지 흐름을 만든다.

분류: Proven. `U_tt/c²−U_xx+VU=S`에 대해 다음 식을 직접 미분해 확인했다.

```text
F_cross = U_B,t U_I,x + U_I,t U_B,x
∂t E_cross = ∂x F_cross + U_B,t S_I + U_I,t S_B

무한원의 outgoing 성분:
F_cross = −2 U_B,t U_I,t / c
ΔM_scalar = (2/c) ∫ U_B,t U_I,t du
```

분류: Proven. 따라서 실제 보존 판정에는 내부 경계의 에너지 흐름과 원천이 한 일도 필요하다. 위 기호 항등식만으로 저장된 물질·광자·scalar 해의 ADM/운동량 제약을 수락할 수 없다. `ΔM_scalar`는 두 성분 사이의 부호 있는 교차 에너지이며 새 양의 광자 재고가 아니다.

## 외부 특해와 아직 맞추지 않은 경계값

분류: Proven. 관측 영역 `t≥0`, `t−x/c≤T`에서 미래의 내부 이력을 가정하지 않으려면, 혼합 제약을 더 큰 반경에서 안쪽으로 적분하는 특해를 사용할 수 있다.

```text
C_part(x,t) = −∫_x^∞ E_cross(y,t) dy − a U_B U_I/r
C(x,t) = C_part(x,t) + H(t)
```

분류: Proven. 이 특해는 고정 유한 시각의 공간 무한대에서 추가 질량이 0이다. **일반 해의 `H(t)`까지 0으로 정한 것은 아니다.** `C_part(R,t)`는 보통 비영이며 저장된 내부 질량 경계값과 접합해야 한다. 적분에 쓰는 외부 점은 더 이른 retarded 시각에 있어, 관측 구간 뒤의 항성 진화를 새로 가정하지 않는다.

분류: Counterexample candidate. 이번 전하 상계는 이 외부 특해와 그 scalar 방출 에너지에 적용했다. 새로 필요한 내부 접합 보정은 아직 전체 전하 구간에 넣지 않았다. 전체 물리적 전하나 물리적 미래의 보존 해를 이 특해와 동일시하지 않는다. 기존 비영 homogeneous 질량 잔여는 단계163 그대로 유지한다.

분류: Proven. 두 방향의 계량 작용은 다음 발산형으로 바꿔 tiny 파형의 이차 유한차분을 피했다.

```text
O_ζ[U] = ∂x(ζ U_x) + ∂t(ζ U_t/c²)
         − 2ζ V_geom U − ζ(U_tt/c²−U_xx) − a ζ_x U/r
```

분류: Counterexample candidate. 내부 경계항, 광원뿔 경계항, 매끄러운 항, 첫 Born 원천, 실제 방출 광자 원천을 각각 절댓값으로 제한했다. 혼합 질량 제약과 초기 scalar 기울기의 곱도 포함했다. 단계160에서 이미 상쇄한 primary 경계에는 보수적인 여유가 남을 수 있으나, 기존 중심값에 그 경계를 다시 더하지 않았다. 퍼텐셜 반복에는 단계164의 가중 수축 상계 `2.1430858601669983e-6`을 사용했다.
