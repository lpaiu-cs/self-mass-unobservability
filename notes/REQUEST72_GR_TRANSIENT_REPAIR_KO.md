# 단계72 — 실제 GR 과도응답의 정밀도·적분 차수·관성 후보 재판정

분류: Counterexample candidate. **같은 GR 경로에서 반올림 오차와 적분 차수를 분리했고, 공간 관성 후보까지 실제로 진화시켰지만 원 수렴 실패는 아직 해결하지 못했다.** 확장 정밀도는 응답을 약1e−12 이내로 재현했다. 5차 Radau도 전체 속도 시간 차수에 미달했고, 평탄한 파동식의 관성 보정을 GR에 직접 넣은 후보도 거부했다. 이번 실패를 수락이나 전체 목표 완료로 바꾸지 않는다.

## 실제 같은 입력의 정밀도 및 시간 적분 대조

분류: Imported from prior work. 단계71의 같은 반경 전도표·정적 GR 배경·에너지 debit·열 운동량 lift·유체·scalar·계량 연산자 K,D를 사용했다. 기간0.23080495568542375초, 공간 격자, 원16/32/64단계와 계수·외부 경계 대조 및 수락 문턱을 유지했다.

분류: Counterexample candidate. 먼저 원2단계 Radau의64단계 경로를 확장 정밀도의 원 stage 방정식 잔차와 반복 정제로 다시 풀었다. 기존 구현은 복소 고유변환 뒤의 선형계 잔차를 검사했지만 새 계산은 원 stage 연립식의 잔차를 직접 정제한다. 기존 이력 대비 차이는 전체 속도2.4701e−13, scalar1.0399e−12, 기존/새 경계 부근 속도2.4001e−13/3.2615e−13이었다. 따라서 이 시험의 선형 풀이 반올림이 약1e−3 수준 시간 차이의 주원인이라는 설명은 지지되지 않는다.

분류: Proven. 3단계 Radau IIA의 Lagrange 적분 표를 구성하고 안정성 함수를 기호 계산했다.

```text
R(z) = (1 + 2z/5 + z²/20) / (1 - 3z/5 + 3z²/20 - z³/60)
R(z) -> 0 as z -> -infinity
```

분류: Counterexample candidate. 해를 아는 제약 진동자의 전체 위상 상태는 차수4.9722/4.9931이었다. 이 대조를 통과한3단계·5차 방법을 실제 GR 다섯 경로에 적용했다. 행렬의 양의/음의 큰 주파수 모드를 해상했다는 보증은 별도로 얻지 않았다.

|---|---:|---:|---|
| 전체 속도 질량 RMS | 0.0204394% | **−0.355131** | 미달 |
| 전체 scalar RMS | 0.00557858% | **1.293933** | 미달 |
| 기존 절단면 부근 속도 | 0.0852294% | 1.964782 | 시간 대조 통과 |
| 새 지지 경계 부근 속도 | 0.000675212% | **0.196459** | 미달 |

분류: Counterexample candidate. 계수·외부 경계·열수지·선형 잔차는 원 기준 안이지만 시간 대조 미달을 구제하지 않는다. 정밀도 경로를 포함한6개 실제 경로는60.271초·최대0.369GB였고 사전180초·3GB 한도 안에서 끝났다. 원 수락 기준을 완화하거나 시간 단계를 늘리지 않았다.

## 확인한 공간 중점 관성의 한계

분류: Proven. 일정 계수 파동식의 1차 공간 연립식을 중점 이산화하면, 균일 격자의 Fourier 파수 theta에서 고유값은 `−4 c² tan²(theta/2)/h²`다. 선형장 제곱의 정확한 셀 적분과 중점 적분의 차이는 `(right-left)²/12`이며, 중점 질량에는 교대 부호 모드의 영방향이 있다. 정확한 선형 요소 질량을 쓰면 `−12 c² sin²(theta/2)/(h²(2+cos theta))`로 바뀌어 주파수 제곱이12c²/h² 아래에 있다. 이는 균일한 주부 파동식의 정리이며 전체 GR 실패 원인의 단독 증명은 아니다.

분류: Counterexample candidate. 실제 K,D의 무차원 주파수32·128·512 부근에서 각8개 모드를 제한적으로 조회했다. 최대 원 pencil 잔차는2.8390e−6이고 좌우 모드의 최소 겹침은7.93e−11이므로, 이 표본을 정밀한 전역 모드 오차 인증으로 쓰지 않는다. 유체 운동에너지 가중치로 계산한 중점/노드 관성 비는32부근 약0.633–0.638,128부근0.294–0.297,512부근 일부 모드에서0.0312–0.0323이었다. 조회는1.79초였으며 시간 경로나 EOS를 추가하지 않았다. 작은 중점 관성을 갖는 실제 모드가 있다는 사실과 그것이 전체 출력 오차를 얼마나 만드는지는 별개다.

## 실제 적용했지만 거부한 관성 보정

분류: Counterexample candidate. 위 균일 계수 한계를 고치는2차 작은 공간 보정을 별도 후보로 만들었다. 정적 K는 유지하고 D의 구성식 행0·2에 `h²(A B)/12`의 좌우 차이를 추가했다. 이 후보는 균일 파동식에서 양의 선형 요소 질량으로 환원된다. 그러나 전체 가변계수 GR 에너지·제약·열 운동량 원천과 수정된 보조 압력의 물리적 복원은 사전에도 미인증으로 명시했다.

분류: Counterexample candidate. 첫16단계 경로의 scalar RMS는 기존 약1.99056e−29에서2.73450e−26으로 약1,374배 변했다. 이를 보고 중단을 시도했지만 확인 시점에는 이미 다섯 경로가45.590초 안에 모두 끝나 있었다. 따라서 중단된 실행이라고 기록하지 않는다.

| 읽기 | 관성 후보 시간 차수 | 추가 실패 |
|---|---:|---|
| 전체 속도 | **−0.548777** | 시간 기준 미달 |
| 전체 scalar | 3.979895 | **계수 민감도6.0424%로2% 기준 미달** |
| 기존 절단면 부근 속도 | 2.573260 | 지정 시간 대조만 통과 |
| 새 지지 경계 부근 속도 | 4.999642 | 지정 시간 대조만 통과 |

분류: Counterexample candidate. 국소 차수의 개선으로 전체 실패를 숨기지 않는다. 이 관성 후보는 **채택하지 않는다**. 특히 수정된 보조 압력을 원 열역학 압력으로 사용하거나 이 후보로 native 물질·계량 완료를 주장하지 않는다. 원2단계 및5차 시간 경로와 거부한 관성 경로를 모두 보존했다.
