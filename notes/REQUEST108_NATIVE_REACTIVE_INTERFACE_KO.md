분류: Counterexample candidate. 기존 대기의 안쪽 경계 양편을 같은 유한 수소·광자 교환 식으로 진화시켜 **원 trace 공간 비교를 통과했다.** 448/896셀 차이는 `1.9117249%`로 원 `2%` 기준 이내다. 기준과의 여유는 작으며, 두 격자의 대조를 연속 오차 상계나 완전한 물리 인증으로 부르지 않는다. 단계107의 `7.7739%` 실패는 보존한다.

## 실제로 바꾼 물리적 연결

분류: Counterexample candidate. 기존 `[-200,1200]m` 대기 구간의 안쪽에 **200m의 실제 내부 유체**를 추가했다. 표면 상대 좌표 `-200m`는 고정 온도·조성 경계에서 두 진화 셀 사이의 공유 면으로 바뀌었다. 같은 EOS, 수소 반응, 광자 에너지·운동량 및 하나의 질량·에너지·종 유속으로 연결했다. 경계의 오차를 열로 더하거나 유속을 맞추는 보정항을 만들지 않았다.

분류: Counterexample candidate. 대기를 측정하는 원 격자 간격은 그대로이며 전체 셀 수만 `256/512/1024`가 됐다. 안쪽 추가 구간은 원 경계의 물리적 정의를 수정하기 위해 실행 전에 명시한 범위다. 기준 미달에 따른 자동 해상도·기간 확대가 아니다. 기존 `3.4344311179ms`, EOS 표, 반응률, 원 수락 문턱을 유지했다.

분류: Proven. 임의의 보존 변수에서 왼쪽·오른쪽 부분영역의 합은 `(F_0-F_j+S_L)+(F_j-F_N+S_R)=F_0-F_N+S_L+S_R`다. 공유 면의 전달은 두 영역 사이에서 정확히 상쇄한다. `physical/symbolic.json`은 이 대수적 명제만 다룬다. 실제 수치 수지는 저장한 전체 구간과 대기 부분구간의 차이로 독립 확인했다.

## 초기 온도 오류를 발견하고 실제 재계산한 이유

분류: Counterexample candidate. 첫 접합 계산은 trace 차이 `0.760866%`로 수치 기준을 통과했다. 하지만 실제 저장 배경과 대조하니 추가 내부에서 초기 온도가 최대 `0.313892%` 높았다. 기존 초기 엔트로피 표의 반경 범위가 옛 `-200m`에서 끝났고, 그보다 안쪽의 보간이 엔트로피를 끝값으로 고정했다. 그 값을 단열 EOS에 넣으면서 거의 등온인 실제 배경 대신 온도가 상승했다. **EOS 자체의 대조 통과가 초기 배경 일치를 보장하지 않았다.**

분류: Counterexample candidate. 이 첫 수치 통과는 원 입력의 결과로 그대로 보존했다. 모든 점유 셀과 기체 면의 `logT`를 저장된 실제 배경에서 직접 읽고, 원 밀도·계량·조성과 같은 EOS로 보존 에너지를 다시 초기화했다. 과거 대기 구간도 온도 근삿값 대신 실제 배경을 사용한다. 수정 후 저장 초기 온도는 해당 배경 보간값과 정확히 일치하며, native P/u 대조 최대 차이는 `7.159e-10`이다. 이후 같은 대기 448/896셀과 448셀 경계 대조를 실제로 다시 진화시켰다.

## 최종 전하에 아직 필요한 것

분류: Counterexample candidate. 유체 경계 조건의 영향이 작다는 결과는 스칼라 전하 원천 전체가 닫혔다는 뜻이 아니다. 같은 저장 계량과 직접 전파식에서 이 시간 구간의 스칼라 과거 광원뿔은 표면 아래 약 **1029.61km**까지 이른다. 이번 전체 유체 구간은 표면 아래 **400m**까지만 포함한다. 이 계산은 저장 계량의 전파 시간에 대한 수치 결과이며 계량 자체의 물리적 오차 인증은 아니다.

분류: Conjectural. 다음에는 실제 반응 내부의 체적 응력을 전하 원천에 넣고, 더 깊은 영역의 광자장·초기 열수지로 그 영역의 변화가 없거나 충분히 작음을 입증하거나 계산해야 한다. 질량 유입량만으로 만든 이전 동결 음향 내부 모형은 반응·광자 열원까지 대신하지 못한다. 작은 내부 구간을 계속 덧붙이는 방식이나 이전 전하 값을 재사용하는 방식으로 이를 완료 처리하지 않는다.

분류: Counterexample candidate. 이번 단계에서는 새 최종 전하를 선언하지 않았다. 단계107 전하 수치는 여전히 당시 실패한 유출의 진단 읽기다. 지정 Planck 광자장, 열역학 역반응, 고정된 다른 종 재고라는 가정은 유지된다. 미시적 역반응 인증, 비균일 전체 종 진화, 인과적 주파수별 광자 수송, 전체 GR/scalar 되먹임·꼬리·질량 정규화와 원 전체 GR 공간 실패는 남는다.
