# 단계113 — 저온 native EOS를 고쳐 실제 결합 진화 완주

분류: Counterexample candidate. **저온 EOS 때문에 멈췄던 실제 양방향 광자·움직이는 대기 진화의 원 fine 경로를 끝까지 계산했다.** 완전한 104단계 저장 상태에서 24단계만 이어서 원 128단계, 3.4344311179 ms에 도달했다. 새 구간의 보존·광자 양수성·실제 native 끝점 검사는 통과했다. 성공한 두 거친 경로와 이전 이력은 재사용했다. 전체 물리 전하의 완료는 아니다.

## 실패 원인과 실제 수정

분류: Counterexample candidate. 이전 200 K 상태에서 native H2+ 들뜬 분배함수가 먼저 overflow한 뒤 매우 작은 Boltzmann 인자와 곱해지고 있었다. 진단에서 그 곱의 인자는 약 `2.605e-150`인데 분배함수는 Infinity였다. 최종 곱이 유한해도 중간 계산이 무한대가 되어 내부 밀도 역산이 상태125로 실패했다. 전자 밀도 초기값 변경으로 해결되지 않았던 이유와 일치한다. 처음 잘못된 분배함수 배열 행을 읽었던 진단도 보존했다.

분류: Proven. 분배함수와 그 원래 1·2차 편미분에 같은 양의 지수 스케일을 나누면, 스케일을 복원한 물리적 곱과 미분의 비는 정확한 실수 산술에서 보존된다. 여기서 저장한 jet는 원래 미분을 스케일한 값이며 스케일된 함수 자체의 미분이 아니다. 구현한 Planck–Larkin 합 항의 두 미분을 기호적으로 확인했다. 유한 정밀도·양자수 꼬리·표 보간의 균일 오차 정리는 아니다.

분류: Counterexample candidate. 같은 native 준위·점유 법칙·제약을 유지하면서 차가운 분배함수 꼬리마다 공통 스케일을 사용했다. 이어 80 K에서 Python 광학 판독기가 극미량 들뜬 H 항의 누락으로 실패했다. 해당 비율을 로그로 보존해 흡수·역방출 지수를 곱하기 전에 합쳤다. 온도나 원소 재고를 잘라내지 않았다. 원 라이브러리는 보존하고 별도 후보 라이브러리를 빌드했다.

분류: Counterexample candidate. 실패 셀의 실제 native 에너지 근은 **170.31791785 K**, 상대 에너지 잔차는 **2.379e-12**였다. 80·120·160·240 K 제약도 통과했다. 기존 918개 상태를 재사용하고 80·120·170·200 K의 136개 상태만 추가했다. 240 K 이상은 원 보간기를 그대로 사용하며 재시작 104단계의 warm primitive가 비트 단위로 같음을 확인했다. 차가운 독립 네 상태의 구성 관계 최대 상대 차이는 `2.006e-6`, 양의 광자 교환 성분의 가중 차이는 `6.912e-5`로 원 `0.002` 기준을 통과했다. 전체 주파수 연속 오차나 모든 화학 채널의 인증은 아니다.

## 실제 원 경로의 결과

분류: Counterexample candidate. 실제 유체 셀 1024개, 내부 반경 셀 16개, 주파수 152개, 각도 8개와 원 시간 간격을 유지했다. 109단계의 기존 실패 지점을 통과했으며, 추가 186개 국소 SSP 단계로 마지막 128단계까지 도달했다. 추가 진화는 **106.16초 / 등록 상한190초**였다. 첫 다섯 단계 실측은22.86초, 보수적 총 예상168.15초였다. 전체 경로·해상도·기간을 추가하지 않았다.

분류: Counterexample candidate. 아래 보존 수치는 재시작104–128 구간의 별도 수지다. 원 스냅샷에 누적 ledger가 없으므로 전체 누적 수지를 복원했다고 하지 않는다. 이전 접두 구간의 보존 판정은 별도 증거로 유지한다.

분류: Counterexample candidate. 앞선 전체 시간 대조는 그대로 재사용한다. 내부 trace0.0917874%, 대기 trace0.518297%, 표면 스펙트럼0.739593%였다. 이번 수치는 지정된 초기 과도응답의 조건부 수치 결과이며 궤도 완화 검출이나 최종 scalar 전하가 아니다.

## 읽기 단계에서 보존한 실패

분류: Counterexample candidate. 재시작 wrapper가 응답 기준값 두 개를 잘못 잡았다. 내부 기준 압력을 원 초기값이 아닌104단계 값에서 계산했고, 대기 초기 온도를104단계 밀도에 대입했다. 이 두 값은 보고용 trace에만 들어가며 실제 진화·교환·보존 잔차에는 들어가지 않는다. 실행 중 소스를 수정하지 않았고 원 결과와 소스를 보존했다. 저장된 이력의 알려진 상수 오프셋을 바로잡았으며 실제 상태 배열은 바뀌지 않았다. 수정된 재시작 코드는 반복 실행하지 않았다.

분류: Counterexample candidate. **추가로 등록한 엄격한 읽기 검사는 아직 실패다.** 수정 뒤104–108의 trace 중첩 차이는 `1.3335e-8`로 등록한 `1e-8`을 조금 넘었다. 새 primitive 역산으로 독립 계산한 끝점 trace와 저장 이력의 차이는 `6.4195e-7`로 `1e-10`을 넘었다. 원 공간2% 이내라는 별도 결과로 이 실패를 덮지 않으며 `result.json.passed=false`를 유지한다.

분류: Proven. 보존 변수의 국소 비정지 에너지 `tau`, 운동량 `S`, 속도 `v`, 압력 `p`를 쓰면 같은 물질 trace는 `tau−S*v−3p`로 쓸 수 있다. 구성 관계에서 내부에너지를 다시 빼서 계산하는 표현과의 차이는 primitive 에너지 잔차에 대응한다. 이 항등식을 기호적으로 확인했다.

분류: Counterexample candidate. 저장된 동일 끝점을 원 `2e-11`과 더 엄격한 `2e-14` primitive 역산으로 읽었을 때 열에너지 재구성의 trace 기여는 약 `3.252e13 erg`에서 `3.264e10 erg`로 감소했다. 보존 표현의 끝점은 약 `3.9016442e21 erg`다. 이는 작은 차분 원천을 큰 열에너지의 재역산으로 읽을 때 생기는 민감성을 보여준다. 저장된 모든 시각의 온도가 남아 있지 않으므로 이것만으로 원 전체 이력의 엄격한 읽기 검사를 통과시킬 수는 없다.

## 남은 목표와 비용 경계

분류: Counterexample candidate. 이번 성과는 **실제 결합 진화를 막던 EOS 병목의 해결인 loophole progress**다. 중간 산술과 trace 항등식은 theorem progress다. 다음은 보존 변수로 저장 원천을 읽고 회복 오차를 전파하여 지연 scalar·질량 정규화에 연결하는 것이다. 읽기 문제 때문에 이미 완주한 진화를 바로 재실행하지 않는다.

분류: Counterexample candidate. 전체 내부의 기계적 움직임, 반경·주파수 오차, 모든 미시 반응, 계량/scalar 되먹임·꼬리·최종 질량 정규화는 남는다. 내부 밀도·계량 고정과 먼 안쪽 물질 ghost의 가정을 유지한다. `final_charge_solved=false`, `full_goal_complete=false`다.

기록된 native 호출669회와 별도 모델 생성 호출 상한36회를 보수적으로 합산한다. cold 상태136개 구축은8.89초였다. CPU 한 스레드로 실행했으며 최대 메모리 실측값은 없다. 실제 생산은 원 fine 경로의24단계뿐이며 성공한 coarse 두 경로를 반복하지 않았다. 단계 전 checkpoint는 `1297eba71`이다. 원 실패·실행 코드·Fortran 패치·새 데이터·해시 연결을 함께 보존한다.
