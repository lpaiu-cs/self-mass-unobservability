# Phase41 — 비영 배경의 외부 전하와 고정 재고 열 민감도

## 결과와 판단

분류: Counterexample candidate. **새 분자 EOS의 비영 scalar 배경을 무한대 외부 전하에 연결했고, 고정 재고의 정규화 열 민감도를 native EOS 차분과 대조했다.** Phase40의 온도 읽기에서 실제 전하 읽기로 한 단계를 연결한 loophole progress다. 이번 결과는 고정한 셀 반경·바리온·조성에서 정의한 구속 상태의 전하이며, 유체가 움직이는 실제 궤도 응답이나 정수압 평형의 완성은 아니다.

분류: Proven. 저장된 수치 계수를 정확한 입력으로 정의한 선도 미분 모형에서, `theta_i=delta ln T_J,i`에 대한 정규화 전하 `C=alpha_A/phi_infinity`의 미분은

\[
\delta C=\sum_i h_i\theta_i,\qquad
\sum_i|h_i|<1.144\times10^{-5}
\]

를 만족한다. 70자리 바깥쪽 반올림 구간 연산으로 스칼라 장·계량·질량 정규화를 모두 미분하고 양의 소거 pivot을 확인했다. 따라서 이 **선형·고정 재고 모형 안에서** 목표 `abs(delta C)>=1e-9`를 얻으려면 `max abs(theta)>=8.74126e-5`가 필요하다. 실제 EOS 미분 오차와 유한 변화의 나머지항을 포함한 물리적 상계는 아니다.

분류: Conjectural. 이전 선언 쌍성의 `phi0=0.001`, `delta_u=1.8837546e-7`과 `theta=phi0^2 delta_u G`를 사용하면 이 열 경로에 필요한 `max abs(G)`는 **약 `4.64034e8` 이상**이다. 실제 동적 유체 증폭을 계산한 값이 아니며, 반경 이동·셀 사이 바리온 재분배·조성 변화·다른 전하 경로에는 이 조건을 적용하지 않는다. 따라서 큰 필요 증폭을 확인했어도 쌍성 전체를 no-go로 닫지 않는다. 다음 계산은 긴 궤도 반복보다 이 동적 연산자와 반경 이동의 기여를 정규화하여 구하는 일이다.

## 이번 상태가 만족하는 것

분류: Counterexample candidate. Phase40의 24셀 전체 반경과 저장 바리온·조성을 사용한다. 각 셀의 Jordan 온도를 지정하고, `B_i=a_i rho_E,i V_i`를 유지하도록 밀도를 갱신한다. `rho_J=rho_E/A^3`, `T_E=A T_J`, `A=exp(beta phi^2/2)`로 실제 native EOS를 다시 평가하고, scalar 응력의 방사 질량 제약과 정적 scalar 방정식을 함께 고정점으로 푼다. 열유속이 있는 상태를 유지하므로 정적 scalar 읽기가 물질의 정수압·열평형을 뜻하지 않는다. 반경을 고정한 순간의 구속 Cauchy 상태다.

분류: Imported from prior work. 외부장은 기존에 검증한 `gr_scalar_nonlinear_exterior.exact`의 비선형 Just 진공 매칭을 재사용한다. 그 모듈은 [Damour–Esposito-Farèse 원문](https://arxiv.org/abs/gr-qc/9602056)의 식에 대응하며, 별도 진공 수치 적분과 대조한 산출물이 이미 있다. 이번에는 외곽에서 유한 반경을 잘라 무한대로 간주하지 않는다. 다만 유한 압력의 물질 표면은 여전히 선언한 벽 경계이고 물리적 대기를 진공에 접합한 항성은 아니다.

분류: Proven. 스칼라 행렬을 `K=L-P`라 하고 정규화 장을 `psi=1+w`로 쓰면 `K w=P 1`이다. 이 식과 source 합으로 외부 유속을 읽으면 `1-psi`나 작은 두 전하를 빼는 손실을 피할 수 있다. `C=J/mu`의 미분은 `dC=dJ/mu-J dmu/mu^2`다. 고정 바리온과 고정 부피는 `d ln rho_E=-d ln a`를 준다. 이 세 대수 관계를 기호 검산했다.

분류: Counterexample candidate. `phi_infinity=0.001` 배경에서 구한 전하는 다음과 같다. 0 배경 행의 값은 0으로 나눈 수치가 아니라 `phi_infinity→0`의 정규화 선형 극한이다.

| 항목 | 결과 |
|---|---:|
| 0 배경 선도 `alpha/phi_infinity` | `-4.00035008700714` |
| 비영 배경 `alpha/phi_infinity` | `-4.000350085060503` |
| 비영 배경 `alpha` | `-0.004000350085060503` |
| 표면 `R phi_prime` | `-1.69553850092822e-8` |
| 표면 `phi` | `0.001000016955313145` |
| 외부를 포함한 ADM 질량 길이 | `29168.6589035907 cm` |
| 배경의 바리온 상대 잔차 | `2.17e-19` |
| 배경의 scalar 상대 잔차 | `3.12e-18` |
| 외부장 매칭 잔차 | 저장 연산에서 0 |

분류: Counterexample candidate. 비영 배경과 선도 계수의 약 `1.95e-9` 차이는 **정적 배경 의존성**이다. 시간 지연이나 정적 비교를 제거한 새 신호로 세지 않는다. 이 차이 자체가 유한 배경 나머지항의 인증 상계도 아니다. `beta=0` 대조에서는 전하가 정확히 0으로 돌아갔다.

## 미분 대조와 조건부 구간 보장

분류: Counterexample candidate. native EOS에서 온도를 `±0.001`, `±0.0003`, `±0.0001`만큼 바꾼 뒤 매번 바리온·계량·scalar·외부 매칭을 다시 풀었다. 균일 온도 방향의 중앙 차분은 각각 `1.143555561e-5`, `1.143555325e-5`, `1.143555473e-5`였다. 선도 복소 미분값 `1.143556719e-5`와의 최종 상대 차이는 `1.09e-6`, 마지막 두 native 차분의 상대 차이는 `1.29e-7`로 사전 `0.005` 기준을 통과했다. 이는 선택한 방향과 스텝의 수치 대조다.

분류: Counterexample candidate. 사전 지정한 두 번째 방향은 미분 벡터의 부호 방향이었다. 이번에는 모든 성분이 양수여서 **균일 방향과 같아졌고 6개 상태가 중복 계산됐다.** 따라서 15개 실행 상태를 15개 독립 상태 또는 두 독립 미분 방향의 검증으로 보고하지 않는다. 서로 다른 상태는 9개, native 열 미분 방향은 하나다. 중복 파일과 `direction-audit.json`을 보존했고 추가 native 실행으로 원 15개 상한을 늘리지 않았다.

분류: Proven. 별도 구간 검사는 모든 24개 미분 성분을 실제 행렬식의 암시적 미분으로 계산한다. 삼대각 연산자의 양의 pivot은 영 커널이 없음을 보장한다. `K dw=dP 1-dK w`를 풀어 외부 유속과 질량 정규화까지 전달했다. 정확한 저장 계수 모형의 `sum abs(h_i)`는 약 `1.14355671932009946e-5`이며 유리수 상한 `0.00001144`보다 작다. 복소 미분과의 최대 절대 차이는 `4.24e-22`였다. 2×2 해석 해의 포함 대조도 통과했다.

분류: Proven. 같은 균일 방향에서 source·장·계량을 포함한 분자 미분 기여는 약 `5.60579e-6`, 질량 정규화 기여는 `5.82978e-6`이다. 이 선언 모형에서는 후자가 전체 미분의 약 절반이므로 질량 분모를 고정하면 올바른 전하 민감도를 얻지 못한다. 이 수치는 앞 문단과 같은 저장 계수 모형의 구간 계산이다.

분류: Conjectural. 물리적 EOS 도함수의 오차, 계수 생성·공간 이산화 오차, 유한 온도 변화와 유한 배경장의 나머지항, 움직이는 반경·조성, 정상적인 궤도 배경, 유체 응답의 resolvent는 구간 증명의 입력 밖이다. `1.144e-5`를 실제 항성의 모든 응답에 대한 상계로 확대하지 않는다. 좁은 증명의 조건을 유지하면서 다음 동적 미분으로 연결해야 한다.
