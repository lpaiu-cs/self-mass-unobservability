# 단계163 — 보존 원천의 질량 성분을 같은 전하 정규화에 적용

분류: Counterexample candidate. **이전에 lapse에만 사용하던 질량 잔여와 새 혼합 GR 질량 성분을 같은 최종 전하 식에 적용했다.** 두 부호가 상당 부분 상쇄되며, 선택된 전하 끝점은 `−2.5375925822713353e-51`에서 `−2.5375890992998707e-51`로 변했다. 추가 질량 정규화의 효과는 기존 절댓값의 약 **1.37255 ppm**이다. 지정한 성분에서 음의 부호가 유지된다. 이것은 실제 저장 원천의 질량항을 판독에 연결한 조건부 loophole progress이며, 추가 외부 혼합 응력이나 정확한 ADM 보존을 완료한 결과는 아니다.

## 질량의 정의와 저장 성분의 연결

분류: Imported from prior work. 구면 Einstein-frame의 `b=1−2m/r`, `λ=−log(b)/2` 정의 및 Hamiltonian/운동량 제약의 구분은 [Novak, 식 2.11·2.23·2.24](https://arxiv.org/pdf/gr-qc/9707041)를 따른다. 아래 혼합 전개와 전하 식은 저장소의 표기로 직접 유도하고 기호 검사했다. 이 논문의 항성 모형을 현재 EOS의 물리적 인증으로 사용하지 않는다.

분류: Proven. 두 독립 일차 증분 B,I와 혼합 계수 BI에 대해, 계량의 지수 표현을 미분하면 다음 식을 얻는다.

```text
m_BI = r b λ_BI − 2 r b λ_B λ_I
λ_BI = r Φ f_BI + J_BI/(r b)
```

분류: Proven. 따라서 유한 반경에서 `J_BI`만 읽는 것은 물리적 혼합 질량을 읽는 것과 다르다. 점근적으로 `f=O(1/r)`, `Φ=O(1/r²)`, `λ_B,λ_I=O(1/r)`인 성분에서는 첫 식의 알려진 곱과 `r²bΦ f_BI`가 무한대에서 사라진다. **현재 계산한 homogeneous 진공 연속 성분**에는 `N J_BI/√b`가 대응한다. 하지만 추가 외부 혼합 원천을 적분한 값은 여기에 별도로 들어간다. 이번 계산은 그 미계산 원천을 0으로 판정하지 않는다.

분류: Counterexample candidate. 이전 incident 응답의 저장 질량항은 `C_I=N J_I/√b+(G/c⁴)E_emitted`다. 내부 보존 원천과 이미 방출된 photon의 debit을 함께 포함하므로, 이 항을 다시 새 방출 에너지로 추가하면 안 된다. 같은 초기 진공 정규화에서 새 mixed 성분 `C_X`, 기존 자체 GR 반환과 단계162 실제 수송 반환의 질량항을 각각 더했다. 마지막 반환 항은 저장된 실제 원천을 기존 구적 소유자에 투영했다. 새 EOS·유체·광선 경로를 계산하지 않았다.

분류: Counterexample candidate. 정밀 경로의 끝점은 다음과 같다. `cm`는 `G M/c²`에 해당하는 질량 길이 단위다.

| 항목 | 질량 길이 |
| --- | ---: |
| 기존 incident 원천의 질량 잔여 | +3.7405773773357075e−49 cm |
| 새 혼합 GR homogeneous 성분 | −3.9945395762808945e−49 cm |
| 자체·수송 반환을 포함한 부호 있는 합 | −2.539621989451855e−50 cm |

분류: Counterexample candidate. 전 구간 최대값의 비교에서 합의 크기는 기존 incident 질량항 최대값의 **0.0736272배**다. 이 상쇄는 저장된 부호를 유지해 직접 계산한 것이다. 남은 비영 값을 방출 에너지에 넘기거나 0으로 설정하지 않았다. 또한 이 표가 초기 ADM 질량과 운동량 제약의 정확한 일치를 입증하지는 않는다.

## 실제 전하 식의 변경

분류: Proven. 초기 질량 `M0`, 초기 전하 계수 `α`, scalar 증분 `s`, 도달 에너지 질량 비율 `ε`, 별도 ADM 성분의 질량 비율 `κ=C/M0`를 사용하면 다음 식이 성립한다.

```text
q = [s + α(ε−κ)] / [1+κ−ε]
Δq = [δs + (α+q)(δε−δκ)] / [1+κ+δκ−ε−δε]
```

분류: Counterexample candidate. 같은 수정된 저장 배경의 `κ_B`를 두 진화 경로에 공통 적용했다. 기존 물질 매개 응답·내부 보정·mixed scalar·실제 수송 반환·직접장을 각각 유지한 채, 위 식의 질량항과 배경 정규화 변화를 연결했다. 이번 선택 응답은 이전 직접장과의 부동소수점 뺄셈으로 추출하지 않았다.

분류: Counterexample candidate. 질량 성분이 추가한 끝점 전하는 **`+3.4829714644393073e-57`**이다. 이전 선택 전하의 절댓값 대비 **1.3725495e-6**로, 크기를 조금 줄이지만 부호를 바꾸지 않는다. 배경 질량 정규화 매개변수의 최대 크기는 `1.3989654586192578e-30`이다. 이 수치적 크기를 전체 배경/EOS 오차의 상계로 해석하지 않는다.

분류: Counterexample candidate. 이 질량 판독의 대조 결과는 다음과 같다. 모든 비교는 새 질량 보정 자체의 전 구간 최대값으로 나눈 것이다.

| 대조 | 상대차 | 사전 기준 |
| --- | ---: | ---: |
| 기존 incident 64/128 실제 경로 | 0.00688011 | 0.02 |
| 4/8 구적 | 1.00867e−6 | 0.002 |
| mixed 원천 17/33 시각 표현 | 0.0100427 | 0.02 |

분류: Counterexample candidate. 마지막 대조는 원천 표현 검사이며 새로운 유체 진화 수렴이 아니다. 작은 두 질량의 상쇄가 잔여에 대한 상대차를 키우므로, 이전 각 항의 구적/시각 대조와 새 합의 대조를 구분했다. 동일한 정밀 mixed 장을 두 incident 경로에 사용했다.

## 작은 항의 산술 보존과 다음 물리적 병목

분류: Counterexample candidate. 최초 공통 분모를 longdouble로 구성하면 `κ_B`가 분모의 해상도보다 작아 사라진다. 전체 합의 고정밀 대조는 직접장에 의해 지배되어 작은 보정 각각의 정확도를 확인하기에 약했다. 원 판독·감사·프로그램은 보존하고, 저장값만 사용한 별도 보정에서 **각 질량항과 각 배경 분모 보정을 110자리 산술로 계산해 독립 열로 저장**했다. 질량항은 유리식의 직접 차분으로 부호·크기를 별도 확인했다. 물리 입력이나 원 대조 기준은 바꾸지 않았다.

분류: Counterexample candidate. 개별 성분 153개 대조의 최대 상대차는 `3.496e-52`로 1e-12 기준을 통과했다. 이 값은 저장된 수치 입력에 대한 산술 대조이며 물리적 정확도가 아니다. 기존 직접장에 대한 배경 분모 보정 `+3.954746496711868e-65`와 단계162 수송 반환의 질량항 `−5.888755455602563e-81`도 별도 열로 보존했다. 큰 선택 합에 반올림돼 보이지 않는 항을 0으로 보고하지 않는다.

분류: Proven. 외부 photon의 혼합 원천에는 stress의 계량 측도 변화가 필요하다. 고정 위치에서 Killing 에너지 재고 `e`를 유지한 packet의 Jordan 에너지 밀도 변화는 `−(ν_I+λ_I+4α f_I)`이고, 제약식 prefactor의 변화는 `2λ_I+4α f_I`다. 두 항의 합은 **`(λ_I−ν_I)e=−ζ_I e`**다. conformal 항은 상쇄된다. packet 에너지·위치 변화는 이 고정 위치 항과 별도이며, 이 항등식만으로 변한 광선이 해결되지는 않는다.

분류: Conjectural. 다음에는 **실제 외부 packet의 위 측도 항과 에너지·위치 변화, 외부 scalar 혼합 제약 원천을 함께 전파**해야 한다. 계량 prefactor만 기존 방출에 곱하는 것은 물리적으로 불완전하다. 그 결과와 초기 질량/flux를 대조해 남은 비영 질량항의 보존 여부를 판정해야 한다. 이번 homogeneous 성분 판독을 전체 물리적 ADM matching으로 승격하지 않는다. 이 때문에 `additional_exterior_mixed_stress_closed`, `exact_ADM_conservation_verified`, `physical_final_charge_solved`, `full_goal_complete`는 모두 false다.

분류: Conjectural. 외부 결합 외에도 직접장 정확도, 상위 입력, 전체 EOS·균일 미분·공간/보간/경계·비선형 오차와 동일 재고 정적/관측 비교는 전체 목표에 남아 있다. 원 완료 조건과 과거 실패 판정은 유지한다.
