# 바리온·운동량·에너지·수소를 같은 광자 단계에 결합

분류: Counterexample candidate. 최종 전하 결론은 미판정이다. 이전178은 실제 충돌 단계 전달로 H 수송 기준을 통과했지만 바리온 시간 대조2.2826%와 물질 상호 입력은 실패했다. 그 판정과 전체 기간 미실행을 유지한다. 이전 목표 턴은 실제 상태·판정을 바꾼 진전이다.

분류: Conjectural. 바리온·운동량을 포함한 네 물질 보존량과 광자를 같은 Radau 단계의 미지수로 푼다. 현재 B에서 재고 변위 xi를 계산하고 B/S의 실제 충돌·압력·속도 미분을 광자에 전달한다. 원 native 물질 유속과 중력을 같은 단계에서 평가하며 비충돌 E/H도 이전 파형에서 가져오지 않는다. 기존 광자 적분기·입력·배경·격자와64/128시계를 재사용한다. 같은 해의 실제 충돌·유속·투영 장부를 저장한다.

분류: Conjectural. 기존 실제178 상태는 Newton 초깃값으로만 사용한다. 작은 방향 응답의 국소 Jacobian은 풀이를 제안하며, 원 native 식의 잔차로 수락한다. 중간 Newton 반복은 최대3회, 선형 물리 잔차 보정은 기존처럼 최대3회다. 원1e-12 단계식,1e-13 에너지·수소 물리 잔차와 추가 B/S 물리 잔차를 검사한다. B/S 분모는 RHS 또는 실제 단계 상태의 크기이며 절대1 바닥으로 작은 성분을 숨기지 않는다. 원0.2% 미분·2% 시간·1e-8 보존 기준을 유지한다.

분류: Conjectural. 준비15초·연산자 대조80초·같은 T/16 구간의4/8macro-step 예비 쌍480초가 상한이다. CPU1스레드·가상메모리4GiB로 제한한다. 이전147.924초 실행에 native Jacobian·추가 결합 비용이 더해지는150–480초를 가정하며 대표 Jacobian을 실측해 실행 전에 재평가한다. 추가 미지수와 잔차 배열 때문에 메모리 상한을 명시적으로 늘렸다. 전체 기간은 등록하지 않았다. 물질 활동영역이 변하거나 원 기준·반복·자원 상한을 실패하면 중단하고 시계·방법·격자를 자동 확대하지 않는다.

분류: Counterexample candidate. 첫 대조는 활동영역이 고정이라는 가정을20.862초에 기각했다. 원 자유 물질 적분과 같은 실제 끝점 floor 투영을 복원하고 제거된 네 보존량을 별도 누적했다. 투영 전 단계식과 투영 후 수지를 각각 검사하며 다른 해의 상태를 덮어쓰지 않는다.20.873초 재대조에서 국소 Jacobian 방향 차이는 최대8.64e-6, 현재 물질의 광자 원천 매핑 차이는4.35e-17이었다. 원 실패와 producer를 보존했다.

분류: Counterexample candidate. 최초 실제 결합 계산은54.097초에 첫 단계의 원 기준을 실패했다. 세 번째 풀이의 전체 상대 잔차2.31e-16과 별개로 운동량의 물리 잔차6.22e-10이1e-13을 넘었다. 바리온 잔차는9.78e-15였다. 수락한 단계는 없고 이 실패를 작은 전체 잔차로 지우지 않는다.

분류: Conjectural. 원시변수 미분은 일부 출력을float64에 저장하므로 가까운 방향 응답을 다시 빼서 만든 Jacobian에서 작은 운동량 열이 오염될 수 있다. 이를 피하기 위해 현재 방향의 minmod·밀도·파동속도·donor 선택을 고정한 연산자의 열을 직접 계산한다. 원 native RHS·정밀도·최대Newton3회와 잔차 기준은 유지한다. 선택된 연산자는 원 방향에서 원 RHS를 정확히 재생해야 하며 Jg와 원 네 유속률을1e-12 이내에서 대조한다. 유한 차분이 실패의 유일 원인이라는 증명은 아니다.

분류: Counterexample candidate. 직접 열 방식의 독립 국소 방향 대조는 최대7.41e-13이었고19.136초가 들었다. 앞선 두 대조를 합쳐 원80초 안이다. 대표 Jacobian은3.441초였고 전체 예비 쌍 추정425.685초가 보수적420초 배정을 넘었다. 따라서 같은64경로부터 최대240초로 실행하고,128경로는 실측 stepping비용의 두 배와 구성·저장 여유20초가 원480초의 남은 예산 안에 들어갈 때만 실행한다. 최초54.097초 실패도 이 예산에 포함한다. 수락한64경로는 재계산하지 않는다. 추정식은 두Newton풀이를 가정하므로 상한 보증이 아니며 미측정 후반 비용의 불확실성을 유지한다.

분류: Counterexample candidate. 수정한 연산자를 실제 광자·B/S/Etilde/H 단계식에 적용한64시계의4개 macro-step,6개 실제 하위 단계가 완료됐다. T/16까지만 계산했으며216초(구성·저장 포함)가 들었다. 다음 수치는 같은 결합 해의 원 방정식·미분·투영 후 수지에서 나왔다.

분류: Counterexample candidate. 현재 B에서 재고 변위를 구하고 B/S를 현재 광자 충돌·압력에 전달하며 네 물질량을 같은 단계식으로 결정했다. 기존178 이력은 Newton 초기 추정에만 쓰였다. 실제 모든 단계의 보존량·native율·충돌율·시각·가중치와 끝점 floor 제거량을 함께 저장했다. 첫 단계 운동량 실패를 실제 예비 진화에서 해결한 **loophole progress**이며 최종 관측량의 성과 판정은 아니다.

분류: Counterexample candidate. 실제 비용으로 계산한128경로 추정은420.927초, 원480초에서 앞선 실패와64실행을 제외한 잔여는210.050초였다. 사전 규칙대로128적분을 시작하지 않았다. 따라서 시간 수렴의 통과·실패를 어느 쪽으로도 판정하지 않는다. 전체 기간·실제 GR 반환·최종 전하는 실행하지 않았고 기존 부호를 계승하지 않는다. 원80초 대조 비용은60.870초이며 최초 실패와 실제64 경로 계산은 합계269.950초다.

분류: Conjectural. 다음 결정에 필요한 계산은 저장된64해를 재사용한 원128시간 대조다. 현재 비용 병목은 많은 Krylov 반복(최대99, 초기 GMRES 비수렴10회 후 원 장정밀도 잔차 보정 통과)이므로 새 장기 계산 전 결합 전처리와 실제 비용을 재평가한다. 전하 판독 전에는 같은 해의 시간 오차·전체 기간·실제 계량 입력과 에너지·경계 이력을 연결해야 한다. 예산 실패를 우회해 자동 확대하거나 별도 해의 질량·일을 사후 합산하지 않는다.
