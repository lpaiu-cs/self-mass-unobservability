분류: Imported from prior work. 시작 체크포인트는 `8309f9b0b`다. 이전 H/He II 공급기와 분자 준위·원 항성 이력은 재사용했다. 새 후보는 별도 이름의 라이브러리이며 기존 두 gas/EOS 라이브러리의 SHA가 그대로임을 확인했다. 기존 단계64의 독립 원자 흡수 수렴을 새 EOS 후보에 자동 이전하지 않는다.

## 실제 변경

분류: Counterexample candidate. 이전 원자 실행의 `fort.5` 모형 순서와 `fort.28` 준위 식별자·가중치·결합에너지를 공통 표로 읽었다. He I, C I–III, N I–III, O I–III, Ne I–III, Mg II, Ca I–II가 대상이다. 원문 578개 준위 중 기존 유효 주양자수 상한 10을 적용한 566개가 남으며, 이 중 550개가 여기 준위다. 제외한 12개를 임의로 다시 살리거나 누락 연속 흡수를 0으로 인증하지 않는다.

분류: Counterexample candidate. 원 `qmhd_calc`를 재사용해 유한 준위의 PL/MHD 가중치와 첫·둘째 온도 및 환경 미분을 계산한다. 이 공급기를 **화학 퍼텐셜의 `excitation_pi`와 자유에너지·압력·에너지의 `excitation_sum` 양쪽**에 넣었다. 원 함수를 쓰는 H/He II와 분자 경로를 유지하고 표가 없는 금속 단계에 임의의 여기 합을 추가하지 않는다. 광학용 개별 합은 같은 컴파일된 함수에서 읽는다.

분류: Counterexample candidate. N III에서 EOS의 바닥 항 축퇴도 6과 광학의 분해된 바닥 준위 축퇴도 2가 달랐다. 원 자료의 다음 준위는 축퇴도 4, 간격 약 174.388cm⁻¹이다. 가중치를 맞추려고 선 세기를 조정하지 않고, 후보 EOS의 바닥 통계 가중치를 2로 바꾸고 위 준위를 여기 합에 포함했다. 통계 가중치를 읽는 `mod_eos_calc`의 평형·이온화 계산과 `mod_excitation`을 함께 재컴파일했다.

분류: Conjectural. 이 후보는 원 EOS의 이온화 에너지 기준점을 유지하면서 원자 표의 여기 에너지 차이를 보존하는 명시적 혼합 모형이다. 가져온 이온화 문턱과의 이동은 단계별 −331.869~+290.570cm⁻¹이다. 실제 광이온화 단면적의 문턱에도 같은 에너지 규약을 적용해야 하며, 현재는 이를 완료하지 않았다. 같은 해밀토니언의 원자 자료 인증으로 부르지 않는다.

분류: Conjectural. 중성 준위 반경은 원 `qmhd_calc`가 쓰는 반올림된 유효 주양자수와 `ellapprox=n−1` 근사 그대로다. 원 함수가 사용하지 않는 `ell` 자리에 LS 항의 전체 L을 추정해 넣지 않았다. PL 열역학 가중치를 광학 생존 확률로 읽는 가정, superlevel의 물리 정확도, 잘린 준위·소멸 연속 성분·누락 이온 단계는 미인증이다.

## 저장 외곽 상태의 검증

분류: Counterexample candidate. 원 상태 T=18827.94717983866K, rho=1.91629314435e−9g/cm³와 같은 조성을 썼다. lnT와 lnrho의 ±2e−4 및 ±1e−4 변화, 상태 재호출, 압력 역산을 합한 최종 12회 native EOS 호출을 저장했다.

분류: Counterexample candidate. 아래 수치는 지정 단일 상태 주변의 수치 대조이며 연속 구간의 엄밀 오차 상계가 아니다.

| 검사 | 최대 오차 또는 판정 |
|---|---:|
| 원소 재고 상대차 | 3.56×10⁻¹⁵ |
| 전하 재고 상대차 | 6.44×10⁻¹⁵ |
| 총 압력·에너지 미분 상대차, h=2e−4 | 1.905×10⁻⁷ |
| 같은 총미분, h=1e−4 | 4.759×10⁻⁸ |
| F=u−Ts에서 압력·엔트로피 재구성 상대차 | 5.867×10⁻⁹ |
| 준위 공급기의 첫·둘째 부분 온도 미분 상대차 | 2.487×10⁻⁶ |
| 광학 준위 합과 EOS의 ln 분배함수 상대차 | 8.715×10⁻¹⁴ |
| 상태 재호출 | 저장 배열 비트 일치 |
| 압력 역산의 ln rho 차이 | 0 |
| 압력·열용량·등온 압축 응답 | 모든 저장 상태에서 양수 |

분류: Proven. 같은 준위 점유가 `n_i ∝ g_i w_i exp(−E_i/kT)`이고 공동 생존 확률 `p_ij`에서 정·역 조건부 계수 `p_ij/w_i`, `p_ij/w_j`를 함께 적용하면 Einstein 대칭 아래에서 Kirchhoff 관계가 성립한다. `p_ij=min(w_i,w_j)`이면 두 조건부 계수는 모두 1 이하다. 이 항등식을 기호 검산했다. 축퇴된 두 상태는 양의 주파수 광자 전이로 세지 않는다. 이 항등식 자체는 전이 세기나 실제 산란 단면적을 결정하지 않는다.

분류: Counterexample candidate. 최초 상향 계수 `w_j/w_i`, 역방향 계수 1을 쓰는 해석에서 C III, N III, O III, Ne III의 일부 확률비가 1을 넘었고 최댓값은 1.00000410107이었다. 상세평형의 대수적 통과만으로 확률 해석을 보장하지 못하는 구체적 경계다. 후보를 위의 양방향 공동 확률 표현으로 바꿔 모든 조건부 계수가 (0,1]에 있고 순흡수가 양수임을 확인했다. 원 계수·결과와 바닥 가중치 수정 전의 부모 가중치를 보여주던 표 메타데이터도 보존했다. native EOS가 사용한 부모 가중치는 이미 수정되어 있었으므로 표 메타데이터 정정에 EOS 재계산은 없었다.

분류: Conjectural. `p_ij=min(w_i,w_j)`는 하나의 공통 균등 변수 U에 대해 `U<w_i`일 때 준위 i가 존재한다고 선언한 공동 모형이다. 확률로서는 일관되지만 실제 플라스마 준위 존재의 상관을 유도한 것은 아니다. 이 추가 가정과 PL/MHD 가중치 자체의 광학 해석을 인증하지 않는다.

분류: Counterexample candidate. 새 표의 양의 주파수 준위 쌍 10,557개에서 정규화 상세평형 잔차는 최대 4.440×10⁻¹³이다. 이는 각 역전이 계수를 1로 정규화한 조건부 쌍 대조다. 실제 oscillator strength를 가중한 총 불투명도 오차가 아니다.

분류: Counterexample candidate. 최초 binary64 쌍 대조는 아주 가까운 He I 준위에서 최대 1.430×10⁻⁹로 원 1e−10 문턱에 실패했다. 열역학 상태는 다시 풀지 않았다. 저장된 개별 합을 재사용하고 **한 결합에너지 배열에서 전이 에너지를 만들며 64비트 가수의 extended precision으로 점유·흡수 차를 평가**해 같은 문턱을 통과했다. 원 실패 결과와 원 광학 배열을 보존했다. `np.longdouble`의 가수가 더 짧은 플랫폼에서는 검사가 명시적으로 중단된다.

## 실패·비용과 다음 연결

분류: Counterexample candidate. 초기 연결에서는 금속만 있는 초기 추정 단계의 빈 수소형 준위 범위를 읽어 실패했다. 공통 유한 표에서는 그 범위를 읽지 않도록 고쳤다. 또 원 EOS 초기 추정기는 MHD 없이 PL만 적용하므로, 이 경로에서는 정의되지 않은 환경 변수를 읽지 않고 영 환경으로 같은 유한 합을 계산하도록 연결했다. 이후 결과 출력 심벌 공개와 Python 검사기의 리스트 절댓값 오류도 고쳤다. 원 실패·빌드 영수증을 보존했다.

분류: Counterexample candidate. 최종 채택 빌드는 6.06초, 실제 12상태 호출을 포함한 첫 전체 검사는 0.410초, 마지막 공동 확률 광학 검사는 0.217초였다. 여섯 개발 빌드의 보고 시간 합계는 약 32.8초로 120초 빌드 예산 이내다. CPU 스레드 1이며 새 광자 시간 적분 및 항성 GR 단계는 0이다. 다만 연결·검사 오류의 재시도에서 native 호출 시도 8회가 더 생겨, 초기 12회 호출 수 예산은 총 20회 시도로 초과했다. 이를 숨기지 않으며 물리 상태·해상도·기간 확대는 없었다. 이후 광학 수정은 저장 상태만 재사용했다. 메모리 사용량은 이번에 별도로 실측하지 않았다.

분류: Conjectural. **다음 직접 병목은 이 공통 점유수와 에너지 문턱을 실제 bound-bound 및 bound-free 단면적·역방출에 연결하는 것**이다. 기존 native 선 계산의 암묵 분배와 별도 명시 준위 합을 함께 제거해야 한다. 표 밖 전이, 잘린/소멸 준위의 연속 성분, F·낮은 Mg 및 높은 이온 단계 누락도 명시해야 한다. 이 연결 전에는 새 광자 결합 결과나 기존 항성 이력으로 물리 인증을 주장하지 않는다.

분류: Conjectural. 결합전자·Rayleigh 재분배, 비균일 대기, 전체 GR 운동량·계량 되먹임, 기존 속도/전하 수렴, 실제 구동·정적 비교·관측과 전체 동적 전하 목표는 계속 미완료다. 현재 결과는 공통 상태 공급기의 구현 병목을 해결한 것이며 이 전체 목표를 닫지 않는다.

분류: Imported from prior work. 재현 코드는 `verification/def_photon_shared_atomic.py`와 `verification/def_photon_shared_atomic_check.py`다. 현재 결과 확인은 전자의 `verify`로 하며 EOS를 다시 호출하지 않는다. WSL 과학 Python과 기존 의존성을 사용한다. 입력·계획·원 실패·수정 원문·패치·재사용 객체·후보 바이너리·저장 상태·광학 배열·기호 검사·보고서는 SHA manifest로 연결한다.
