# 단계111 — 물질·광자 비분할 시간 결합으로 전체 응답 대조 통과

분류: Counterexample candidate. 단계110에서 남았던 **전체 내부 trace의 시간 차이 4.8889%를 0.0372244%로 줄여 원 2% 기준을 통과했다.** 기존 반경·주파수·각도·시간 격자, 초기값, EOS와 문턱을 그대로 사용했다. 광자 수송과 물질 반응을 실제로 같은 시간식에서 풀어 얻은 결과다. 고정 배경 시간 병목의 해결이며, 움직이는 대기나 최종 전하의 완료는 아니다.

## 무엇을 연결했는가

분류: Counterexample candidate. 같은 16개 반경 셀·152개 Killing 주파수의 각도별 광자 점유와 native 수소 재고·총 내부에너지를 비분할로 진화시켰다. 각 단계에서 반경/각도 수송, Thomson 산란, 수소 흡수·자발/유도 방출, 화학 저장 에너지를 동시에 계산한다. 새 EOS 표나 광학 채널은 추가하지 않았다.

분류: Counterexample candidate. 물질 상태를 시도할 때 각 주파수의 띠 행렬로 광자장을 풀고, 그 미분을 반영한 32개 물질 변수의 Schur 방정식을 Newton 방법으로 풀었다. 시간법은 `gamma=1−1/sqrt(2)`인 두 단계 SDIRK다. 광자 양수성은 일반적으로 보장된다고 가정하지 않고, 실제 모든 수락 단계에서 직접 검사했다. 점유·온도·조성을 절단하거나 기존 잔차 문턱을 낮추지 않았다.

분류: Proven. 이 시간법의 안정함수는 `R(z)=[1+(1−2 gamma)z]/(1−gamma z)^2`다. 원점의 0/1/2차 미분은 모두 1이고 무한대 극한은 0이다. 허수축에서 분모 절댓값 제곱과 분자 절댓값 제곱의 차이는 `gamma^4 y^4 ≥ 0`, 극점은 우반평면에 있으므로 A 안정성과 감쇠 극한을 갖는다. 이는 매끄러운 ODE의 형식 차수·안정성에 대한 명제이며 실제 강결합 문제의 연속 오차 상계나 양수성 정리는 아니다.

분류: Proven. 물질 총 내부에너지와 광자 에너지에 동일한 반응량·시간 가중치를 적용하면 내부 교환은 상쇄된다. 같은 단계 가중치로 계산한 경계 광자 유속만 전체 수지에 남는다. 독립 수치 대조에서는 이 상쇄와 기존 보존 공간 연산자를 함께 확인했다.

분류: Counterexample candidate. 가장 온도 변화가 큰 셀과 표면 쪽 셀을 실제 native EOS로 재평가했고, 저장된 모든 각도 스냅샷의 J/H/K와 비음수 조건을 독립 재계산했다. 시간·각도 대조를 통과한 표면 점유·광도 이력은 `surface-port-candidate.npz`에 내보냈다. 반경·주파수 대조를 통과했다고 표시하지 않았다.

## 해결 범위와 남은 직접 병목

분류: Counterexample candidate. 단계110의 분할 시간 실패는 그대로 보존한다. 같은 입력·격자에서 비분할 결합만 바꿔 전체 응답 대조를 통과했으므로, 기존 강한 결합을 분리해 계산하던 시간 처리의 문제를 실제 진화에서 해소했다. 다만 두 시간 격자만으로 엄밀한 시간 오차 상계나 점근 차수까지 인증한 것은 아니다.

분류: Counterexample candidate. 현재는 깊은 내부의 밀도·계량이 고정이고, 표면 경계는 진공 incoming 조건이다. 단계108의 움직이는 내부·대기는 여전히 지정 광자장을 사용하므로, 두 모형이 동일 광자장을 주고받는 결합은 미완료다. 반경/주파수 해상도, 누락 반응·광학 채널, 전체 GR/scalar 되먹임과 최종 전하도 남아 있다. 이번 결과는 **loophole progress**, 시간식·교환 상쇄식은 **theorem progress**다. 전체 목표는 active다.

분류: Conjectural. 다음 직접 작업은 이 결합식을 실제 내부·대기 접합으로 옮겨 같은 반경 면에서 양방향 광자 유속과 물질 교환을 함께 진화시키는 것이다. 표면 이력을 외부 가열량으로 단순 주입해 전체 결합으로 부르지 않는다. 접합에 필요한 경계층의 실제 반경·EOS를 연결하고, 그 결합 결과를 좌우하는 반경/주파수 오차를 판단해야 한다.

## 계산 예산과 보존

두 짧은 시험으로 두 각도 경로를 직접 측정했다. 전체 세 경로의 예상은 94.23초, 두 배 여유 상한은 188.46초였다. 최초 120초 예산의 자격 판정은 false로 보존했고, 이 실측을 근거로 같은 세 경로의 실행 상한만 200초로 명시적으로 재평가했다. 해상도·시간 구간·경로 수·문턱은 바꾸지 않았다. 실제 생산 묶음은 **70.09초**, 두 짧은 시험의 경로 합은 1.22초였다. CPU 한 스레드 설정이며 메모리 2GB는 예산으로만 기재했다.

추가 native 호출은 끝점 대조 **11회/24회**, 감사 실행은 약 1.65초였다. 두 시험에서 이미 계산한 시작 두 단계는 완전한 누적 경계 에너지 기록을 얻기 위해 전체 경로에서만 재실행했다. 원 시험 결과와 당시 소스는 보존했다. 장기 전체 항성 적분이나 추가 256단계 경로는 실행하지 않았다.

단계 전 checkpoint: `fa2c644d0`. 관련 여섯 문서, 증거 목록과 기존 OSK 상세·허브·scope를 갱신했다. 과거 실패·미완료 판정을 소급 변경하지 않는다.
