# 단계138 — 실제 결합 잔차의 전하 적용과 조건부 상계

분류: Counterexample candidate. 단계137의 광자–자유 물질 에너지/H 불일치를 같은 보존 변수의 native 압력·반경 응력·trace로 변환하고 실제 지연 GR 판독에 적용했다. 이어 셀별 잔차의 부호와 시간별 조합을 자유롭게 허용한 입력 집합의 전하 상계를 구성했다. 새 유체·광자 궤적, EOS 표, 격자·기간·시간 경로는 추가하지 않았다. 실제 잔차의 전하 연결은 loophole progress이며, 지정한 저장 계수 모형의 상계는 조건부 theorem progress다.

분류: Proven. 정확한 binary 저장 계수와 아래 명시한 선형 원천 재구성을 전제로, 주128/128 경로의 허용 E/H 원천 집합은 compact GR의 모든 퍼텐셜 반복을 포함해 정규화 전하 변화 절댓값1.446615046085e-52 이하를 준다. 독립40자리 구간 연산으로531셀·17압력 시점의 변환과8,496개 공간/퍼텐셜 계수 부등식을 확인했다. 이 정리는 물리 EOS 계수 생성 오차나 실제 결합 해의 오차가 이 입력 집합에 들어간다는 주장까지 증명하지 않는다.

## 실제 원천 연결

분류: Counterexample candidate. 공통17시점에서 residual=광자 풀이의 물질 E/H−자유 물질의 E/H를 구성했다. 바리온·운동량·계량·광자·포트를 고정한 채 기존 보존 primitive 압력 소유자를 재사용했다. 에너지/H 기저에서 접선·반경 압력 계수를 얻고, 실제 잔차를 함께 넣은 별도 native 판독과 비교했다. 중첩 항등식의 상대 차이는최대3.853e-16, 압력 기저의 독립 probe 차이는최대0.000181108로 원0.002 기준을 통과했다. sampled probe를 균일 물리 EOS 미분 인증으로 바꾸지 않는다.

분류: Proven. 이 고정 조건에서 기준 에너지 차이δEref와 중성수소 차이δH의 압력 변환은 다음 선형식이다. 반경 압력에는 고정 운동량에서 생기는 속도·운동응력 변화도 기존 소유자를 통해 포함된다.

```text
δe = δEref / a_ref
δPt = c_tE δEref + c_tH δH
δPr = c_rE δEref + c_rH δH
δtrace = δe − δPr − 2 δPt
δmetric_stress = δe − δPr
```

분류: Counterexample candidate. 이 원천으로 질량 제약J와 지연 scalar 응답을 직접 판독했다. EOS 압력 변화의 진단값만 계산하고 멈춘 것이 아니다. 네 기존4/8차 대조의 구적 차이는8.217e-16, Jordan 반경의 독립 직접 적분 차이는최대8.315e-15로 기준을 통과했다.

## 상계의 정확한 전제와 증명

분류: Proven. 각 셀에서 B_E=max_k|residual_E(k)|, B_H=max_k|residual_H(k)|로 저장 입력 집합을 정의한다. 각 저장 시점에서 |δEref|≤B_E, |δH|≤B_H를 독립적으로 허용한다. 고정 압력 계수에 삼각부등식을 적용하면 접선/반경 압력과 trace를 모두 제한할 수 있다. 이 원천 집합은 실제 물질 방정식을 만족하는 궤적보다 넓다. 독립적인 임의 부호 원천 자체를 물리적 보존 진화 해라고 부르지 않는다.

분류: Counterexample candidate. 주 경로의 셀별 상한 합은 에너지2.903913e4erg, H7.804980e10이다. 각 셀의 최대 시점이 달라도 허용하므로 단계137의 최대시점 L1 잔차2.879843e4erg/7.727897e10보다 넓다. 영 압력 변환 셀의 E/H 잔차 비율도 단위를 섞지 않고 각각 확인했으며2.742e-39/4.308e-35 이하였다.

분류: Proven. 기존 GR의 공간 Legendre 재구성에서 각 계수의 절댓값 상한을 저장 inverse 행렬의 절댓값으로 전파했다. |P_n|≤1을 이용하며, 특성선에서 나뉜 양의 구적 가중치와 나뉘지 않은 기존 광학 구적 가중치의 합을 모두 덮었다. 노드 최대값이나 상쇄된 끝점만으로 공간 노름을 대신하지 않았다. 시간 원천의 선형 보간은 입력 최대 노름을 늘리지 않는다.

분류: Proven. 자유 응답의 노름 상한을B, compact 퍼텐셜 연산자를P라 하면 U=U_free+P U에서 ||P||≤η<1은 ||U||≤B/(1−η)를 준다. 저장된 공간 퍼텐셜 재구성도 같은 방식으로 제한했다. 이 η는 scalar의 compact 퍼텐셜 반복만의 노름이다. 유체·광자·EOS 전체 되먹임의 수축 상수가 아니다.

## 현재 전하와의 관계 및 남은 요구사항

분류: Counterexample candidate. 단계130의 기존 조건부 하한1.020019038924e-27와 비교하면 주 경로 잔차 집합의 상계는그 하한의1.418224e-25배다. 그 하한 자체는 전체 EOS·시간·경계·비선형 오차를 포함한 최종 하한이 아니다. 이번 잔차 판독이나 상계로 기존 추가 compact 성분1.64550663e-44 또는 주 성분1.02113508e-27를 대체하지 않는다.

분류: Proven. 만약 최종 E/H 유래 원천 오차가 이번 정확한 입력 집합의A배 안에 든다면 해당 전하 영향은A*1.446615046085e-52 이하이다. 기존 조건부 하한을 이 항목만으로 지우려면A가약7.05e24 이상이어야 한다. 이 조건문은 A의 실제 크기를 인증하지 않으며, 다른 바리온·운동량·EOS·경계 오차가 같은 집합 안에 든다고 가정하지 않는다. 두 반복의 유한 감소율로 A를 정하지 않았다.

분류: Conjectural. 따라서 같은 E/H waveform을 더 반복해 잔차를 줄이는 일은 현재 우선순위가 낮다. 다음은 주 전하를 만드는 원천의 오차 예산이다. 저장된 실제 전 이력의 EOS 구성 관계·미분 오차와 시간/작은 물질 포트/삭제 물질 조건을 같은 전하 판독에 연결하고, 실제 결합 증폭을 제한해야 한다. 원초기 GR 열역학 계수 표현과 수정 EOS의 일치도 열린 조건으로 유지한다. 전체 EOS 인증·외부/삭제 물질 후속 수송·비선형 GR·정적 비흡수성과 관측 likelihood 및 최종 전하의 요구사항을 줄이지 않는다.

## 실행 비용과 보존한 실패

첫 압력 pilot는 계량 입력을3성분으로 잘못 만든 새 판독 코드에서 실패했다. 실제 소유자는5성분을 요구하므로 그 소유자의 반환 shape를 사용하도록 수정했다. 원 생산자·계획·오류를 보존했고 물리 진화나 원천 생산은 아직 시작 전이었다. 실패의 정확한 벽시간을 따로 저장하지 못했으므로 원45초 cap 전부를 보수적으로 계상했다.

수정 pilot5.02초는 원120초 원천 예산에서 차감했다. 중간시점 실측을 이용한 원천 예상35.53초/여유 상한71.05초가 남은114.98초 안에 들어왔고, 실제 원천 연결은23.90초였다. 중간시점의 성공한 압력 변환은 재사용했다. 네 지연 GR 판독은39.41초/45초, 최초 상계 및 입력 결속은65.32초/90초였다.

독립 구간 검사는 처음에 같은 NPZ 배열을 매 스칼라 연산마다 다시 읽어 남은24초 cap에서 중단됐다. 수치 부등식 실패는 아니며 원 계획·검사자·중단을 보존했다. 배열을 한 번만 메모리로 읽도록 수정하고, 이미 끝난 원천 단계의 남은 예산 중최대60초를 독립 판독에 재배분했다. 원 단계 총합300초는 늘리지 않았다. 독립 전체 검사는6.54초에 통과했고, 두 실패를 보수적으로 포함한 단계 계상은209.18초였다. 원90초 구간 안에서 첫 독립 검사까지 성공했다고 소급하지 않는다.

모든 시간은 각 driver 내부 구간이며 interpreter import·공유 디스크 입력 대기 일부와 전체 대화 시간을 포함하지 않는다. 프로세스 확인 시134초 벽시간에 CPU9초인 입력 대기도 관측했다. 이를 새 물리 적분 비용으로 바꾸어 보고하지 않는다. 새 native 표·궤적·waveform 반복은0회다.
