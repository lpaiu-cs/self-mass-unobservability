# Lemma 59: data beyond a Taylor series

Status: Proven. A smooth-flat local response has every finite Taylor jet. If the goal is exact functional reconstruction, its jet alone is insufficient and additional profile/amplitude data are needed. For a finite-order asymptotic calculation the same response is already contained in the remainder; no replacement of that calculation is required.

Status: Proven. A threshold branch can require threshold position, exponent, branch and amplitude data to specify the response across activation. Its failure of regularity at the threshold must not be inferred for every nonanalytic function.

Status: Proven. These functional data do not prove an infinite number of fitted parameters, an independent measurable force, or a failure of fixed-order catalog finiteness. See [Lemma 55](55-monopole-jet-collapse.md) and [Lemma 58](58-nonanalytic-jet-failure.md).
