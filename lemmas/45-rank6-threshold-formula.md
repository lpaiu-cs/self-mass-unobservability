# Lemma 45: Rank-6 Threshold Formula

## Scope

- Status: Proven. This lemma derives the class-limited threshold formula for the audited parity-even fully symmetric trace-free rank-6 primitive family `Z_{ijklmn}`.
- Status: Proven. The statement is only for the audited rank-6 class and does not by itself prove a theorem for all even ranks.

## Witness Weights

- Status: Proven. The first self witness is `Z2`, so

```math
W_{\mathrm{self}}(\mathrm{Reven6+}; w_Z) = 2 w_Z.
```

- Status: Proven. The first mixed witness is `EZZ`, so

```math
W_{\mathrm{mix}}(\mathrm{Reven6+}; w_Z) = 2 w_Z + 1.
```

- Status: Proven. No lower mixed layer exists in the audited rank-6 class because both `EZ` and `EEZ` are absent under the current primitive-family definition.

## Threshold Consequence

- Status: Proven. Therefore

```math
W_{\min}(\mathrm{Reven6+}; w_Z) = 2 w_Z.
```

- Status: Proven. At `\Delta \le 4`, the exclusion condition is

```math
2 w_Z > 4,
```

  hence
  `w_Z \ge 3`.
- Status: Proven. The audited rank-6 threshold is self-only and sharp.

## Structural Interpretation

- Status: Proven. The audited rank-6 result does not repeat the rank-4 `EEQ` exception.
- Status: Proven. Instead, the audited rank-6 case returns to the `Y2 / EYY` first-witness pattern already seen at ranks `L = 3, 5`.
- Status: Proven. Therefore the present audited evidence supports the view that rank `4` is an isolated even-rank exception inside the currently audited STF sector, not the first confirmed member of a broader audited even-rank pattern.
