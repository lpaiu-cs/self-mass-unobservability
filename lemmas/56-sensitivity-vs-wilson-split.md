# Lemma 56: Sensitivity Versus Wilson Split

## Statement

- Status: Proven. Work with a local worldline action of the form

```math
S_A
=
\int d\tau \left[
-m_A(Y)
+ \sum_\alpha C_{A,\alpha}\,{\cal O}_\alpha
\right],
```

where `Y^I` is a finite scalar normal-form basis and `{\cal O}_\alpha` is a finite residual operator basis.
- Status: Proven. Then the body-dependent free-fall data split into two finite coefficient sets:
  the monopole sensitivities from the Taylor jet of `m_A(Y)`,
  and the higher-multipole Wilson coefficients `C_{A,\alpha}` multiplying residual operators.

## Positive Part Of The Split

- Status: Proven. By Lemma 54, the scalar normal-form basis `Y^I` is finite.
- Status: Proven. By Lemma 55, the fixed-order analytic monopole jet contains finitely many sensitivity coefficients.
- Status: Proven. The residual operator list `{\cal O}_\alpha` is finite because it is drawn from the same finite admitted family catalog and fixed-order local derivative expansion.
- Status: Proven. Therefore both the sensitivity set and the Wilson-data set are finite.

## Distinction

- Status: Proven. Sensitivity coordinates are Taylor coefficients of the scalar monopole function `m_A(Y)`.
- Status: Proven. Wilson data are coefficients of residual higher-multipole operators `{\cal O}_\alpha`.
- Status: Proven. The theorem does not merge these two structures into one undifferentiated coefficient set.

## Conditionality

- Status: Proven. The sensitivity side uses analyticity `A5`.
- Status: Proven. The Wilson side uses locality `A3` and the sharpened local weight-spectrum condition `A8`.
- Status: Proven. Therefore the positive finite-family collapse theorem is closed inside the current theorem domain, but its exact assumption-drop failure modes remain `A3`, `A5`, and `A8`.
