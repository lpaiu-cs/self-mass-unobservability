# Lemma 68: State Versus Wilson Split

## Statement

- Status: Proven. In the finite state-augmented branch, the body-dependent free-fall data split into two distinct sectors:
  augmented monopole and state-space data,
  and higher-multipole Wilson coefficients.
- Status: Proven. Local state variables are not Wilson coefficients.

## Augmented State Sector

- Status: Proven. The augmented monopole/state sector consists of:
  the finite scalar normal-form coordinates `Y^I`,
  the finitely many local state variables `\chi^a`,
  the local analytic monopole function `m_A(Y,\chi)`,
  and the local state-evolution data encoded in `{\cal L}_{\rm state}` or equivalently in the state equations.
- Status: Proven. These data belong to the low-multipole response manifold, now enlarged from `Y^I` to `(Y^I,\chi^a)`.

## Wilson Sector

- Status: Proven. The Wilson sector still consists of the coefficients `C_{A,\alpha}` multiplying the residual higher-multipole local operators `{\cal O}_\alpha`.
- Status: Proven. This sector is unchanged by whether the monopole bookkeeping uses Y-only or the augmented `(Y,\chi)` coordinates.

## Separation

- Status: Proven. The augmented local state variables do not get absorbed into Wilson coefficients.
- Status: Proven. Wilson coefficients do not replace the explicit state variables or their initial data.
- Status: Proven. Therefore the `A4` branch breaks the original no-state sensitivity theorem but does not erase the state-versus-Wilson distinction.
