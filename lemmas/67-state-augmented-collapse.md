# Lemma 67: State-Augmented Collapse

## Statement

- Status: Proven. Keep the fixed local scalar normal-form basis `Y^I`, fixed admitted primitive-family content, locality `A3`, and analyticity `A5`.
- Status: Proven. Drop only the no-state assumption `A4` and admit finitely many explicit local state variables `\chi^a`.
- Status: Proven. Then the original Y-only theorem fails in general, but a finite state-augmented collapse theorem survives at the level of a finite-dimensional local state-space EFT.

## Finite State-Augmented Theorem

- Status: Proven. The augmented local worldline data can be written as

```math
S_A
=
\int d\tau \left[
-m_A(Y,\chi)
+ {\cal L}_{\rm state}(Y,\chi,\dot{\chi})
+ \sum_\alpha C_{A,\alpha} {\cal O}_\alpha
\right],
```

with finitely many scalar normal-form coordinates `Y^I`, finitely many local state variables `\chi^a`, and finitely many residual higher-multipole operators `{\cal O}_\alpha`.
- Status: Proven. Because the admitted primitive-family catalog is finite and the local scalar operator quotient is already finite, the only new bookkeeping directions are the finitely many explicit state variables `\chi^a`.
- Status: Proven. Therefore the free-fall body dependence still collapses to a finite-dimensional local state-space description:
  finitely many scalar normal-form coordinates,
  finitely many local state variables,
  finitely many local state-evolution equations,
  and finitely many Wilson coefficients.

## What Survives And What Does Not

1. Status: Proven. The original Y-only sensitivity jet of Lemma 55 does not survive in the genuinely dynamical branch.
2. Status: Proven. The finite-dimensional local state-space structure does survive, because the state sector is explicitly finite by construction.
3. Status: Proven. The resulting positive branch is therefore weaker than the original no-state theorem but stronger than a generic nonlocal or infinite-state escape.
4. Status: Proven. If one further wants a finite truncated Taylor-coefficient count in the augmented variables `(Y^I,\chi^a)`, an additional explicit state-amplitude truncation convention is needed; that stronger coefficient-counting statement is not smuggled in here.

## Verdict

- Status: Proven. The smallest local finite-state counterexample breaks the original no-state theorem.
- Status: Proven. A finite state-augmented collapse theorem nevertheless survives as a finite-dimensional local state-space statement.
